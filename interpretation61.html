STEP 0 — First Read —

まず、自分で読んでみよう

解説を読む前に必ずやってほしいステップ。「自分はどう読んだか」を意識化することが、読み方を身につける最大の近道です。

"Developing countries" is a term used to describe the countries of the world which are not rich and which are in the process of improving agriculture, building more factories, and making better roads.

STOP. ここで一度立ち止まって。
① まず辞書を引かずに訳してみてください。
② 訳せなくても OK。「どこで詰まったか」を意識してください。
③ 「ここの構造がよく分からない」「この単語の品詞が判別できない」と感じたら、それがあなたの伸びしろです。
STEP 1 — Common Mistakes —

ありがちな誤読を先につぶしておく

この英文で多くの生徒がハマる罠が 6つ あります。先に見ておくことで、自分が同じ罠にハマっていないかチェックできます。

! "Developing countries" の引用符を訳出しない
「発展途上国とは~」(引用符なし)

★ "Developing countries" の ""(=引用符)に対応するものとして、日本語の「 」(かぎかっこ)を使う!
★ 正しい訳: 「「発展途上国」とは~」
★ 引用符は、その語が用語・専門用語として扱われていることを示す!
★ developing = 「発展している」(=現在分詞、形容詞用法)
★ developing countries = 「発展途上国」(=慣用表現)

! a term used to describe ~ の used を「使った」と訳す
「~を説明するために使った言葉~」

★ used の3つの用法を区別する!
(1) be used to (V)「~するために使われる」: used は過去分詞(=受動態)
例: This oven is used to bake bread.「このかまどはパンを焼くのに使われている」
(2) be used to (V)ing「~するのに慣れている」: used は形容詞
例: Nancy is used to baking bread.「ナンシーはパンを焼くのに慣れている」
(3) used to (V)「かつて~した」: used to で助動詞
例: I used to bake bread, but now I do not.「私はかつてパンを焼いていたが、今ではやっていない」
★ 本問の used:
→ "Developing countries" is a term までで一つの完成された文。
→ 後続の used ... は形容詞か過去分詞形とみるのが妥当!
→ ここでは a term (used to describe ~) = 「~を説明するために使われる言葉」
→ used は(1) 過去分詞として直前の a term を修飾!
★ a term used to describe ~ の訳に「~を説明するための言葉」は不適切!正しくは「~について述べるために使われる言葉」

! the countries of the world which are not rich の which の先行詞を取り違える
「世界の中の豊かではない国々~」

★ 関係代名詞の先行詞は直前の名詞とは限らない!
★ the countries of the world which are not rich
→ もし which の先行詞を直前の the world とすると、「豊かではない世界」となるが、これは不自然!
→ are(=複数の動詞)で受けているから、主語は複数形 → the countries が先行詞!
★ 判別ルール: 関係代名詞の先行詞を見つけるときは、動詞の数(単複)で判別!
★ the countries of the world which are not rich = 「世界の中で経済的に豊かではない国々」
★ 「世界の中の~な国々」とすると、「~」が「世界」を修飾しているように取られかねない → 「世界の中で~な国々」とする!
★ which を代名詞 they(=the countries)に置き換えると意味がとれる: they are not rich「彼らは豊かではない」

! the process of improving ~, building ~, and making ~ の三つ以上の並列を見落とす
「(三つの動名詞句が並列していることが分からない)」

★ and の前にコンマがあれば複数並列の可能性!
★ 本問の構造:
→ the process of improving agriculture, building more factories, and making better roads
→ 3つの動名詞句が並列!
★ 第60講で学んだ通り、三つ以上のものを並べる場合、最後の要素の直前にだけ and をつけるのが英語の標準!
★ 本問:
(1) improving agriculture「農業を改善する」
(2) building more factories「より多くの工場を建てる」
(3) making better roads「よりよい道路を造る」
★ これら3つが in the process of ~(=「~の過程にある」)に続く動名詞句として並列!
★ 視覚化:
which are in the process of ┳ improving agriculture,
    ┃ building more factories,
    ┗ and making better roads

! in the process of ~ を「過程の中の」と訳す
「~過程の中の国々~」

★ in the process of ~ = 「~の過程にある」「~している過程にある」(=慣用)
★ which are in the process of improving agriculture = 「農業を改善している過程にある(国々)」
★ 「過程の中の」は不自然!「過程にある」と意訳!

! describe を「説明する」と訳す
「~について説明する~」

★ describe = 「~について述べる/~を描写する」(=「説明する」より広い意味)
★ a term used to describe the countries = 「国々について述べるために使われる言葉」
★ 「説明する」も意味は通るが、「述べる」「描写する」の方が文脈に合う!
★ 例: describe a scene「場面を描写する」、describe one's feelings「気持ちを述べる」

★ of the world = 「世界の」(=形容詞句、countries を修飾)

① 直訳
発展途上国は世界の国々を説明するために使った言葉である、それは豊かではない、そしてそれは農業を向上させ、より多くの工場を建て、そしてよりよい道路を作る過程の中である。 構造どおりの直訳。「説明するために使った」「過程の中」が硬く、関係代名詞節をきちんと結合できていない。

② 中間訳

💡 自然訳の「型」: used ─ 3つの用法

★ used には3つの用法があります!混同しやすいので、しっかり区別しましょう!

★ (1) be used to (V)「~するために使われる」: used は過去分詞(=受動態)
例: This oven is used to bake bread.「このかまどはパンを焼くのに使われている」
→ use「使う」の受動態。「~するために使われている」というニュアンス。

★ (2) be used to (V)ing「~するのに慣れている」: used は形容詞
例: Nancy is used to baking bread.「ナンシーはパンを焼くのに慣れている」
→ used は形容詞「慣れている」、to は前置詞、後ろは動名詞!

★ (3) used to (V)「かつて~した」: used to で助動詞
例: I used to bake bread, but now I do not.「私はかつてパンを焼いていたが、今ではやっていない」
→ 過去の習慣・状態を表す。

★ 判別のコツ:
(1) be used + to + 動詞の原形 → 「~するために使われる」
(2) be used + to + 動名詞 → 「~するのに慣れている」
(3) used + to + 動詞の原形(=be なし) → 「かつて~した」

★ 本問では受動態ではありませんが、used の働きは(1)と同種!過去分詞として直前の a term を修飾しています。

This tool is used to fix the engine. この道具はエンジンを直すのに慣れている この道具はエンジンを直すのに使われる ((1) be used to V = 受動態「使われる」)
I am used to driving on the left. 私は左側通行のために使われる 私は左側通行に慣れている ((2) be used to V-ing = 形容詞「慣れている」)
She used to live in Paris. 彼女はパリに住むために使われた 彼女はかつてパリに住んでいた ((3) used to V = 助動詞「かつて~した」)

STEP 3 — Try It Yourself —

同じ思考で、別の英文を読んでみる

読み方は「使えてナンボ」。今日身につけた思考プロセスを、別の英文で試してみましょう。答えを見る前に必ず自分で考えるのがポイント。

Q1 used の用法判別 ① 受動態

Hammers are used to drive nails.

used の用法と訳は？

用法: be used + to + 動詞の原形「~するために使われる」(=過去分詞、受動態)
訳: 「ハンマーは釘を打つために使われる」

💡 後ろが動詞の原形(drive) → (1)の用法!
Q2 used の用法判別 ② 慣れ

I am used to getting up early.

used の用法と訳は？

用法: be used + to + 動名詞「~するのに慣れている」(=形容詞)
訳: 「私は早起きすることに慣れている」

💡 後ろが動名詞(getting) → (2)の用法!be 動詞 + used to V-ing。
Q3 used の用法判別 ③ かつて

There used to be a tower here.

used の用法と訳は？

用法: used + to + 動詞の原形(=be なし)「かつて~した」(=助動詞)
訳: 「かつてここに塔があった(が、今はない)」

💡 be 動詞がない → (3)の用法!過去の習慣・状態を表す。
