▶ 過去完了 had been V-ed + Such was the case 倒置 + コロン

過去完了 had been V-ed で、過去より前の時制を捉える

Online Cram School THINKING
▶ THIS LESSON

この講で身につく「読み方」

第58講のテーマは 「過去完了 had been V-ed で、過去より前の時制を捉える」。
第19講で受動態、第43講で過去分詞、第54講で受動態並列を学びましたが、今日は時制をさらに一歩深く!
過去完了形 had + V-ed「(過去のある時点より前から)~していた」(=完了/継続)
さらに今日のサブテーマは 倒置 Such was the case と コロン (:) で具体例を導入!
第43講応用の過去分詞、第15講応用の or 並列、第29・55講応用の because 副詞節、第19講応用の受動態も登場!
今日のキー:
① have V-ed(=現在完了)「(現在まで)~した/している」
② had V-ed / had been V-ed(=過去完了)「(過去のある時点より前に)~していた」(=継続/完了/経験)
③ Such was the case「そういう事例だった」(=倒置、強調表現)
④ 過去分詞修飾: "letters" called hieroglyphics「ヒエログリフと呼ばれる「文字」」(=第43講応用)
⑤ コロン (:) で具体例・説明を導入(=英文の頻出記号)

STEP 0 — First Read —

まず、自分で読んでみよう

解説を読む前に必ずやってほしいステップ。「自分はどう読んだか」を意識化することが、読み方を身につける最大の近道です。

Some languages in the long history of writing have "died" because there are no longer any native speakers or writers of the language. Such was the case with written "letters" called hieroglyphics: the meanings and the sounds of the hieroglyphic symbols had been lost over many centuries.

STOP. ここで一度立ち止まって。
① まず辞書を引かずに訳してみてください。
② 訳せなくても OK。「どこで詰まったか」を意識してください。
③ 「ここの構造がよく分からない」「この単語の品詞が判別できない」と感じたら、それがあなたの伸びしろです。
STEP 1 — Common Mistakes —

ありがちな誤読を先につぶしておく

この英文で多くの生徒がハマる罠が 8つ あります。先に見ておくことで、自分が同じ罠にハマっていないかチェックできます。

! Some languages in the long history of writing の in the long history of writing を取り違える
「(in the long history of writing が何を修飾するか不明)」

★ in the long history of writing = 前置詞句「書かれた言葉の長い歴史の中で」(=Some languages を修飾)
★ 本問: Some languages in the long history of writing have "died" ~
→ S = Some languages「いくつかの言語」(=主語の中心)
→ 修飾 = in the long history of writing「書かれた言葉の長い歴史の中で」(=前置詞句、Some languages を修飾)
→ V = have "died"「死んだ」(=現在完了)
★ writing:
→ 動名詞「書くこと/書かれた言葉」(=不可算名詞、第41講応用)
→ ここでは「書かれた言葉/文字記録」のニュアンス!
★ the long history of writing = 「書記言語の長い歴史」
→ 「文字を使った言語の歴史(=人類が文字を書き始めてからの歴史)」
→ 5000年以上前のシュメール文字あたりから!
★ 意訳: 「書かれた言葉の長い歴史の中で、いくつかの言語は「死んだ」」
★ "died"(=引用符):
→ 引用符付きの died は「比喩的に死んだ」(=実際に生き物のように死んだのではなく、使われなくなった)
→ 「死語になる」(=言語学の用語)
★ 類例(=of writing):
・the art of writing「文字を書く技術/書記法」
・the history of writing「文字の歴史」

! have "died" の現在完了を取り違える
「(現在完了の意味を取り違え)」

★ have V-ed = 現在完了「(過去から)~した」(=完了/結果/継続/経験)
→ 過去の出来事が現在に影響!
★ 本問: Some languages have "died"
→ S = Some languages
→ V = have "died"「死んだ(状態にある)」(=現在完了、結果)
→ 過去に死んで、現在も死語のまま!
★ die(=自動詞「死ぬ」)の活用:
→ 原形 die
→ 過去形 died
→ 過去分詞 died(=過去形と同じ)
★ 現在完了の用法:
(1) 結果「(過去に~して)現在は~の状態」(=本問!)
(2) 完了「(現在までに)~した」
(3) 継続「(過去から現在まで)~している」
(4) 経験「(過去に)~したことがある」
★ 本問の意味合い:
→ 過去に「死んだ」(=使われなくなった)
→ 現在も「死んだまま」(=もう話す人がいない)
→ 結果としての現在の状態を表す!
★ 意訳: 「(いくつかの言語は)死んだ(=今も死語のままだ)」
★ 類例(=現在完了 結果):
・He has gone to Paris.「彼はパリへ行ってしまった(=今ここにいない)」
・I have lost my key.「鍵を失くした(=今も見つからない)」

! there are no longer any native speakers or writers of the language の no longer を取り違える
「(no longer の意味を取り違え)」

★ no longer = 副詞句「もはや~ない」(=「以前はあったが、今はない」)
→ not ~ any more / not ~ anymore と同じ意味!
★ 本問: there are no longer any native speakers or writers of the language
→ there are 構文 = 「~がある/いる」(=存在)
→ S = any native speakers or writers「(いかなる)母語話者や書き手」(=any + 名詞 or 名詞)
→ M = no longer「もはや~ない」(=否定)
→ 修飾 = of the language「その言語の」
★ any の用法:
→ no longer + any ~ → 「もはや(いかなる)~もいない」(=完全否定)
★ 意訳: 「その言語の母語話者や書き手は、もはや一人もいない」
★ native speakers = 「母語話者」(=その言語をネイティブとして話す人)
★ native writers = 「(母語として)書ける人」
★ or の名詞並列(=第15講応用):
→ speakers or writers「話し手や書き手」(=2つの名詞並列)
→ どちらも of the language「その言語の」が修飾!
★ 類例(=no longer):
・He no longer lives here.「彼はもはやここに住んでいない」
・I no longer love her.「彼女をもう愛していない」

! because there are no longer any native speakers の because を取り違える
「(because の役割を意識しない)」

★ because = 接続詞「~なので/~だから」(=理由、第29・55講応用)
→ 副詞節「~の理由」を導く
★ 本問: Some languages ~ have "died" because there are no longer any native speakers ~
→ メイン文 = Some languages have "died"「いくつかの言語は死んだ」
→ because 副詞節 = because there are no longer ~「~がもはやいないから」(=理由)
★ 核心: because 副詞節はメイン文の理由を表す!
→ 「死語になる」=「話す人がいなくなる」 という因果関係!
★ because vs so:
(1) because + S V → 副詞節「~なので」(=理由)
(2) so → 接続詞「だから/それで」(=結果)
(3) 因果関係: A because B = B so A(=同じ事実、語順が逆)
★ 意訳: 「~がもはやいないから(=死語になる原因)」
★ 類例(=because):
・I am tired because I worked too much.「働きすぎて疲れた」
・She passed because she studied hard.「彼女は一生懸命勉強したから合格した」

! Such was the case with ~ の Such was the case を取り違える
「(Such was the case の倒置を取り違え)」

★ 核心 ─ 倒置!
★ Such was the case (with ~) = 「(~に関して)そういう事例だった」(=倒置、慣用表現)
→ 通常の語順: The case was such (with ~).
→ 倒置語順: Such was the case (with ~).(=本問!)
→ 補語 such が文頭に出ると、主語と動詞が倒置!
★ 本問: Such was the case with written "letters" called hieroglyphics
→ 補語 = Such「そういう/そのような」(=代名詞、前文を指す)
→ V = was(=be 動詞)
→ S = the case「事例/状況」
→ M = with written "letters" called hieroglyphics「ヒエログリフと呼ばれる書かれた「文字」に関して」
★ 倒置の意味:
→ 補語 Such = 前文の内容を指す代名詞「そのような(死語になった事例)」
→ 「そういう事例だったのが、ヒエログリフ」(=具体例の導入)
★ be the case = 「事例である/事実である」(=慣用)
→ This is the case.「これは事実だ」
→ That is the case.「それは事実だ」
★ 意訳: 「そういう事例だったのが、ヒエログリフと呼ばれる「文字」だ」
★ 本問の意味合い:
→ 前文: 言語が死語になる(=母語話者がいなくなる)
→ Such was the case「そういう事例だった」
→ with hieroglyphics「ヒエログリフに関して」
→ つまり、ヒエログリフは死語の典型例!
★ 類例(=倒置 Such was ~):
・Such was his anger that he couldn’t speak.「彼の怒りはそれほど大きく、話せなかった」
・Such is life.「人生とはそういうものだ」(=有名なフレーズ)

! written "letters" called hieroglyphics の written / called を取り違える
「(written と called の過去分詞修飾を取り違え)」

★ 核心: written / called = どちらも過去分詞!(=第43講応用)
→ 名詞 letters を前後から修飾!
★ 本問: written "letters" called hieroglyphics
→ 名詞 = "letters"「文字(複数)」(=引用符付き、特殊な意味合い)
→ 前から修飾 = written「書かれた」(=過去分詞、形容詞的、第42講応用)
→ 後ろから修飾 = called hieroglyphics「ヒエログリフと呼ばれる」(=過去分詞句、第43講応用)
★ 2つの過去分詞の違い:
(1) written: 1語の過去分詞 → 名詞の前から修飾
(2) called hieroglyphics: 過去分詞句(=過去分詞 + 補語) → 名詞の後ろから修飾
★ letter の意味:
→ ここでは「文字」(=「手紙」ではない!)
→ 引用符付き "letters" で、「文字」という特殊な意味を強調!
→ ヒエログリフは絵のような文字!
★ hieroglyphics:
→ 「ヒエログリフ/エジプト象形文字」(=固有名詞)
→ 古代エジプトで使われた絵文字
→ 紀元前3000年頃から紀元4世紀頃まで使われ、その後「死語」に!
→ ロゼッタストーン(=第52講!)で解読された!
★ 意訳: 「ヒエログリフと呼ばれる、書かれた「文字」」
★ 類例(=過去分詞修飾):
・a written letter「書かれた手紙」(=前置)
・a letter written by him「彼によって書かれた手紙」(=後置、過去分詞句)
・a country called Japan「日本と呼ばれる国」(=後置)

! had been lost over many centuries の had been lost を取り違える
「(had been lost の過去完了受動態を取り違え)」

★ 本講最大の核心 ─ 過去完了!
★ had + V-ed = 過去完了形「(過去のある時点より前から)~していた」(=完了/継続/経験)
→ さらに受動態と組み合わさると had been V-ed「(過去のある時点より前に)~されていた」
★ 本問: the meanings and the sounds of the hieroglyphic symbols had been lost over many centuries.
→ S = the meanings and the sounds of the hieroglyphic symbols「ヒエログリフのシンボルの意味と音」
→ V = had been lost「失われていた」(=過去完了 + 受動態)
→ M = over many centuries「何世紀にもわたって」
★ 過去完了の構造:
→ had + V-ed(=過去分詞)
→ had + been + V-ed(=受動態の過去完了)
★ 過去完了の意味:
→ 過去のある時点より前の出来事/状態
→ 本問: 「(発見・解読された時点より前から)失われていた」(=継続)
→ 「(ある時点より前に)失われた状態だった」(=完了/結果)
★ 時制の重なり:
→ ヒエログリフの意味と音 = 何世紀にもわたって失われていた(=過去完了)
→ そして、ロゼッタストーン発見・解読(=過去) = 過去完了より後の時点!
→ 過去完了 = 過去より前の時制!
★ over many centuries = 「何世紀にもわたって」(=期間、継続)
→ over = 「~にわたって/~の間に」(=期間を表す前置詞)
★ 意訳: 「ヒエログリフのシンボルの意味と音は、何世紀にもわたって失われていた」
★ 類例(=過去完了):
・When I arrived, he had already left.「私が着いた時、彼はすでに出ていた」(=過去より前の完了)
・She had studied English for ten years before she went to America.「彼女はアメリカに行く前に、英語を10年勉強していた」(=過去より前の継続)
・The book had been written before I was born.「その本は、私が生まれる前に書かれていた」(=過去完了 + 受動態)

! コロン (:) の役割を取り違える
「(コロンの役割を取り違え)」

★ コロン (:) の役割:
→ 説明・具体例・引用を導入する記号!
→ 「つまり/具体的には/すなわち」というニュアンス!
★ 本問: Such was the case with written "letters" called hieroglyphics: the meanings and the sounds of the hieroglyphic symbols had been lost over many centuries.
→ コロンの前: 「ヒエログリフがそういう事例(=死語)だった」(=主張)
→ コロンの後: 「意味と音が何世紀にもわたって失われていた」(=具体的な説明)
★ コロンの主な用法:
(1) 具体例の導入(=本問!)
(2) リストの導入: There are three things: A, B, and C.
(3) 説明・要約の導入
(4) 引用の導入
★ 意訳のニュアンス:
→ 「~だ。具体的には、~」
→ 「~だ。つまり、~」
→ 「~だ。その内容は、~」
★ 類例(=コロン):
・I have one wish: to live in peace.「私には1つの願いがある。それは平和に生きること」
・There are two reasons: time and money.「2つの理由がある。時間と金だ」
・Remember this: practice makes perfect.「これを覚えておけ。練習が完璧を作る」
★ セミコロン (;) との違い:
→ コロン (:) = 説明・具体例の導入
→ セミコロン (;) = 関連する2つの文を繋ぐ(=接続詞の代わり)
