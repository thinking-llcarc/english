STEP 0 — First Read —

まず、自分で読んでみよう

解説を読む前に必ずやってほしいステップ。「自分はどう読んだか」を意識化することが、読み方を身につける最大の近道です。

Now I know if each of us has a sense of responsibility and gives our pets more attention, we can reduce the number of unhappy pets.

STOP. ここで一度立ち止まって。
① まず辞書を引かずに訳してみてください。
② 訳せなくても OK。「どこで詰まったか」を意識してください。
③ 「ここの構造がよく分からない」「この単語の品詞が判別できない」と感じたら、それがあなたの伸びしろです。
STEP 1 — Common Mistakes —

ありがちな誤読を先につぶしておく

この英文で多くの生徒がハマる罠が 6つ あります。先に見ておくことで、自分が同じ罠にハマっていないかチェックできます。

! Now I know if ~ の if を「~かどうか」と取る
「私は~かどうか知っている~」(=if の用法を取り違える)

★ if は多義語(=第21講応用)!
(1) 名詞節「~かどうか」
(2) 副詞節「もし~なら」(=本問はこちら!)
★ 判別の核心: 本問では know の直後に if が来るが、文の構造を整理すると…
★ 本問の構造: Now I know (that) if ~ , we can reduce ~ .
→ know の後ろにthat が省略されている!
→ that 節の中身は 「if 節 + 主節」の構造!
→ つまり if は副詞節「もし~なら」!
★ full version:
→ Now I know that, if each of us has ~, we can reduce ~ .
→ I know that 〔if 節, 主節〕
★ 判別ルール:
→ if 節の後ろに別の主節(=条件の結果)が来る → 副詞節!
→ if 節が動詞の目的語の位置で完結する → 名詞節!
★ 本問は「if 節 + 主節 we can reduce ~」で完結 → 副詞節!

! that が省略されていることに気づかない
「(know if ~ という構造に違和感)」

★ that の省略: 動詞 know / think / believe / say / hope 等の後ろの that は省略可能!(=第18講で学習)
★ 本問: Now I know if each of us has ~ , we can reduce ~ .
→ 元の形: Now I know that if each of us has ~ , we can reduce ~ .
→ that が省略されている!
★ 判別のヒント:
→ 動詞の後ろに「主語+動詞」が突然出てきたら、that 省略を疑う!
→ 本問は「know + if 節 + 主節」 → 全体が that 節の中身!
★ 類例:
・I think (that) he is right.「私は彼が正しいと思う」
・She said (that) she would come.「彼女は来ると言った」
★ 口語では that を省略することが多い!

! each of us has の has に違和感
「(each of us が複数主語と思って have を期待)」

★ each of us = 「私たち一人ひとり」!
★ 判別の核心: each = 「それぞれ」(=単数扱い!)
→ 主語が each ~ なら、動詞は三人称単数現在(=has)!
★ 本問: each of us has a sense of responsibility
→ S = each of us(=単数扱い)
→ V = has(=三単現の-s)
→ 「私たち一人ひとりが責任感を持つ」
★ 類例:
・Each of them is special.「彼ら一人ひとりは特別だ」(=is、単数)
・Each student has a textbook.「各生徒が教科書を持っている」(=has、単数)
★ 注意: all of us(=私たち全員)は複数扱い!
→ All of us have ~
★ each(=個別) vs all(=全体)で扱いが違う!

! a sense of responsibility を「責任の感覚」と硬く訳す
「責任の感覚~」(=やや硬い)

★ a sense of responsibility = 慣用「責任感」
★ a sense of ~ = 「~の感覚」「~感」
★ 類例:
・a sense of humor「ユーモアのセンス/ユーモア感」
・a sense of duty「義務感」
・a sense of belonging「所属感」
・a sense of direction「方向感覚」
★ 意訳: 「責任感」(=慣用、自然な日本語)
★ have a sense of responsibility = 「責任感を持つ」
★ responsibility = 「責任」(=名詞)
→ responsible(=形容詞「責任のある」)の名詞形

! gives our pets more attention の構造を見落とす
「(give + 名詞 + 名詞 のパターンを忘れる)」

★ give + O₁(人) + O₂(物) = 「O₁にO₂を与える」(=第4文型 SVOO、第4講応用)
★ 本問: gives our pets more attention
→ V = gives(=他動詞、三単現)
→ O₁ = our pets「私たちのペット(に)」
→ O₂ = more attention「より多くの注意(を)」
★ 意訳: 「ペットにもっと注意を与える」「ペットにもっと気を配る」
★ give A B = 「AにBを与える」!
→ A(=人) と B(=物)は別物(=第4講応用)
★ 類例:
・give me a present「私にプレゼントをくれる」
・give him a hand「彼に手を貸す」
★ attention = 「注意/関心」(=不可算名詞)
★ more attention = 「より多くの注意」(=比較級+不可算名詞)
★ more = much の比較級!

! we can reduce the number of unhappy pets の the number of ~ を見落とす
「(the number of の慣用を取り違える)」

★ the number of ~ = 慣用「~の数」
★ 本問: we can reduce the number of unhappy pets
→ S = we
→ 助 = can「~できる」
→ V = reduce「減らす」(=他動詞)
→ O = the number of unhappy pets「不幸なペットの数」
★ 意訳: 「不幸なペットの数を減らせる」
★ 類例:
・the number of students「生徒の数」
・the number of cars「車の台数」
・a number of people「いくつかの人々」(=不定冠詞、=「いくつかの」)
★ 注意: the number of ~(=「~の数」、定冠詞)と a number of ~(=「いくつかの~」、不定冠詞)を区別!
★ unhappy pets = 「不幸なペット」(=形容詞 unhappy + 名詞 pets)
★ unhappy = happy(=幸せ)に否定の接頭辞 un- を付けた形「不幸な」

STEP 2 — Read Along —

左から右へ、頭の中の実況中継

読める人は、英文を読みながら頭の中で常に何かを「考えて」います。その思考プロセスを 1語ずつ覗いてみましょう。これが英文解釈の正体です。

1 Now I know ▸ 主語+動詞 ─ 今、私は分かる

冒頭 Now I know「今、私は分かる」!

★ Now = 副詞「今」
★ S = I「私」
★ V = know「分かる/知る」(=他動詞)

★ know は他動詞 → 後ろに目的語が必要!
→ 後ろに that 節が来そう!(=第18講応用)

→ でも本問では that が見えない…that の省略を疑う!
〈Now〉S=I / V=know「今、私は分かる」(=他動詞、that 節を予測!that 省略の可能性!)
2 if ▸ if が登場 ─ 「~かどうか」or「もし~なら」?

来ました if!

★ if = 多義語(=第21講応用)!
(1) 名詞節「~かどうか」
(2) 副詞節「もし~なら」

★ どちらか? 後ろの構造を見て判断!
→ 後ろに「主節(=結果)」が続けば 副詞節「もし~なら」!
→ if 節が動詞の目的語で完結すれば名詞節「~かどうか」!

→ 後ろを追ってみる!
if = まだどちらか不明!後ろの構造を待つ!
3 each of us has a sense of responsibility ▸ if 節の中身① ─ 一人ひとりが責任感を持つ

each of us has a sense of responsibility「私たち一人ひとりが責任感を持つ」!

★ if 節の中身(=主語+動詞):
→ S' = each of us「私たち一人ひとり」(=単数扱い!)
→ V' = has「持つ」(=他動詞、三単現!)
→ O' = a sense of responsibility「責任感」

★ each of us の単複:
→ each = 「それぞれ/一人ひとり」(=単数扱い)
→ だから動詞は has(=三単現)!

★ a sense of ~ = 「~感」(=慣用)
→ a sense of responsibility = 「責任感」

★ 意訳: 「私たち一人ひとりが責任感を持つ」

→ さらに後ろに and が来そう!
if 節の中: S' = each of us(=単数扱い) / V' = has / O' = a sense of responsibility「責任感を持つ」
4 and gives our pets more attention, ▸ and ─ 動詞2つをつなぐ + give + O₁ + O₂

来ました and gives our pets more attention,「そしてペットにもっと注意を向ける」!

★ and = 接続詞、何をつなぐ?
→ 前: has a sense of responsibility「責任感を持つ」
→ 後: gives our pets more attention「ペットに注意を与える」
→ 動詞句2つをつなぐ!(=主語 each of us が共通、第8講応用)

★ gives = 三単現の-s!(=主語 each of us が単数扱い)

★ give + O₁ + O₂ = 「O₁にO₂を与える」(=SVOO、第4講応用)
→ O₁ = our pets「私たちのペット(に)」
→ O₂ = more attention「より多くの注意(を)」

★ attention = 「注意/関心」(=不可算名詞)
★ more = much の比較級「もっと」
★ more attention = 「もっと多くの注意」

★ 意訳: 「ペットにもっと注意を向ける」「ペットにもっと気を配る」

★ コンマ → if 節は終わり、後ろに主節が来るはず!
and = 動詞句2つをつなぐ。give + O₁ + O₂「ペットにもっと注意を向ける」。if 節終了、主節を予測!
5 we can reduce the number of unhappy pets. ▸ 主節 ─ if 節の結果

最後に we can reduce the number of unhappy pets.「私たちは不幸なペットの数を減らせる」!

★ S = we「私たち」
★ 助 = can「~できる」
★ V = reduce「減らす」(=他動詞)
★ O = the number of unhappy pets「不幸なペットの数」

★ the number of ~ = 慣用「~の数」
★ unhappy pets = 「不幸なペット」

★ これが主節! if 節の結果を示す!
→ if 節「もし~なら」+ 主節「~できる」
→ 「もし責任感を持ってペットに注意を向ければ、不幸なペットの数を減らせる」

★ 核心: if は副詞節「もし~なら」と確定!
→ if 節が単独で完結せず、主節が続いた → 副詞節!

★ 全体の構造:
→ Now I know (that) 〔if 節, 主節〕.
→ know の目的語=that 節(=that 省略)
→ that 節の中身=if 節+主節

★ 全体の意訳:
→ 「今私は分かっている、私たち一人ひとりが責任感を持ってペットにもっと注意を向ければ、不幸なペットの数を減らせるのだと」

★ 本講の本質: 動詞の後ろのthat 省略を見抜き、その中身がif 節+主節と整理する!入れ子構造を左から右に処理!
主節「不幸なペットの数を減らせる」!if 節は副詞節「もし~なら」と確定。「責任を持てば結果を変えられる」のメッセージ!

5つのステップで、左から右へと考えてきたことを構造図にまとめると、こうなります。色分けで見ると、骨格(メイン)と補足の関係が一気にクリアになるはず。

▼ 構造が見えたら、いよいよ訳の仕上げ

構造解析で終わると「結局この文は何を言ってるの？」が宙ぶらりんになりがち。
ここから、直訳 → 中間訳 → 完成訳と、日本語として自然な訳に磨き上げる手順を見ていきます。これも「センス」ではなく、ちゃんと段階的な手順があります。

① 直訳
今、私は知っている、もし私たちのそれぞれが責任の感覚を持って、私たちのペットにもっと多くの注意を与えるならば、私たちは不幸なペットの数を減らすことができる。 構造どおりの直訳。「責任の感覚」「注意を与える」が硬く、流れもぎこちない。
▼ that の省略: know/think/believe + (that) S V 動詞の後ろに「主語+動詞」が突然出てきたら、that 省略を疑う!口語ではよく省略される。
② 中間訳
今、私は分かっている。もし私たち一人ひとりが責任感を持って、ペットにもっと注意を向けるなら、不幸なペットの数を減らせるのだと。 「責任の感覚」を「責任感」に、「注意を与える」を「注意を向ける」に意訳。「~のだと」で締める。
▼ 条件の if「もし~なら」(=副詞節、第21講応用) if 節の後ろに主節(=結果)が続けば副詞節!動詞の目的語で完結すれば名詞節「~かどうか」。
③ 完成訳
今私は分かっている、私たち一人ひとりが責任感を持ってペットにもっと注意を向ければ、不幸なペットの数を減らせるのだと。 「もし~なら」を「~ば」(=日本語的)に、「責任感を持って~注意を向ければ」と一気に流す。これで完成!
💡 自然訳の「型」: that の省略 + if 副詞節 ─ 入れ子構造の整理

★ 第24講で身につけてほしい「省略を見抜く目」と「節の整理」を伝えます。

★ 英語、特に口語では、that がよく省略されます。

★ that 省略のパターン:
★ 動詞 (know, think, believe, say, hope, feel 等) + (that) + 主語 + 動詞 ~
→ that が省略されても意味は同じ!

★ 本問の例:
★ Now I know (that) if each of us has ~ , we can reduce ~ .
→ know の後ろに that 省略
→ that 節の中身は「if 節 + 主節」の構造!

★ 判別ヒント:
★ 動詞の後ろに「主語+動詞」が突然出てきたら、that 省略を疑う!
★ 本問の場合、know の後ろにいきなり if が来るが、これは「if 節を含む大きな that 節の始まり」!

★ 本問の整理:
★ Now I know (that) [〈if 節〉, 主節] .
(1) 主節: Now I know「今、私は分かる」
(2) that 節(=know の目的語、省略あり): その内側全体
(3) that 節の中身は「if 副詞節 + 主節」の構造!
  ・if 副詞節: if each of us has ~ and gives ~「もし~なら」
  ・主節: we can reduce ~「~できる」

★ 左から右に処理:
(1) Now I know ─ 主節の主語+動詞
(2) if ─ あれ?ここで that 省略を疑う + if が始まる
(3) each of us has ~ ─ if 節の主語+動詞(=単数扱い)
(4) and gives ~ ─ 動詞句2つ目(=主語共通)
(5) , ─ if 節終了
(6) we can reduce ~ ─ 主節の続き(=if 節の結果)

★ もう一つ大事なポイント ─ each of us:
★ each = 「それぞれ」 ─ 単数扱い!
★ だから動詞は has, gives(=三単現の-s)!
★ all of us(=私たち全員、複数扱い)とは違う!
例: Each of us has ~(=単数) vs All of us have ~(=複数)

★ 本問のメッセージ:
★ 「責任感を持てば、行動を変えられる」
★ 動詞の三単現の-sは、文法的な細かい点だが、主語の単複を明確にする大事な印!

★ これからの60講で、that 省略 + 副詞節のような複合構造は何度も登場します。出会うたびに「省略を疑い、節の境目を整理する」姿勢で読みましょう!

I think he is right. (動詞の後ろに突然 he is が来て混乱) 私は彼が正しいと思う (think の後ろに that 省略、that 節 = he is right)
She knows if you study hard, you will succeed. 彼女はあなたが一生懸命勉強するかどうか知っている 彼女は、もしあなたが一生懸命勉強すれば成功すると分かっている (know + that 省略 + if 節 + 主節)
Each of the students has a textbook. (each of に have を使ってしまう) 生徒一人ひとりが教科書を持っている (each = 単数扱い、動詞は has)

1 左から右へ、1語ずつ品詞と役割を確定する
→
2 骨格と修飾語(M)を色分けで把握する

STEP 3 — Try It Yourself —

同じ思考で、別の英文を読んでみる

読み方は「使えてナンボ」。今日身につけた思考プロセスを、別の英文で試してみましょう。答えを見る前に必ず自分で考えるのがポイント。
知識として「覚える」のではなく、手を動かして「使える」状態に持っていきます。

Q1 that の省略

I know he is busy.

know の後ろに何が省略されている？

分析: know の後ろにthat が省略!
→ 元の形: I know (that) he is busy.
→ that 節 = he is busy「彼は忙しい(ということ)」(=know の目的語)
訳: 「私は彼が忙しいと知っている」

💡 動詞の後ろに「主語+動詞」が突然出たら、that 省略を疑う!
Q2 副詞節の if + 主節

If you study hard, you will pass the exam.

if 節の役割と全体の構造は？

分析: If S V = 副詞節「もし~なら」(=条件、第21講応用)
・if 節: If you study hard「もし一生懸命勉強すれば」
・主節: you will pass the exam「試験に合格するだろう」(=結果)
訳: 「もし一生懸命勉強すれば、試験に合格するだろう」

💡 if 節の後ろに主節(=結果)があれば副詞節!
Q3 each of us ─ 単数扱い

Each of us has a special role.

なぜ has？have ではない？

分析: each of us = 「私たち一人ひとり」(=単数扱い!)
→ each = それぞれ → 一人ひとり
→ 動詞は三単現の-s!
→ だから has(=三単現)!
訳: 「私たち一人ひとりには特別な役割がある」

💡 each(=個別)は単数扱い!all(=全体)は複数扱い!
STEP 4 — Your Reading Algorithm —

これからの英文に使える「思考フロー」

最後に、今日の学びを初見の英文に使える型として整理しておきます。これを毎回頭の中で回せば、確実に読める英文が増えていきます。

1
動詞 + S V → that 省略を疑う
know, think, believe, say, hope, feel 等の後ろに突然「主語+動詞」 → that 省略!
2
that 節の中身が「if 節 + 主節」
that 節は大きな名詞節!その中に if 副詞節と主節が入る入れ子構造!
3
if の2つの顔(=第21講応用)
名詞節「~かどうか」(=動詞の目的語)、副詞節「もし~なら」(=条件)。後ろの構造で判別!
4
条件の if: if 節 + 主節(=結果)
本問は副詞節!if 節の後ろに「~できる」のような結果が続く。
5
each of us「一人ひとり」(=単数扱い)
動詞は三単現の-s(=has, gives)!all of us(=複数扱い)とは違う。
6
慣用 a sense of responsibility「責任感」
a sense of ~ = 「~感」!a sense of humor/duty/direction なども覚える。
7
慣用 the number of ~「~の数」
a number of ~(=「いくつかの~」)とは違う!定冠詞 the で「~の数」を表す。
8
give + O₁ + O₂「O₁にO₂を与える」(=第4講応用)
O₁(人) と O₂(物)は別物!give our pets more attention「ペットに注意を与える」!

今日のチェックリスト ─ 全部できれば本日の内容は完璧

  • that の省略を見抜ける(=動詞+S V のパターン)
  • that 節の中身が if 節 + 主節(=入れ子構造)を整理できる
  • 条件の if「もし~なら」(=副詞節、第21講応用)を再確認
  • if の2つの顔の判別(=後ろに主節が続けば副詞節)ができる
  • each of us「私たち一人ひとり」(=単数扱い)を覚えた
  • each(個別、単数) vs all(全体、複数)の違いを理解した
  • 慣用 a sense of ~「~感」を覚えた
  • 慣用 the number of ~「~の数」を覚えた
  • a number of ~(=「いくつかの~」)との違いを理解した
  • give + O₁ + O₂(=SVOO、第4講応用)を再確認
  • 左から右に積み上げて入れ子構造を整理できる
  • STEP 3のドリル3問を、答えを見ずに自力で説明できる
