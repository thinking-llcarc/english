STEP 0 — First Read —

まず、自分で読んでみよう

解説を読む前に必ずやってほしいステップ。「自分はどう読んだか」を意識化することが、読み方を身につける最大の近道です。

Scientific progress is made step by step, each new point that is reached forming a basis for further advances.

STOP. ここで一度立ち止まって。
① まず辞書を引かずに訳してみてください。
② 訳せなくても OK。「どこで詰まったか」を意識してください。
③ 「ここの構造がよく分からない」「この単語の品詞が判別できない」と感じたら、それがあなたの伸びしろです。
STEP 1 — Common Mistakes —

ありがちな誤読を先につぶしておく

この英文で多くの生徒がハマる罠が 7つ あります。先に見ておくことで、自分が同じ罠にハマっていないかチェックできます。

! Scientific progress を「科学的進歩」と訳す
「科学的進歩は段階を踏んでなされ~」

★ Scientific progress = 「科学の進歩」(=「科学的進歩」は避ける)
★ scientific は形容詞で「科学の/科学的な」だが、progress と組み合わさるときは「科学の進歩」が自然!
★ 「科学的進歩」は意味は通るが、やや硬い日本語。「科学の進歩」と訳す方が自然!

! is made を「作られる」と訳す
「科学の進歩は段階を踏んで作られる~」

★ make の目的語に動詞の名詞形が置かれる場合、make を「~を作る」とするとおかしな日本語になる!
★ 原則: 動詞の名詞形を元の動詞に戻して訳す!
★ 例:
・make a choice of ~「~を選ぶ」(=「~の選択をする」と訳すと硬い)
・make use of ~「~を利用する」
・make an excuse「言い訳をする」
・make a mistake「間違いを犯す」
・make a decision「決定する」
・make a call「電話をする」
・make a turn「曲がる」
・make a reservation「予約する」
★ 今回 make scientific progress「科学の進歩をなす」の受動態の形 → 「科学の進歩がなされる」と訳す!
★ 「科学の進歩がつくられる」は不自然!

! step by step を「ステップ・バイ・ステップ」とカタカナで訳す
「ステップ・バイ・ステップで~」

★ step by step = 「段階を踏んで」「一歩ずつ」「少しずつ」(=慣用)
★ カタカナ表記避ける。「段階を踏んで」「一歩ずつ」と日本語で。
★ by = 「~ずつ」(=「方法・手段」ではない、ここでは「~ごとに」のニュアンス)。

! each new point that is reached forming ~ の構造を取り違える
「(eachが何の役割か分からず混乱)」

★ 判別: Scientific progress is made step by step までで1つの完成された文!
★ よって、後ろの each new point ... advances は副詞節!
★ さらに、that の後ろは is reached(=主語が欠落) → that は関係代名詞!(=第40講)
★ each new point that is reached = 「達成される一つ一つの新たな段階」(=カタマリを形成、each new point を説明)
★ もし forming a basis for further advances が形容詞句で each new point を修飾すると仮定すると、「達成される、さらなる進歩のための基礎を形成する一つ一つの新たな段階」で1つの大きな名詞となる。
★ しかし、完全な文の後ろに名詞が単独で置かれることは普通ない!
★ よって、each 以下は独立分詞構文!
= each new point that is reached は forming の意味上の主語!

! forming a basis を「基礎が作られる」(誤り)と訳す
「~の基礎がつくられる」

★ forming a basis = 「基盤を形成する/基礎を築く」(=動詞 form)
★ 直訳「基礎を形成する」は可だが、能動態。日本語ではこれを受動態に変換!
→ 「基盤が築かれる」「基礎が形成される」(=自然な日本語)
★ 「基礎がつくられる」は不適切!(=「築く/形成する」と意訳)
★ 「基礎が築かれる」「基礎が構築される」が適切!

! each new point を「点(ポイント)」と訳す
「一つ一つの新たな点(ポイント)~」

★ point は多義語!
① 「点」「ポイント」(=単純な意味)
② 「段階」「地点」(=文脈による)
③ 「論点」「要点」
★ ここでは「段階」が適切!
→ 「達成される一つ一つの新たな段階」
★ 「点(ポイント)」と訳すと、文脈に合わない!
★ カタカナ「ポイント」も避ける!

! each + 単数形の名詞 を every と同じと考える
「(each と every の違いを意識しない)」

★ 《each+単数形の名詞》と《every+単数形の名詞》はいずれも「各々の~」という意味だが、ニュアンスが違う!
① every = 「すべて一緒に」の感じ(=形容詞、全体性)
② each = 「一人一人別個に」の感じ(=個別性)
★ 例:
・Nancy gave a hug to each student.「ナンシーは生徒一人一人を抱きしめた」(=個別性、each)
・Every student was happy.「すべての生徒が幸せだった」(=全体、every)
★ 今回 each new point = 「一つ一つの新たな段階」(=個別性のニュアンス)
→ 「(達成されるたびに)新たな段階が」のニュアンスを表現!

左から右へ、頭の中の実況中継

読める人は、英文を読みながら頭の中で常に何かを「考えて」います。その思考プロセスを 1語ずつ覗いてみましょう。これが英文解釈の正体です。

★ step by step = 「段階を踏んで」「一歩ずつ」「少しずつ」(=慣用)

3 each new point ▸ each + 単数形の名詞 ─ 個別性

each new point「一つ一つの新たな段階」が登場。

★ 《each + 単数形の名詞》= 「一人一人別個に」のニュアンス(=個別性)
→ every(=「すべて一緒に」)とは違う!

★ point = 「段階/地点」(=多義語、ここでは「段階」が文脈に合う)
→ 「点(ポイント)」と訳すのは不適切!

★ each new point = 「一つ一つの新たな段階」

★ 判別: 完全な文の後ろに each new point ~ がある!
→ 単独の名詞ではなく、独立分詞構文の主語(=意味上の主語)の可能性大!
→ 続きを見て確認!
each new point = 「一つ一つの新たな段階」(individuality を強調する each)
4 that is reached ▸ 関係代名詞 that ─ 主語欠落

that is reached「達成される」が登場。

★ that の判別(=第40講):
→ is reached の主語が欠落!
→ that は関係代名詞!

★ 先行詞は直前の each new point!
→ each new point that is reached = 「達成される一つ一つの新たな段階」(=カタマリを形成)

★ reach = 「~に到達する/~を達成する」
★ be reached = 「達成される/到達される」(=受動態)
{that is reached} = 関係代名詞節「達成される」(each new point を修飾)

来ました forming a basis「基盤を形成する」!

★ 判別: もし forming a basis for further advances が形容詞句で each new point を修飾と仮定すると...
→ 「達成される、さらなる進歩のための基礎を形成する一つ一つの新たな段階」で1つの大きな名詞。
→ しかし、完全な文の後ろに名詞が単独で置かれることは普通ない!

★ よって、each 以下は独立分詞構文!(=主文の主語と異なる主語をもつ分詞構文、第53講)
→ each new point that is reached は forming の意味上の主語!

★ 元の文: each new point that is reached forms a basis for further advances
= 「達成される一つ一つの新たな段階が、さらなる進歩のための基盤を形成する」
→ これを分詞構文にすると forms → forming
= each new point that is reached forming a basis ...

★ forming = 「形成する」(=動詞 form の (V)ing 形)
★ a basis = 「基盤/基礎」
★ 能動態 → 日本語では受動態に変換が自然!
→ 「基盤が築かれる」「基礎が形成される」
forming a basis = 独立分詞構文「~ が基盤を形成する」 → 「基盤が築かれる」(受動態に変換)
6 for further advances ▸ for + 名詞 = 形容詞句

for further advances「さらなる進歩のための」が登場。

★ for further advances = 「さらなる進歩のための」(=形容詞句、a basis を修飾)
★ further = far「遠い」の比較級「さらなる/より一層の」
★ advances = 「進歩」(=複数形、可算名詞)

→ a basis for further advances = 「さらなる進歩のための基盤」

★ 全体の意訳:
直訳: 「達成される一つ一つの新たな段階が、さらなる進歩のための基礎を形成する」
→ 自然な日本語: 「一つ一つの新たな段階が達成されるたびに、さらなる進歩のための基盤が築かれる」
(=「達成されるたびに」と能動態 → 受動態に変換、each の個別性を「~たびに」で表現)
for further advances = 「さらなる進歩のための」(a basis を修飾)。文末分詞構文 = 主文の具体化(第49講)。
▼ ここまでの解析を1枚で見る

6つのステップで、左から右へと考えてきたことを構造図にまとめると、こうなります。色分けで見ると、骨格(メイン)と補足の関係が一気にクリアになるはず。

▼ 構造が見えたら、いよいよ訳の仕上げ

構造解析で終わると「結局この文は何を言ってるの？」が宙ぶらりんになりがち。
ここから、直訳 → 中間訳 → 完成訳と、日本語として自然な訳に磨き上げる手順を見ていきます。これも「センス」ではなく、ちゃんと段階的な手順があります。

① 直訳
科学的進歩は段階を踏んで作られ、達成される一つ一つの新たな段階がさらなる進歩のための基盤を形成する。 構造どおりの直訳。「科学的進歩」「作られ」「形成する」が硬く、英語の能動態がそのまま。
▼ 動詞の名詞形を元の動詞に戻す(make progress → 「進歩する」) make + 動詞の名詞形 = 元の動詞の動作。scientific progress is made = 「科学の進歩がなされる」。
② 中間訳
科学の進歩は段階を踏んでなされ、達成される一つ一つの新たな段階がさらなる進歩のための基盤を築く。 「科学的進歩」を「科学の進歩」に、「作られ」を「なされ」に、「形成する」を「築く」に意訳。
▼ 能動態 → 日本語では受動態 forming a basis「基盤を形成する」 → 日本語では「基盤が築かれる」と受動態に変換が自然。
③ 完成訳
科学の進歩は段階を踏んでなされ、一つ一つの新たな段階が達成されるたびにさらなる進歩のための基盤が築かれる。 能動態を受動態に変換(=「築かれる」)、each を「~たびに」と個別性で表現。これで完成。
💡 自然訳の「型」: 動詞の名詞形を見たら、元の動詞に戻してみよう

★ make の目的語に動詞の名詞形が置かれる場合、make を「~を作る」とするとおかしな日本語になります!
★ 原則: 動詞の名詞形を元の動詞に戻して訳す!

★ 《make + 動詞の名詞形》のパターン(=覚えておくと便利):
① make a choice of ~ = 「~を選ぶ」(=「~の選択をする」と訳すと硬い)
② make use of ~ = 「~を利用する」
③ make an excuse = 「言い訳をする」
④ make a mistake = 「間違いを犯す」
⑤ make a decision = 「決定する」
⑥ make a call = 「電話をする」
⑦ make a turn = 「曲がる」
⑧ make a reservation = 「予約する」
⑨ make progress = 「進歩する」

★ 応用: make 以外の動詞でも、目的語が動詞の名詞形なら、動詞に戻して訳すのが自然!
例: have a discussion「議論する」、take a look「見る」、give an answer「答える」など。

We need to make a decision soon. 私たちはすぐに決定を作る必要がある 私たちはすぐに決定する必要がある (make a decision = 「決定する」、動詞の名詞形を動詞に戻す)
Bus fares will be raised. バス料金が上がられるだろう バス料金が値上げになる (raise の用法 = 「~を上げる」、受動態を自然な日本語に)

STEP 3 — Try It Yourself —

同じ思考で、別の英文を読んでみる

読み方は「使えてナンボ」。今日身につけた思考プロセスを、別の英文で試してみましょう。答えを見る前に必ず自分で考えるのがポイント。

Q1 make + 動詞の名詞形

I need to make a phone call right now.

構造と訳は？

構造: make a phone call = 「電話をする」(=動詞の名詞形)
訳: 「私は今すぐ電話をする必要がある」

💡 make = 「~を作る」と直訳すると不自然。動詞の名詞形を元の動詞に戻す!
Q2 独立分詞構文 ─ 副詞句の名詞+(V)ing

The meeting was successful, everyone agreeing on the new plan.

everyone agreeing on the new plan の役割と訳は？

役割: 独立分詞構文(=主文と異なる主語)。everyone が agreeing の意味上の主語。
訳: 「会議は成功した、皆が新しい計画に同意して」
または: 「皆が新しい計画に同意し、会議は成功した」

💡 文末の独立分詞構文 = 主文の具体化(=「成功」の理由を説明、第49講)。
Q3 each + 単数形 vs every + 単数形

Each student received a gift.

each と every の違い、訳は？

違い:
・each + 単数形 = 「一人一人別個に」(=個別性)
・every + 単数形 = 「すべて一緒に」(=全体性)
訳: 「生徒一人一人がプレゼントを受け取った」

💡 each は個別に注目するニュアンス。「(それぞれが)別々に」の感じ。every は集合的に「全員」。
