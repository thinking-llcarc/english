この講で身につく「読み方」

第21講のテーマは 「文頭の副詞節は『本文を待つ前置き』」+「if=もし~なら/~かどうか」。
第16講・第20講で副詞節の基本を学びました。今回はその応用 ─ 文頭の副詞節+主節(=命令文)のパターン、そして2つの if の使い分けを読み解きます。
左から右に積み上げて、それぞれのカタマリを順に処理しましょう。

今日のキー:
① 文頭の副詞節は「本文を待つ前置き」(=主節を時間的・条件的に位置づける)
② 主節が命令文のパターン(=look ~ / keep ~、第12講応用)
③ if の2つの顔:「~かどうか」(=名詞節) vs 「もし~なら」(=副詞節)
④ 不定詞の副詞的用法 to see ~「~するために」(=第8講応用)
⑤ 従属接続詞 until「~するまで」(=時の副詞節)
ドアを通る時のマナーを題材に、副詞節と if の使い分けを読み解きます!

STEP 0 — First Read —

まず、自分で読んでみよう

解説を読む前に必ずやってほしいステップ。「自分はどう読んだか」を意識化することが、読み方を身につける最大の近道です。

When you pass through the door, look quickly behind you to see if anyone is following. If there is someone following, keep your hand on the door until the other person reaches it.

STOP. ここで一度立ち止まって。
① まず辞書を引かずに訳してみてください。
② 訳せなくても OK。「どこで詰まったか」を意識してください。
③ 「ここの構造がよく分からない」「この単語の品詞が判別できない」と感じたら、それがあなたの伸びしろです。
STEP 1 — Common Mistakes —

ありがちな誤読を先につぶしておく

この英文で多くの生徒がハマる罠が 6つ あります。先に見ておくことで、自分が同じ罠にハマっていないかチェックできます。

! When you pass through the door, を独立した文と思う
「(when節を主節と取って混乱)」

★ When you pass through the door, = 副詞節「ドアを通り抜けるとき」(=時、第16講・第20講応用)
★ 文頭の副詞節は「前置き」!主節を待つ役割。
★ 本問の構造: 〔副詞節〕, 〔主節=命令文〕
→ 副詞節: When you pass through the door
→ 主節: look quickly behind you ~(=命令文、Sなし)
★ pass through ~ = 「~を通り抜ける」(=群動詞)
→ pass(=自動詞「通る」)+ through(=前置詞「~を通って」)
★ 判別: 文頭の When/If/Although/Because + S V, ~ は副詞節 + 主節のパターン!

! look quickly behind you の主語を探そうとする
「(主語が誰か分からず混乱)」

★ look quickly behind you = 命令文!(=第12講・第17講応用)
★ 文頭が動詞の原形 look → 主語You は省略!
★ 意訳: 「すばやく後ろを振り返ろう」
★ V = look(=自動詞「見る」)
★ quickly = 副詞「すばやく」
★ behind you = 前置詞句「あなたの後ろを」
★ 類例:
・Look up.「上を見て」
・Look at this.「これを見て」
・Look behind you.「後ろを見て」

! to see if anyone is following の to see の役割を取り違える
「(to see を「見ること」と訳す)」

★ to see ~ = 不定詞の副詞的用法「~するために」(=目的、第8講応用)
★ 本問: look quickly behind you to see if anyone is following
→ 「~するために、すばやく後ろを見る」
→ to see は動詞 look を修飾(=なぜ見るのか?)
★ 意訳: 「~を確認するためにすばやく後ろを振り返る」
★ 類例:
・I went to the store to buy milk.「牛乳を買うためにお店に行った」
・She studied hard to pass the exam.「試験に合格するために一生懸命勉強した」
★ 判別: 動詞の後ろに to V + 動詞の修飾 → 副詞的用法「~するために」!

! if anyone is following の if を「もし~なら」と取る
「もし誰かが続いているなら~を確認する」(=if の用法を取り違える)

★ if は多義語!
(1) 名詞節「~かどうか」(=本問の1つ目)
(2) 副詞節「もし~なら」(=本問の2つ目)
★ 判別ルール:
→ 動詞の目的語の位置に来る if 節 → 名詞節「~かどうか」!
→ 文頭・文末に来る if 節 → 副詞節「もし~なら」!
★ 本問: to see if anyone is following
→ see は他動詞、後ろに目的語が必要
→ if anyone is following = see の目的語(=名詞節)
→ 「誰かが続いているかどうかを見る/確認する」
★ 類例:
・I don't know if she will come.「彼女が来るかどうか分からない」(=know の目的語、名詞節)
・If she comes, I will be happy.「彼女が来るなら、私は嬉しい」(=文頭、副詞節)
★ 本問の if は2回出てくる:
→ 1つ目: 名詞節「~かどうか」(=see の目的語)
→ 2つ目: 副詞節「もし~なら」(=次の文)
★ 同じ if でも、文中の位置と役割で意味が変わる!

! If there is someone following の構造を見落とす
「(There is構文と現在分詞の関係を見落とす)」

★ If there is someone following = 副詞節「もし~なら」(=2つ目の if)
★ 中身: There is someone following
→ There is/are ~ 構文(=第9講応用)「~がいる」
→ 本当の主語: someone「誰か」
→ following = 現在分詞「続いている」(=第12講応用、O+V-ing の応用)
★ someone following = 「続いている誰か」(=現在分詞 following が someone を修飾)
★ 意訳: 「もし続いている誰かがいれば」「もし誰かが続いているなら」
★ somebody/something + V-ing = 「~している誰か/何か」(=後置修飾、第15講応用)
★ 類例:
・There is a man waiting.「待っている男がいる」
・There is something interesting.「何か面白いことがある」

! until the other person reaches it の until を見落とす
「(until が時を表すと気づかない)」

★ until = 従属接続詞「~するまで」(=時の副詞節)
★ 本問: keep your hand on the door until the other person reaches it
→ 主節: keep your hand on the door「ドアに手を添えておこう」(=命令文)
→ 副詞節: until the other person reaches it「他の人がドアに着くまで」
★ until 節の中身:
→ S' = the other person「他の人/もう一方の人」
→ V' = reaches「着く/到達する」(=他動詞、三単現)
→ O' = it「それ(=ドア)」
★ 意訳: 「その人がドアに着くまで、ドアに手を添えておこう」
★ until = 時の副詞節を作る!
★ 類似の従属接続詞(=時を表す):
・when「~するとき」
・while「~する間」
・until「~するまで」
・before「~する前に」
・after「~した後に」

読める人は、英文を読みながら頭の中で常に何かを「考えて」います。その思考プロセスを 1語ずつ覗いてみましょう。これが英文解釈の正体です。

7つのステップで、左から右へと考えてきたことを構造図にまとめると、こうなります。色分けで見ると、骨格(メイン)と補足の関係が一気にクリアになるはず。

▼ 構造が見えたら、いよいよ訳の仕上げ

構造解析で終わると「結局この文は何を言ってるの？」が宙ぶらりんになりがち。
ここから、直訳 → 中間訳 → 完成訳と、日本語として自然な訳に磨き上げる手順を見ていきます。これも「センス」ではなく、ちゃんと段階的な手順があります。

① 直訳
あなたがドアを通り抜けるとき、誰かが続いているかどうかを見るためにすばやくあなたの後ろを見なさい。もし続いている誰かがいれば、他の人がそれに到達するまであなたの手をドアに保ちなさい。 構造どおりの直訳。「あなた」の連発、「保ちなさい」「到達する」が硬く、マナー指南の柔らかさが消える。
▼ 文頭の副詞節は「本文を待つ前置き」 When/If/Although/Because + S V, ~ のパターン!副詞節が主節を時間的・条件的に位置づける。
② 中間訳
ドアを通り抜けるとき、誰かが続いているかどうか、すばやく後ろを振り返って確認しよう。もし誰かが続いていれば、他の人がドアに着くまで、ドアに手を添えておこう。 「あなたの」を消して自然に。「保つ」を「添える」、「到達する」を「着く」に。「~しよう」で命令文を柔らかく。
▼ 主節が命令文(=第12講応用) 主語Youが省略、動詞の原形から始まる!look ~ / keep ~ = 「~しよう/~しなさい」!
③ 完成訳
ドアを通り抜けるときは、すばやく後ろを振り返って誰かが続いて来ていないか確認しよう。もし誰かが続いているなら、その人がドアに着くまで、ドアに手を添えておこう。 「~ときは」とトピック化、「続いて来ていないか」と自然な日本語に。マナー指南の柔らかさが伝わる。これで完成!
💡 自然訳の「型」: 文頭の副詞節 = 前置き ─ 主節を待つ姿勢で読む

★ 第21講で身につけてほしい「前置き」を待つ姿勢を伝えます。

★ 英文には、しばしば文頭に副詞節が来るパターンがあります。これは日本語の感覚と似ていて、「~するとき/もし~なら/~なので」のように、本題の前に状況を設定する役割!

★ 文頭の副詞節を導く接続詞:
・When ~ ,「~するとき」(=時)
・If ~ ,「もし~なら」(=条件)
・Although ~ ,「~だけれども」(=譲歩)
・Because ~ ,「~なので」(=理由)
・While ~ ,「~する間」(=時)
・After ~ ,「~した後に」(=時)
・Before ~ ,「~する前に」(=時)

★ 読み方のコツ:
(1) 文頭の接続詞 + S V を見たら、「これは前置きだ」と認識
(2) コンマ までは主節を待つ姿勢で読む
(3) コンマの後ろに主節が来る ─ そこが本題!

★ 本問の場合:
★ When you pass through the door, look quickly behind you ~
(1) 前置き: 「ドアを通り抜けるとき」(=時の状況設定)
(2) 本題: 「すばやく後ろを振り返ろう」(=指示)

★ もうひとつ大事なポイント ─ if の2つの顔:

★ if は文中の位置と役割で意味が変わる多義語!

★ (1) 名詞節「~かどうか」:
→ 動詞の目的語の位置に来る
例: I don't know if she will come.「彼女が来るかどうか分からない」(=know の目的語)
例: to see if anyone is following「誰かが続いているかどうかを確認する」(=本問の1つ目)

★ (2) 副詞節「もし~なら」:
→ 文頭・文末に来る
例: If she comes, I will be happy.「もし彼女が来るなら、私は嬉しい」
例: If there is someone following, keep ~「もし誰かが続いていれば、~しよう」(=本問の2つ目)

★ 判別ルール: if が動詞の目的語の位置 → 名詞節「~かどうか」!文頭・文末 → 副詞節「もし~なら」!

★ 本問では同じ if が2回出るのも面白いポイント!
→ 1つ目: to see if ~(=see の目的語、名詞節)
→ 2つ目: If there is ~(=文頭、副詞節)

★ 同じ単語でも、文中の役割で意味が変わる ─ これが英語の面白いところ!
★ 形だけでなく、その単語が何の役割をしているかを見抜く目が大事!

★ これからの60講で、副詞節 + 主節のパターンは頻繁に登場します。「文頭の副詞節 = 前置き」と認識する習慣を!

When it rains, take an umbrella. (When節を独立した文と思う) 雨が降るとき、傘を持って行こう (前置き「雨が降るとき」+ 命令文「傘を持っていこう」)
I want to know if he is coming. もし彼が来るなら、私は知りたい (if の用法を取り違える) 彼が来るかどうか知りたい (if が know の目的語=名詞節「~かどうか」)
If he is coming, I will wait. 彼が来るかどうか、私は待つ もし彼が来るなら、私は待つ (if が文頭=副詞節「もし~なら」)

1 左から右へ、1語ずつ品詞と役割を確定する
→

STEP 3 — Try It Yourself —

同じ思考で、別の英文を読んでみる

読み方は「使えてナンボ」。今日身につけた思考プロセスを、別の英文で試してみましょう。答えを見る前に必ず自分で考えるのがポイント。
知識として「覚える」のではなく、手を動かして「使える」状態に持っていきます。

Q1 文頭の副詞節 + 命令文

When you finish your homework, you can play.

副詞節と主節の関係は？

分析: 文頭の副詞節 + 主節!
・副詞節: When you finish your homework「宿題が終わったら」(=時、前置き)
・主節: you can play「遊んでよい」(=本題)
訳: 「宿題が終わったら、遊んでいいよ」

💡 文頭の When 節は前置き!主節を時間的に位置づける!
Q2 if = 名詞節「~かどうか」

I want to know if she likes me.

if の用法と訳は？

分析: if は動詞 know の目的語の位置!
→ 名詞節「~かどうか」!
訳: 「私は彼女が私を好きかどうかを知りたい」

💡 動詞の目的語の if = 名詞節「~かどうか」!文頭の if(=副詞節「もし~なら」)とは別!
Q3 until 副詞節 ─ ~するまで

Wait here until I come back.

until 節の役割と訳は？

分析: until S V = 副詞節「~するまで」(=時)
・主節: Wait here「ここで待って」(=命令文)
・until 節: until I come back「私が戻るまで」
訳: 「私が戻るまで、ここで待って」

💡 until は時の副詞節を作る!when, while, before, after などと同類!
STEP 4 — Your Reading Algorithm —

これからの英文に使える「思考フロー」

最後に、今日の学びを初見の英文に使える型として整理しておきます。これを毎回頭の中で回せば、確実に読める英文が増えていきます。

1
文頭の副詞節は「本文を待つ前置き」
When/If/Although/Because + S V, ~ のパターン!主節を時間的・条件的に位置づける。
2
コンマまでは「前置き」、コンマの後ろが「本題」
前置きを読み終えたら、主節を待つ姿勢で読み進める!
3
主節が命令文のパターン(=第12講応用)
主語Youが省略、動詞の原形!look ~ / keep ~ / wait ~ 等。
4
if の2つの顔
名詞節「~かどうか」(=動詞の目的語) vs 副詞節「もし~なら」(=文頭・文末)。位置で判別!
5
名詞節 if: 動詞 know/see/wonder/ask 等の後ろ
動詞の目的語の位置 → 「~かどうか」!
6
副詞節 if: 文頭・文末
主節と並列で条件を示す → 「もし~なら」!
7
従属接続詞 until「~するまで」(=時)
when, while, until, before, after 等、時の副詞節を作る接続詞!
8
後置修飾の現在分詞: someone following「続いている誰か」
名詞 + V-ing で「~している名詞」(=第15講応用)。
