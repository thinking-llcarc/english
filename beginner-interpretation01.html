★ 全60講シリーズの記念すべき第1講!★
たった2語の英文 Time flies.。
シンプルすぎて拍子抜けかもしれません。でも、この一文には英文を読むうえでこれから何度も使う考え方がぎっしり詰まっています。

今日のキー:
① 英文には必ず「主語」と「動詞」がある(=ここから読解は始まる)
② 動詞は「何を求めているか」を語る(=後ろに目的語を欲しがる動詞もあれば、何もいらない動詞もある)
③ 動詞の後ろに何もない → 動詞単独で完結していると判断する
④ 同じ単語でも、文中の位置で品詞が変わる(=flies は動詞か名詞か?)
⑤ 慣用表現「Time flies.」= 「光陰矢の如し」(=ことわざとして対応する日本語を当てる)
シンプルに見えて、英文を読むときの核となる姿勢がぎっしり詰まった一文です!

1
主語と動詞を最初に押さえる(=英文を読むスタート地点)を身につけます。
2
動詞が後ろに何を求めているか(=目的語が要る/要らない)を見抜きます。
3
同じ単語でも文中の位置で品詞が変わる(=多義性の見抜き方)を理解します。
STEP 0 — First Read —

まず、自分で読んでみよう

解説を読む前に必ずやってほしいステップ。「自分はどう読んだか」を意識化することが、読み方を身につける最大の近道です。

Time flies.

STOP. ここで一度立ち止まって。
① まず辞書を引かずに訳してみてください。
② 訳せなくても OK。「どこで詰まったか」を意識してください。
③ 「ここの構造がよく分からない」「この単語の品詞が判別できない」と感じたら、それがあなたの伸びしろです。
STEP 1 — Common Mistakes —

ありがちな誤読を先につぶしておく

この英文で多くの生徒がハマる罠が 6つ あります。先に見ておくことで、自分が同じ罠にハマっていないかチェックできます。

! Time を「タイム」とカタカナで訳す
「タイムは飛ぶ~」

★ Time = 「時/時間」!
★ カタカナ「タイム」を避ける!
★ Time は無冠詞(=a/an/the が付いていない)
→ これは抽象的・一般的な「時」全般を指す!
→ もし a time なら「ある(特定の)時間」、the time なら「その時間」となる。
★ 本問の Time = 「時」(=哲学的な意味合い、抽象名詞)
★ 類例:
・Time is money.「時は金なり」
・Time waits for no one.「時は誰も待たない」

! flies を「ハエ」と名詞で読む
「時のハエ~」(意味不明!)

★ flies は多義語!
(1) 動詞 fly の三人称単数現在形「飛ぶ」
(2) 名詞 fly の複数形「ハエ(複数)」
★ 判別ルール: 主語の後ろに動詞が必要!
→ 主語 Time の後ろは動詞でなければならない!
→ よって、flies は(1) 動詞「飛ぶ」!
★ Time flies.(=主語+動詞)
★ 主語が三人称単数(=Time)なので、動詞に-(e)s がつく!
→ fly + s = flies(=y → ies)
★ もし「ハエ」と読むと: 「Time flies」全体が名詞句のみになり、動詞が存在しない → 文として成立しない!
★ 原則: 英文には必ず動詞が存在する!

! 「光陰矢の如し」を知らずに直訳のみで終わる
「時は飛ぶ。」(=直訳のみで意味不明)

★ Time flies. は英語の慣用表現/格言!
★ 直訳:「時は飛ぶ」
★ 意訳:「時は飛ぶように過ぎる」「時の経つのは早い」「時間が経つのはあっという間だ」
★ 日本のことわざに対応:「光陰矢の如し(こういんやのごとし)」
→ 「光陰」= 月日、時の流れ
→ 「矢の如し」= 矢のように(=速い)
→ つまり「時の流れは矢のように速い」
★ 正式な訳例:「光陰矢の如し。(時は飛ぶように過ぎる。)」
★ 類例(=英語の格言):
・Time is money.「時は金なり」
・Time and tide wait for no man.「歳月人を待たず」
・Time flies when you're having fun.「楽しい時は時間が早く過ぎる」

! flies の後に目的語を探そうとする
「(flies の後に何が来るのか分からず混乱)」

★ flies(=動詞 fly「飛ぶ」)は自動詞!
★ 自動詞 = 目的語を必要としない動詞
→ flies 単独で完結!
→ 後ろに目的語は不要!
★ 判別ルール: 動詞の後ろに目的語がない → 自動詞!
★ 第1文型 SV: 主語+自動詞のみで完成する文型
→ Time flies. = S(Time) + V(flies)
★ 類例(=自動詞のみで完結する文):
・Birds fly.「鳥は飛ぶ」
・Babies cry.「赤ちゃんは泣く」
・Dogs bark.「犬は吠える」
・Time passes.「時は過ぎる」

! 英文に S と V が必ずあることを意識しない
「(主語と動詞を確認せず適当に訳す)」

★ 英文解釈の大原則: 英文には必ず S(主語)と V(動詞)が存在する!
★ これは第1講で身につけるべき最重要の姿勢!
★ 英文を読むとき、まず「主語はどれ?動詞はどれ?」と探す癖をつける!
★ 本問の手順:
(1) Time flies. を見る
(2) 「主語と動詞はどれ?」と考える
(3) Time(=名詞、無冠詞)→ 主語(S)!
(4) flies(=動詞、三単現の-s)→ 動詞(V)!
(5) 後ろに何もない → 第1文型 SV!
★ これからの60講で何度も繰り返し:
「動詞からその前後の役割を判断していく」 = 入門60の基本姿勢!

! 「光陰矢の如し」の意味を取り違える
「(光陰矢の如しの意味が分からない)」

★ 「光陰矢の如し(こういんやのごとし)」の意味:
→ 「光陰」= 月日/時の流れ(=日光と月影、転じて「時間」)
→ 「矢の如し」= 矢のように(速い)
→ つまり 「時の流れは矢のように速い」!
★ 使い方:
・「光陰矢の如し、もう年末だ」
・「青春は光陰矢の如しと言うが、本当だ」
★ 哲学的含意: 時間は瞬く間に過ぎ去る → 時間を大切に!
★ 英語の Time flies. も同じ哲学的含意をもつ!
★ 類似表現:
・Time waits for no one.「時は誰も待たない」
・Carpe diem.(=ラテン語)「今を生きよ/今日を捕まえよ」

STEP 2 — Read Along —

左から右へ、頭の中の実況中継

読める人は、英文を読みながら頭の中で常に何かを「考えて」います。その思考プロセスを 1語ずつ覗いてみましょう。これが英文解釈の正体です。

1 Time ▸ 主語 ─ 「時」(=抽象名詞、無冠詞)

主語 Time「時」が登場。

★ S(主語)= Time「時/時間」
★ カタカナ「タイム」を避ける!

★ Time は無冠詞(=a/an/the が付いていない)!
→ これは抽象的・一般的な「時」全般を指す!
→ 哲学的・普遍的な意味合い

★ もし冠詞があれば:
・a time = 「ある(特定の)時間」
・the time = 「その時間」
・Time(無冠詞)= 「時間というもの」(=抽象)

★ 類例(=無冠詞の抽象名詞):
・Love is patient.「愛は寛容である」
・Knowledge is power.「知識は力である」
・Music is universal.「音楽は普遍的である」

→ 後ろに動詞が来るはず!(=英文には必ずSとVが存在!)
S = Time「時」(=抽象名詞、無冠詞、一般的な意味)
2 flies. ▸ 動詞 ─ 「飛ぶ」(=自動詞、三単現の-s)

動詞 flies「飛ぶ」が登場。

★ flies は多義語!
(1) 動詞 fly の三人称単数現在形「飛ぶ」
(2) 名詞 fly の複数形「ハエ(複数)」

★ 判別ルール: 主語の後ろに動詞が必要!
→ 主語 Time の後ろは動詞でなければならない!
→ よって、flies は(1) 動詞「飛ぶ」!

★ 主語が三人称単数(=Time)なので、動詞に-(e)s がつく!
→ fly + s = flies(=y → ies のスペル変化)

★ V(動詞)= flies「飛ぶ」(=自動詞)

★ 自動詞と他動詞の区別:
・自動詞 = 目的語を必要としない動詞
・他動詞 = 目的語を必要とする動詞

★ 判別ルール: 動詞の後ろに目的語がない → 自動詞!
→ 本問は flies の後ろに何もない(=ピリオドのみ)
→ よって、flies は自動詞!

★ 第1文型 SV の完成!
→ Time flies. = S(Time) + V(flies)
→ これが英語で最もシンプルな文型!

★ 意訳:
直訳: 「時は飛ぶ」
→ 慣用表現: 「光陰矢の如し」(=日本のことわざ)
→ 意訳: 「時は飛ぶように過ぎる」「時の経つのは早い」
V = flies「飛ぶ」(=自動詞、目的語不要)。S(Time) + V(flies) = 第1文型!「光陰矢の如し」
▼ ここまでの解析を1枚で見る

2つのステップで、左から右へと考えてきたことを構造図にまとめると、こうなります。色分けで見ると、骨格(メイン)と補足の関係が一気にクリアになるはず。

TimeS fliesV ..

骨格 = S V.(第1文型:主語+自動詞のみで完成する最もシンプルな文型)
▼ 構造が見えたら、いよいよ訳の仕上げ

構造解析で終わると「結局この文は何を言ってるの？」が宙ぶらりんになりがち。
ここから、直訳 → 中間訳 → 完成訳と、日本語として自然な訳に磨き上げる手順を見ていきます。これも「センス」ではなく、ちゃんと段階的な手順があります。

① 直訳
時は飛ぶ。 構造どおりの直訳。意味は通るが、英語の慣用表現としてのニュアンスが伝わらない。
▼ カタカナを避ける: Time = 「時」(=「タイム」ではない) Time は無冠詞 → 抽象的・一般的な「時」全般を指す!哲学的・普遍的な意味合い。
② 中間訳
時は飛ぶように過ぎる。 「飛ぶ」の意味を補って自然な日本語に。「時間がどんどん過ぎていく」というニュアンスが見えてくる。
▼ 多義語の判別: flies = 動詞「飛ぶ」(=「ハエ」ではない) 主語の後ろは動詞でなければならない!三人称単数現在形 -s がついた fly = 「飛ぶ」!
③ 完成訳
光陰矢の如し。(時は飛ぶように過ぎる。) 日本のことわざ「光陰矢の如し」を当てると、英語の慣用表現としての格言性が完璧に伝わる。これで完成!
💡 自然訳の「型」: 動詞中心で英文を読む ─ 60講を貫く姿勢

★ 第1講で身につけてほしい最も大切な姿勢を伝えます。

★ 英語を読むとき、多くの人は「左から右へ単語を順に訳す」やり方をしがちです。でも、これだと長い文や複雑な文で必ず迷子になります。

★ 代わりに身につけてほしいのが 「動詞中心で文を見る」という姿勢。

★ 動詞は文の心臓部です。動詞が:
・「自分一人で完結できる」と言っているのか
・「後ろに目的語が欲しい」と言っているのか
・「主語とイコールの説明が欲しい」と言っているのか

これを見抜けば、文の構造はほぼ自動的に決まります。

★ 本問の flies はどう言っているか?
→ 後ろに何もない、ピリオドだけ
→ 「自分一人で完結する」と動詞が言っている
→ つまり「飛ぶ」という動作だけで意味が完成

★ 動詞の「求めるもの」のパターンは実は限られていて、慣れると瞬時に見抜けるようになります。これからの60講では、いろいろな動詞が登場するたびに「この動詞は後ろに何を求めているか?」と意識的に問いかけてみてください。

★ 類例:
・Birds fly.「鳥は飛ぶ」(=fly は何も求めていない)
・She smiled.「彼女は微笑んだ」(=smile は何も求めていない)
・He reads books.「彼は本を読む」(=read は何を読むかを求める → 目的語 books)
・She is kind.「彼女は親切だ」(=is は主語の説明を求める → kind)

★ 「動詞からその前後の役割を判断していく」 ── これが入門60を貫く基本姿勢です!

Time flies. 時のハエ (flies = 名詞「ハエ」と誤読) 光陰矢の如し (flies = 動詞「飛ぶ」、第1文型 SV)
Birds sing. 鳥たちは歌(名詞) 鳥は鳴く (sing = 動詞、自動詞のみで完結 = 第1文型 SV)
She is kind. 彼女は親切な(意味不明) 彼女は親切だ (She = kind の関係 = 第2文型 SVC、kind は形容詞の補語)
✓ STEP 2 のまとめ ─ 「構造」から「意味」までの一直線
1 左から右へ、1語ずつ品詞と役割を確定する
→
2 骨格と修飾語(M)を色分けで把握する
→
3 直訳 → 中間訳 → 完成訳と日本語に仕上げる

この一連の流れが、英文解釈の全プロセスです。「構造が見えた」だけで満足せず、必ず最後の「自然な訳」まで仕上げる習慣を、今日からつけていきましょう。

STEP 3 — Try It Yourself —

同じ思考で、別の英文を読んでみる

読み方は「使えてナンボ」。今日身につけた思考プロセスを、別の英文で試してみましょう。答えを見る前に必ず自分で考えるのがポイント。
知識として「覚える」のではなく、手を動かして「使える」状態に持っていきます。

Q1 第1文型 SV

The sun rises.

主語と動詞は？文型は？

分析:
・S(主語)= The sun「太陽」
・V(動詞)= rises「昇る」(=自動詞)
→ 動詞の後ろに何もない → 第1文型 SV!
訳: 「太陽は昇る」

💡 自動詞 rise「昇る」(過去形 rose、過去分詞 risen)。他動詞 raise「~を上げる」と区別!
Q2 自動詞 vs 他動詞の判別

(1) Babies cry. / (2) I read a book.

2つの動詞は自動詞？他動詞？

(1) cry: 動詞の後ろに目的語がない → 自動詞!
→ S(Babies)+V(cry)= 第1文型 SV
→ 訳: 「赤ちゃんは泣く」
(2) read: 動詞の後ろに目的語 a book がある → 他動詞!
→ S(I)+V(read)+O(a book)= 第3文型 SVO
→ 訳: 「私は本を読む」

💡 動詞の後ろに目的語があるかどうかで自動詞/他動詞を判別!
Q3 flies の多義性

(1) Time flies. / (2) I see flies.

2つの flies の品詞と意味は？

(1): Time(=主語)+ flies(=動詞「飛ぶ」)
→ 第1文型 SV「時は飛ぶ」(=光陰矢の如し)
(2): I(=主語)+ see(=動詞)+ flies(=名詞「ハエ(複数)」、目的語)
→ 第3文型 SVO「私はハエを見る」

💡 同じ単語でも文中の位置と役割で品詞・意味が変わる!主語の後ろなら動詞、目的語の位置なら名詞!
