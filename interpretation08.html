8
▶ 接続詞ほか

if SV は二通りの可能性 ─ 「もし」と「〜かどうか」を見極める

Online Cram School THINKING
▶ THIS LESSON

この講で身につく「読み方」

今日は if がテーマ。if = 「もし」と単純に覚えていると、今日の英文では意味が通らなくなります。
実は if SV には2つの可能性があって、それぞれ「もし〜なら」(副詞節)と「〜かどうか」(名詞節)に分かれます。判別を間違えると、文の意味が180度ズレることも。
この見極めができるようになれば、if を含む英文の読解力が一段上がります。

1
if SV の2つの可能性(「もし〜なら」/「〜かどうか」)を見極める眼が育ちます。
2
動詞の後ろの if SV は名詞節(=動詞の目的語)になる、というルールが分かります。
3
be at a loss for ~のような《be動詞+前置詞句》のイディオムを見抜く方法が分かります。
STEP 0 — First Read —

まず、自分で読んでみよう

解説を読む前に必ずやってほしいステップ。「自分はどう読んだか」を意識化することが、読み方を身につける最大の近道です。

When I asked the college student if he could talk about Japanese literature, he was at a loss for an answer.

STOP. ここで一度立ち止まって。
① まず辞書を引かずに訳してみてください。
② 訳せなくても OK。「どこで詰まったか」を意識してください。
③ 「ここの構造がよく分からない」「この単語の品詞が判別できない」と感じたら、それがあなたの伸びしろです。
STEP 1 — Common Mistakes —

ありがちな誤読を先につぶしておく

この英文で多くの生徒がハマる罠が 4つ あります。先に見ておくことで、自分が同じ罠にハマっていないかチェックできます。

! if を機械的に「もし」と訳す
「もし彼が日本文学について語れるなら、その大学生に尋ねたとき、彼は答えに詰まった」

if = 「もし」と覚えていると、こう読みたくなります。でも、これだと意味が通らない。「もし語れるなら、答えに詰まった」って何のこっちゃ?
このように意味が破綻したら、もう一つの可能性 if = 「〜かどうか」を試してみてください。「日本文学について語れるかどうかを尋ねた」と読むと一気に意味が通ります。

! be at a loss を「答えを失った」と誤訳
「彼は答えを失った」

be at a loss for ~ は熟語で「〜を求めて途方に暮れる」「どう答えたらいいか困っていた」「答えに窮した」が正しい訳。
「答えを失った」は誤訳。at a loss の at は「点」を表し、「途方に暮れる状態の点にいる」イメージ。at war / at peace / at work / at home なども同じく「ある状態の極点」を示します。

! When I asked の節がどこまで続くのか分からない
「いつ私は尋ねたか…誰に？何を？(構造が把握できない)」

When SV「〜したとき」は副詞節。どこまでがwhen節なのかを正確に区切ることが、文全体の構造把握の第一歩。
今回の when 節は When I asked the college student if he could talk about Japanese literature まで(=長い!)。コンマで区切られるところまでが副詞節。

! at a loss for an answer を副詞句と誤読
「彼は (どこか) で答えのために なんとか…」

at a loss for an answer は be 動詞の補語(形容詞句として働く)。
《be 動詞 + 前置詞 + 名詞》の形は、形容詞句(補語C)になることが多いんです。Tigers are in danger of extinction.「トラは絶滅の危機にある」も同じパターン。

STEP 2 — Read Along —

左から右へ、頭の中の実況中継

読める人は、英文を読みながら頭の中で常に何かを「考えて」います。その思考プロセスを 1語ずつ覗いてみましょう。これが英文解釈の正体です。

1 When ▸ 副詞節のサイン

文頭から When。これは接続詞「〜するとき」。後ろにSVが続いて、副詞節を作ります。

When SV = 副詞節「~するとき」。
→ これは主節を修飾する補足情報。本体の文(主節)はこの後ろにある。
→ どこまでがwhen節なのかを正確に把握することが大事。普通はカンマで区切られる。
when節スタート。どこまで続くか見ながら読み進める。
2 I asked the college student ▸ SVO の中身

when節の中身: I asked the college student「私はその大学生に尋ねた」。

ask は他動詞「〜に尋ねる」。
→ 後ろに「何を尋ねたのか」(=もう一つの目的語)が来るはずと予測。
→ ask + 人 + 物(=人に物を尋ねる)の第4文型かもしれない。
when節内: S' = I / V' = asked / O₁' = the college student。「何を」尋ねたかは次へ。
3 if ▸ これは「もし」？「〜かどうか」？

来ました if。ここが今日の最大のポイントです。

if SV には2つの可能性:
① 副詞節「もし〜なら」
② 名詞節「〜かどうか(ということ)」

判別法: if の位置を見る!
→ 動詞の後ろ(動詞の目的語の位置)にあれば → 名詞節(=「〜かどうか」)
→ 文頭(If ~)や文中で動詞の目的語以外の位置 → 副詞節(=「もし〜なら」)

今回: asked(他動詞)の後ろにある → 名詞節!「〜かどうか」と読む。
→ asked the college student if SV = 「大学生に、SVかどうかを尋ねた」(SV4文型のO₂が if節)
if = 名詞節を導く接続詞「〜かどうか」(asked の目的語O₂)
4 he could talk about Japanese literature ▸ if節の中身

if節の中身: he could talk about Japanese literature「彼が日本文学について話せる(かどうか)」。

talk about ~ = 「〜について話す」。talk(自動詞)+ 前置詞 about + 名詞。
→ 第1講で出てきた群動詞のような形。about は前置詞(後ろに名詞 Japanese literature がある)。
if節 = if he could talk about Japanese literature「彼が日本文学について語れるかどうか」
5 , he was ▸ コンマで主節スタート

コンマでwhen節が終わり、いよいよ主節が始まります。he was「彼は〜だった」。

S = he / V = was → 後ろに補語(C)が来るはず
6 at a loss ▸ be動詞 + 前置詞句 = 補語C

at a loss「途方に暮れて」が登場。was の補語(C)です。

《be 動詞 + 前置詞 + 名詞》の形は、形容詞句として補語(C)になることがよくある。
→ at a loss = 「途方に暮れた状態で」
→ at は「点」を示す前置詞。「途方に暮れるという状態の点にいる」イメージ。
→ 同じパターン: at war「戦争中で」/ at peace「平和に」/ at home「在宅で」など、ある状態の極点を表す。
C = at a loss「途方に暮れた状態で」
7 for an answer ▸ forで修飾

for an answer「答えを求めて」が登場。at a loss を修飾する形容詞句として読みます。

be at a loss for ~ = 「〜を求めて途方に暮れる」(=どう〜したらよいか分からない)
→ 全体で1つの熟語として覚えておくと良い。
→ 訳: 「答えに窮していた」「どう答えたらいいか困っていた」など。
形容詞句 〈for an answer〉が at a loss を修飾。「答えを求めて途方に暮れた」=「答えに詰まった」
▼ ここまでの解析を1枚で見る

7つのステップで、左から右へと考えてきたことを構造図にまとめると、こうなります。色分けで見ると、骨格(メイン)と補足の関係が一気にクリアになるはず。

When接 IS' askedV' the college studentO₁' [if he could talk about Japanese literature]O₂' heS wasV at a lossC for an answerM.

骨格 = [副詞節 When S'V'O₁'O₂'], S V C(when節の中で、if節がO₂'(動詞askedの目的語)になる名詞節)
▼ 構造が見えたら、いよいよ訳の仕上げ

構造解析で終わると「結局この文は何を言ってるの？」が宙ぶらりんになりがち。
ここから、直訳 → 中間訳 → 完成訳と、日本語として自然な訳に磨き上げる手順を見ていきます。これも「センス」ではなく、ちゃんと段階的な手順があります。

① 直訳
私がその大学生に、彼が日本文学について話せるかどうかを尋ねたとき、彼は答えを求めて途方に暮れた状態だった。 構造どおりの直訳。意味は通るが、日本語として硬い。
▼ be at a loss for an answer を「答えに詰まった」と意訳 直訳の「答えを求めて途方に暮れた状態だった」は冗長。「答えに詰まった」「答えに窮した」と短くまとめると自然。
② 中間訳
私がその大学生に、日本文学について話せるかどうか尋ねたとき、彼は答えに詰まった。 「彼が」は文脈で省略可。「途方に暮れた状態だった」を「答えに詰まった」と意訳。
▼ 主語の「私」を省略(日本語の特徴) 日本語は主語を頻繁に省略する言語。「私が尋ねたとき」より「尋ねたとき」の方が自然な日本語の流れに。
③ 完成訳
その大学生に、日本文学について語れるかどうか尋ねたとき、彼は答えに詰まった。 「私が」を省略(主語の重複を避け、より自然に)。「話せる」→「語れる」で文学を語る雰囲気を表現。これで完成。
💡 自然訳の「型」: if SV の「もし」と「〜かどうか」の見分け方

if SV を見たら、必ず2つの可能性を検証する習慣をつけましょう。判別の決定打は「if節の位置」。動詞の目的語の位置にあれば名詞節「〜かどうか」、それ以外は副詞節「もし〜なら」。
意味で確認するのも有効: ① 「もし〜なら」で読んで意味が通る? ② ダメなら「〜かどうか」を試す。

I asked her if she understood me. もし彼女が理解しているなら、私は彼女に尋ねた 私の言うことを理解しているかどうかを彼女に尋ねた (asked の目的語 = 名詞節)
I told her to raise her hand if she understood me. 私が彼女に理解しているかどうかを話した 私の言うことを理解しているなら手を挙げるように彼女に言った (raise を修飾する副詞節)
If it rains tomorrow, we will cancel the picnic. 雨かどうか、ピクニックをキャンセルする もし明日雨が降れば、ピクニックをキャンセルする (文頭のIf節 = 副詞節)
✓ STEP 2 のまとめ ─ 「構造」から「意味」までの一直線
1 左から右へ、1語ずつ品詞と役割を確定する
→
2 骨格と修飾語(M)を色分けで把握する
→
3 直訳 → 中間訳 → 完成訳と日本語に仕上げる

この一連の流れが、英文解釈の全プロセスです。「構造が見えた」だけで満足せず、必ず最後の「自然な訳」まで仕上げる習慣を、今日からつけていきましょう。

STEP 3 — Try It Yourself —

同じ思考で、別の英文を読んでみる

読み方は「使えてナンボ」。今日身につけた思考プロセスを、別の英文で試してみましょう。答えを見る前に必ず自分で考えるのがポイント。
知識として「覚える」のではなく、手を動かして「使える」状態に持っていきます。

Q1 if SV の働きを判別

I wonder if she will come to the party tonight.

この if SV は名詞節？副詞節？　訳は？

判別: wonder(他動詞)の後ろにある → 名詞節(=動詞の目的語)
意味: 「〜かどうか」
訳: 「彼女が今夜パーティーに来るかどうか気になる」

💡 wonder if SV「〜かどうかと思う」は超頻出パターン。同様に ask if / know if / wonder if など、多くの動詞の目的語にif節を取る。
Q2 副詞節の if

If you study hard, you will pass the exam.

この if SV は名詞節？副詞節？　訳は？

判別: 文頭の If → 副詞節(=主節を修飾)
意味: 「もし〜なら」
訳: 「もし一生懸命勉強すれば、試験に合格するだろう」

💡 文頭の If ~ は自動的に副詞節。「〜かどうか」になることはない(動詞の目的語の位置に来ないから)。
Q3 be 動詞 + 前置詞 + 名詞 の構造

Many endangered species are in danger of extinction.

are in danger of extinction の構造は？　補語Cはどれ？

構造: are(be動詞)+ in danger(前置詞句)= SVCの第2文型。in danger が補語Cの形容詞句として働く。
修飾: of extinction「絶滅の」が danger を修飾。
訳: 「多くの絶滅危惧種は絶滅の危機にある」

💡 《be 動詞 + 前置詞 + 名詞》= 形容詞句の補語C、というパターンは超頻出。at a loss / in trouble / on time / out of order なども同様。
STEP 4 — Your Reading Algorithm —

これからの英文に使える「思考フロー」

最後に、今日の学びを初見の英文に使える型として整理しておきます。これを毎回頭の中で回せば、確実に読める英文が増えていきます。

1
if SV を見たら2つの可能性(名詞節 or 副詞節)を検証
機械的に「もし」と訳さず、必ず両方の可能性を考える習慣をつける。
2
動詞の目的語の位置の if SV は名詞節「〜かどうか」
ask / wonder / know / find out など、目的語にif節を取る動詞は多い。
3
文頭や、目的語以外の位置の if SV は副詞節「もし〜なら」
文頭の If ~ は自動的に副詞節。これで悩む必要なし。
4
《be 動詞 + 前置詞 + 名詞》は形容詞句の補語C
at a loss / in danger / on time など、ある状態を表す慣用表現になる。
5
前置詞 at は「点」を表す
at a loss / at war / at peace / at home / at work など、ある状態の極点を表す。
6
直訳の不自然な日本語は意訳でスムーズに
be at a loss for an answer「答えを求めて途方に暮れた」→「答えに詰まった」など。
