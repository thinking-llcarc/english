▶ There 構文

「~がある」の文で本当の主語はどこにあるか

Online Cram School THINKING
▶ THIS LESSON

この講で身につく「読み方」

第9講のテーマは 「There is/are ~ 構文」。
文頭の There を見て「そこには~」と訳してしまうのは、初学者にとても多い間違い。実はこの There は主語ではないのです。

今日のキー:
① There is/are ~ = 「~がある/いる」(=存在を示す慣用)
② There は形式上の主語、本当の主語は be の後ろの名詞
③ be 動詞は本当の主語に合わせる(=単数なら is、複数なら are)
④ Some ~, others ~ = 「~もあれば、~もある」(=対比、第2講の応用)
⑤ 2文の関係:1文目で全体を述べ、2文目で具体例を列挙
世界遺産を題材に、There 構文の正体を見抜きます!

1
There is/are ~「~がある」(=存在を示す慣用)を覚えます。
2
本当の主語は be の後ろの名詞と理解します。
3
Some ~, others ~「~もあれば~もある」(=対比)を覚えます。
STEP 0 — First Read —

まず、自分で読んでみよう

解説を読む前に必ずやってほしいステップ。「自分はどう読んだか」を意識化することが、読み方を身につける最大の近道です。

There are different kinds of World Heritage Sites. Some have natural beauty, and others have important history.

STOP. ここで一度立ち止まって。
① まず辞書を引かずに訳してみてください。
② 訳せなくても OK。「どこで詰まったか」を意識してください。
③ 「ここの構造がよく分からない」「この単語の品詞が判別できない」と感じたら、それがあなたの伸びしろです。
STEP 1 — Common Mistakes —

ありがちな誤読を先につぶしておく

この英文で多くの生徒がハマる罠が 6つ あります。先に見ておくことで、自分が同じ罠にハマっていないかチェックできます。

! There を「そこに(は)」と場所として訳す
「そこにはさまざまな種類の世界遺産がある」

★ 大原則: There is/are ~ の There は場所を示すThereではない!
★ これは形式的な主語(=飾り)!
★ 本当の主語は be の後ろの名詞!
★ 本問: There are different kinds of World Heritage Sites.
→ 形式上の主語 = There
→ 本当の主語 = different kinds of World Heritage Sites「さまざまな種類の世界遺産」
★ 訳: 「世界遺産にはさまざまな種類がある」(=「~がある」と訳す)
★ 「そこには」は「(その場所に)」のニュアンスを生んでしまうので避ける!
★ 場所のThere(=「そこに」)は別物:
例: She is over there.「彼女はあそこにいる」(=場所のthere、文末や強調位置)
★ There is/are ~ 構文の There は文頭で固定!

! are の主語を There と思い、単複を間違える
「(なぜ are なのか分からない)」

★ be動詞は「本当の主語」に合わせる!
★ 本当の主語が単数なら → There is ~
★ 本当の主語が複数なら → There are ~
★ 本問: 本当の主語は different kinds(=複数) → are!
★ 例:
・There is a book on the desk.「机の上に本がある」(=主語 a book は単数)
・There are books on the desk.「机の上に本がある(複数)」(=主語 books は複数)
★ There はあくまで飾りの主語。本物の主語(=後ろの名詞)に注目!

! different kinds of ~ を「異なる種類の~」と直訳
「異なる種類の世界遺産~」(=不自然)

★ different kinds of ~ = 「さまざまな種類の~」「いろいろな種類の~」(=慣用)
★ different = 「異なる/さまざまな」(=多様性を示す)
★ kinds of ~ = 「~の種類」(=複数形)
★ 注意: different を「異なる」と直訳すると硬い!ここでは「さまざまな」「いろいろな」が自然!
★ 類例:
・different kinds of music「いろいろな種類の音楽」
・different countries「さまざまな国々」
・different opinions「さまざまな意見」
★ World Heritage Sites = 「世界遺産」(=固有名詞、複数形)

! Some have ~, and others have ~ の Some と others を「いくつか」「他のいくつか」と訳す
「いくつかは~を持っている、そして他のいくつかは~」(=不自然)

★ Some ~, others ~ = 「~もあれば、~もある」(=対比、第2講応用)
★ Some = 代名詞「(あるものは~/ある人々は~)」
★ others = 代名詞「(他のものは~/他の人々は~)」(=otherの複数形)
★ 直訳「いくつかは~」は不自然!
★ 本問の文脈: 前文の World Heritage Sites(=世界遺産)を指す!
→ Some = 「(世界遺産の)いくつかは」「~を持つもの(=場所)もある」
→ others = 「(他の世界遺産は)」「~を持つもの(=場所)もある」
★ 訳: 「自然の美しさを持つ場所もあれば、重要な歴史を持つ場所もある」
★ 類例:
・Some like coffee, others like tea.「コーヒーを好む人もいれば、紅茶を好む人もいる」
・Some are tall, others are short.「背の高い人もいれば、背の低い人もいる」

! have natural beauty / have important history の have を「持っている」と直訳
「自然の美しさを持っている~」(=やや硬い)

★ have は多義語!
(1) 「持っている/所有する」(=物理的な所有)
(2) 「~がある/~を備えている」(=性質や特徴を表す)
★ 本問: 「~を持つ」(=性質を表す)
→ have natural beauty = 「自然の美しさを持つ」「自然の美しさがある」
→ have important history = 「重要な歴史を持つ」「重要な歴史がある」
★ 直訳「~を持っている」も意味は通るが、「~を持つ」の方がリズムが良い!
★ さらに自然に: 「~がある」とすると流れる文に!
例: This city has a long history.「この街には長い歴史がある」
★ natural beauty = 「自然の美しさ/自然美」
★ important history = 「重要な歴史」

! 2文の関係を意識せず、それぞれ独立して訳す
「(1文目と2文目の関係性が見えない)」

★ 本問は2文構成!
★ 1文目: There are different kinds of World Heritage Sites.
= 「世界遺産にはさまざまな種類がある」(=全体を述べる、抽象的)
★ 2文目: Some have natural beauty, and others have important history.
= 「自然の美しさを持つ場所もあれば、重要な歴史を持つ場所もある」(=具体例を列挙)
★ 関係: 抽象 → 具体!
→ 1文目で「いろいろある」と全体を述べる
→ 2文目で「具体的にどんな種類があるか」を例示
★ この抽象→具体の流れは英語の典型的な書き方!
★ 「例えば」と補って訳しても自然: 「世界遺産にはさまざまな種類がある。(例えば)自然の美しさを持つ場所もあれば、重要な歴史を持つ場所もある」
★ 論理の流れを意識すると、英文がぐっと深く読めるようになる!

STEP 2 — Read Along —

左から右へ、頭の中の実況中継

読める人は、英文を読みながら頭の中で常に何かを「考えて」います。その思考プロセスを 1語ずつ覗いてみましょう。これが英文解釈の正体です。

1 There are ▸ There + be 動詞 ─ ~がある構文！

冒頭の There are「~がある」が登場。

★ There is/are ~ = 「~がある/いる」(=存在を示す慣用)
★ 大原則: 文頭の There は形式上の主語(=飾り)!
→ 「そこには」と訳さない!
→ 本当の主語は be の後ろの名詞!

★ are(=複数のbe動詞)→ 後ろの名詞は複数!

★ be動詞は本当の主語に合わせる:
・単数 → There is ~
・複数 → There are ~

→ 後ろに本当の主語(=複数の名詞)が来るはず!
There are = 「~がある」(=存在の慣用)、複数のbe動詞 → 後ろに複数主語を予測!
2 different kinds of World Heritage Sites. ▸ 本当の主語 ─ さまざまな種類の世界遺産

本当の主語 different kinds of World Heritage Sites.「さまざまな種類の世界遺産」が登場、1文目が完結!

★ 本当の主語 = different kinds of World Heritage Sites!
★ different kinds of ~ = 「さまざまな種類の~」(=慣用)
→ different = 「異なる/さまざまな」
→ kinds = 「種類(複数形)」
→ 「異なる種類の」は硬い!「さまざまな」の方が自然!

★ World Heritage Sites = 「世界遺産」(=固有名詞、複数形)

★ 1文目の意訳: There are different kinds of World Heritage Sites.
→ 直訳「さまざまな種類の世界遺産がある」
→ 自然な訳: 「世界遺産にはさまざまな種類がある」(=「世界遺産には」を主題に)

→ 2文目で具体例が来るはず!
本当の主語 = different kinds of World Heritage Sites「さまざまな種類の世界遺産」。1文目: 「世界遺産にはさまざまな種類がある」
3 Some have natural beauty, ▸ 2文目の主語 ─ Some = 「~なものもある」

2文目の Some have natural beauty,「自然の美しさを持つものもある」が登場。

★ Some = 代名詞「(あるものは~/ある場所は~)」(=第2講応用)
→ 前文の World Heritage Sites(=世界遺産)を指す!
→ 「(世界遺産の中で)~なものもある」

★ have = 「~を持つ/~がある」(=多義語、ここは性質を表す)
★ natural beauty = 「自然の美しさ/自然美」

★ Some have natural beauty = 「自然の美しさを持つもの(=場所)もある」
→ コンマ → 後ろに and others ~ が来る予感(=対比)!

★ 抽象→具体の流れ: 1文目「いろいろある」 → 2文目「具体的に何があるか」!
Some have natural beauty = 「自然の美しさを持つ場所もある」(=Some は世界遺産の一部を指す代名詞)
4 and others have important history. ▸ Some ~, others ~ の対比！

最後に and others have important history.「重要な歴史を持つものもある」!

★ Some ~, (and) others ~ = 「~もあれば、~もある」(=対比!)
→ Some = 「あるものは~」
→ others = 「他のものは~」(=otherの複数形)

★ and = 接続詞、文と文をつなぐ!(=主語が Some から others に変わる)

★ others have important history = 「重要な歴史を持つもの(=場所)もある」
★ important history = 「重要な歴史」

★ 2文目の意訳: Some have natural beauty, and others have important history.
→ 直訳「あるものは自然の美しさを持ち、他のものは重要な歴史を持つ」
→ 自然な訳: 「自然の美しさを持つ場所もあれば、重要な歴史を持つ場所もある」(=「~もあれば、~もある」の対比表現)

★ 全体の意訳:
→ 「世界遺産にはさまざまな種類がある。自然の美しさを持つ場所もあれば、重要な歴史を持つ場所もある」
→ 抽象から具体への流れが、日本語でも自然に伝わる!
Some ~, others ~ = 対比「~もあれば、~もある」。「自然の美しさを持つ場所もあれば、重要な歴史を持つ場所もある」
▼ ここまでの解析を1枚で見る

4つのステップで、左から右へと考えてきたことを構造図にまとめると、こうなります。色分けで見ると、骨格(メイン)と補足の関係が一気にクリアになるはず。

There形式主語 areV₁ different kinds of World Heritage SitesS₁(本当の主語) . SomeS₂ haveV₂ natural beautyO₂ , and接 othersS₃ haveV₃ important historyO₃ ..

骨格 = There V S(本当の主語). S₂ V₂ O₂, and S₃ V₃ O₃.(1文目=There構文、本当の主語は be の後ろ。2文目=Some ~, others ~ の対比、文と文をandがつなぐ)
▼ 構造が見えたら、いよいよ訳の仕上げ

構造解析で終わると「結局この文は何を言ってるの？」が宙ぶらりんになりがち。
ここから、直訳 → 中間訳 → 完成訳と、日本語として自然な訳に磨き上げる手順を見ていきます。これも「センス」ではなく、ちゃんと段階的な手順があります。

① 直訳
そこには異なる種類の世界遺産がある。あるものは自然の美しさを持ち、他のものは重要な歴史を持つ。 構造どおりの直訳。「そこには」の誤訳、「異なる種類の」「持つ」が硬い。
▼ There is/are ~ = 「~がある」(=存在の慣用) There は形式主語(=飾り)!「そこには」と訳さない。本当の主語は be の後ろの名詞。
② 中間訳
世界遺産にはさまざまな種類がある。自然の美しさを持つものもあれば、重要な歴史を持つものもある。 「そこには」を消して「世界遺産には~がある」に。Some ~, others ~ を「~もあれば~もある」に意訳。
▼ be 動詞は本当の主語に合わせる 本当の主語が単数 → There is ~、複数 → There are ~!
③ 完成訳
世界遺産にはさまざまな種類がある。自然の美しさを持つ場所もあれば、重要な歴史を持つ場所もある。 「ものもある」を「場所もある」に変更(=世界遺産は「場所」のニュアンス強)。これで完成!
💡 自然訳の「型」: There is/are ~ 構文 ─ 「そこに」ではない There の正体

★ 第9講で学ぶ新しい構文を伝えます。

★ There is/are ~ は、英語でとても頻繁に使われる構文です。意味はシンプル:

★ 「~がある/いる」(=存在を示す)

★ 形のルール:
・単数主語 → There is ~「~が(1つ)ある」
・複数主語 → There are ~「~がある(複数)」

★ 例:
・There is a cat in the garden.「庭に猫が(1匹)いる」
・There are three cats in the garden.「庭に猫が3匹いる」
・There was a strange noise last night.「昨夜、変な音がした」
・There were many people at the concert.「コンサートにはたくさんの人がいた」

★ 大事なルール ─ There は主語ではない!

★ 文頭の There は形式上の主語(=飾り)です!
★ 本当の主語は be の後ろの名詞!

★ 判別ルール:
(1) There を見たら、まず後ろを確認
(2) be の後ろの名詞が本当の主語
(3) その名詞が単数なら is、複数なら are

★ 注意:
★ 似た形に「場所のThere」(=「そこに」)もありますが、これは別物!
例: She is over there.「彼女はあそこにいる」(=場所のthere、文末)
例: There she is!「あそこにいた!」(=場所のthere、強調)
→ これらは There is/are ~ 構文ではない!

★ 判別: 文頭の There + is/are/was/were は存在のThere!
★ 文末・強調位置の there は場所のThere!

★ これからの60講で There is/are ~ は何度も登場します。「そこに」ではなく「~がある」と訳す習慣を!

STEP 3 — Try It Yourself —

同じ思考で、別の英文を読んでみる

読み方は「使えてナンボ」。今日身につけた思考プロセスを、別の英文で試してみましょう。答えを見る前に必ず自分で考えるのがポイント。
知識として「覚える」のではなく、手を動かして「使える」状態に持っていきます。

Q1 There is/are ~ の本当の主語

There are three apples on the table.

本当の主語はどれ？なぜ are？

分析: 本当の主語は three apples(=複数)!
→ 複数主語なので be 動詞は are!
→ There は形式主語(=飾り)
訳: 「テーブルの上に3つのリンゴがある」

💡 There is/are ~ は「そこに」と訳さない!「~がある」!be 動詞は本当の主語に合わせる!
Q2 単数 vs 複数の There

(1) There is a book. / (2) There are books.

なぜ is と are が使い分けられる？

(1): 本当の主語 a book(=単数) → is
→ 訳: 「本が(1冊)ある」
(2): 本当の主語 books(=複数) → are
→ 訳: 「本がある(複数冊)」

💡 be動詞の単複は本当の主語(=be の後ろの名詞)で決まる!
Q3 Some ~, others ~ の対比

Some students like math, others like English.

構造と訳は？

分析: Some ~, others ~ = 「~もあれば、~もある」!
・Some students = 「(数学が好きな)生徒もいる」
・others = 「(英語が好きな)他の生徒もいる」
訳: 「数学が好きな生徒もいれば、英語が好きな生徒もいる」

💡 対比のパターン!Some ~, others ~ は「~人(物)もいる、~もいる」と訳すと自然!
