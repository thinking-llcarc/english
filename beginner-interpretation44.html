STEP 0 — First Read —

まず、自分で読んでみよう

解説を読む前に必ずやってほしいステップ。「自分はどう読んだか」を意識化することが、読み方を身につける最大の近道です。

In Japan, people developed a special kind of theater for performing the ancient drama called No. The masked actors entered the plain, square stage across a structure like a little bridge. There was no scenery.

STOP. ここで一度立ち止まって。
① まず辞書を引かずに訳してみてください。
② 訳せなくても OK。「どこで詰まったか」を意識してください。
③ 「ここの構造がよく分からない」「この単語の品詞が判別できない」と感じたら、それがあなたの伸びしろです。
STEP 1 — Common Mistakes —

ありがちな誤読を先につぶしておく

この英文で多くの生徒がハマる罠が 6つ あります。先に見ておくことで、自分が同じ罠にハマっていないかチェックできます。

! for performing the ancient drama の performing を進行形と取る
「(performing を進行形と勘違い)」

★ 核心: 前置詞 + V-ing → 動名詞!(=第41講応用)
→ be 動詞がない → 進行形ではない!
→ for(=前置詞)の目的語に V-ing が来る!
★ 本問: a special kind of theater for performing the ancient drama
→ 名詞 = a special kind of theater「特別な種類の劇場」
→ 修飾 = for performing the ancient drama「古い演劇を上演するための」(=前置詞句)
→ 「古い演劇を上演するための特別な種類の劇場」
★ for + V-ing = 「~するための」(=目的・用途)
★ performing = 動名詞、the ancient drama = perform の目的語!
★ 核心: 前置詞 + V-ing → 動名詞「~すること(のための)」!
★ 類例:
・a tool for cutting paper「紙を切るための道具」
・a room for sleeping「眠るための部屋」
・a method for solving problems「問題を解くための方法」

! the ancient drama called No の called を動詞と取る
「(called を文の主動詞と勘違い)」

★ called = 過去分詞(=後置修飾、第43講応用)!
→ 名詞 the ancient drama を修飾!
→ 「能(No)と呼ばれる古い演劇」
★ 本問: the ancient drama called No
→ 名詞 = the ancient drama「古い演劇」
→ 修飾 = called No「Noと呼ばれる」(=過去分詞句)
→ 「Noと呼ばれる古い演劇」
★ 意訳: 「能(No)と呼ばれる古い演劇」
★ No = 「能」(日本の伝統芸能)。英語では Noh と表記されることもある!
★ 判別ヒント: 名詞 + V-ed + 補足 → 過去分詞の後置修飾(=「~された(名詞)」)
★ 類例(=過去分詞 called/named):
・a man called Tom「Tom と呼ばれる男」(=第43講)
・a flower called sakura「桜と呼ばれる花」
・a sport called sumo「相撲と呼ばれるスポーツ」

! a structure like a little bridge の like を「好き」と取る
「小さな橋を好きな構造」(=動詞 like と勘違い)

★ like = ここでは前置詞「~のような」(=動詞「好き」ではない!)
→ like + 名詞「~のような」(=形容詞的・副詞的)
★ 本問: a structure like a little bridge
→ 名詞 = a structure「造り/構造物」
→ 修飾 = like a little bridge「小さな橋のような」(=前置詞句)
→ 「小さな橋のような造り」
★ like の用法:
(1) 動詞「~を好む」I like dogs.「犬が好き」
(2) 前置詞「~のような/~に似た」like a bridge「橋のような」(=本問)
★ 判別ヒント: like の前後を見る!
→ 主語 + like + 名詞 → 動詞「好き」
→ 名詞 + like + 名詞 → 前置詞「~のような」
★ 類例(=前置詞 like):
・a face like an angel「天使のような顔」
・a voice like thunder「雷のような声」
・a man like my father「父のような男性」

! the plain, square stage の plain を「平原」と取る
「平原で四角い舞台」(=plain を名詞と勘違い)

★ plain = ここでは形容詞「飾りのない/シンプルな/何もない」
→ stage(=名詞)を修飾!
★ 本問: the plain, square stage
→ 形容詞₁ = plain「飾りのない」
→ 形容詞₂ = square「四角い」
→ 名詞 = stage「舞台」
→ 形容詞2つがコンマで連続!
→ 「飾りのない四角い舞台」
★ plain の用法:
(1) 形容詞「飾りのない/シンプルな」(=本問)
(2) 形容詞「明白な」
(3) 名詞「平原」
★ 意訳: 「何もない四角い舞台」(=能舞台の特徴を表現!)
★ plain と plane は別の単語!
→ plain = 飾りのない/平原
→ plane = 飛行機/平面
★ 核心: 形容詞2つ以上 + 名詞 → コンマで区切る場合あり!

! There was no scenery. の no を「いいえ」と取る
「(no を否定の返答と勘違い)」

★ no + 名詞 = 「~がない/1つもない」(=形容詞、強い否定)
→ no scenery「背景道具(=書き割り)がない」
★ 本問: There was no scenery.
→ there + be 動詞 + 名詞 = 「~がある/いる」(=第9講応用)
→ there + be + no 名詞 = 「~は1つもない」
→ S = no scenery「背景道具がない」
→ V = was
→ M = there(=副詞「そこに」)
★ 意訳: 「背景の道具(=書き割り)はなかった」
★ 能舞台の特徴: 装飾を最小限にし、観客の想像力に委ねる!
★ not vs no:
(1) not + a/any 名詞「~がない」(=動詞を否定)
(2) no + 名詞「(全く)~がない」(=名詞を否定、強い否定)
★ 類例:
・There is no time.「時間がない」
・I have no money.「お金がない」
・No problem.「問題ない」

! the masked actors の masked を動詞と取る
「(masked を動詞の過去形と勘違い)」

★ masked = 過去分詞「仮面をつけた」(=actors を前から修飾!)
→ mask(=他動詞「仮面をつける」)→ masked(=過去分詞)
→ 1語の修飾は名詞の前!(=第42・43講応用)
★ 本問: The masked actors
→ 形容詞(過去分詞) = masked「仮面をつけた」
→ 名詞 = actors「俳優たち」
→ 「仮面をつけた俳優たち」
★ 2語以上 vs 1語の違い(=第42・43講で学んだ重要ルール):
(1) 1語修飾 → 名詞の前: a masked actor「仮面の俳優」(=本問!)
(2) 2語以上修飾 → 名詞の後ろ: an actor masked in white「白い仮面をつけた俳優」
★ 核心: 過去分詞も形容詞のように名詞を修飾できる!
★ 類例:
・a broken window「割れた窓」
・a closed door「閉まった扉」
・written words「書かれた言葉」

STEP 2 — Read Along —

左から右へ、頭の中の実況中継

読める人は、英文を読みながら頭の中で常に何かを「考えて」います。その思考プロセスを 1語ずつ覗いてみましょう。これが英文解釈の正体です。

1 In Japan, people developed a special kind of theater ▸ 冒頭 ─ 副詞句 + SVO

冒頭 In Japan, people developed a special kind of theater「日本では、人々は特別な種類の劇場を発展させた」!

★ In Japan, = 副詞句「日本では」(=場所の補足、M)

★ S = people「人々」
★ V = developed「発展させた」(=他動詞、過去形)
★ O = a special kind of theater「特別な種類の劇場」
→ a special kind of「特別な種類の~」(=慣用)
→ theater「劇場」(=名詞、目的語の中心)

★ 骨格: SVO + 補足 = 第3文型!

→ 後ろにどんな修飾が続く?(=待つ!)
副詞句 + SVO の3文型!develop = 他動詞「発展させる」!a special kind of ~「特別な種類の~」!
2 for performing the ancient drama ▸ 前置詞 + 動名詞 ─ 「~するための」

続く for performing the ancient drama「古い演劇を上演するための」!

★ 核心: 前置詞 + V-ing → 動名詞!(=第41講応用)
→ be 動詞がない → 進行形ではない!
→ for(=前置詞)の目的語に動名詞が来る!

★ 本問:
→ 前置詞 = for「~のための」
→ 動名詞 = performing「上演すること」
→ 動名詞の目的語 = the ancient drama「古い演劇」

★ for + V-ing = 「~するための」(=目的・用途)

★ 修飾関係:
→ 名詞 = a special kind of theater「劇場」
→ 修飾 = for performing the ancient drama「古い演劇を上演するための」
→ 「古い演劇を上演するための特別な種類の劇場」

→ さらに後ろに来る!(=次へ!)
前置詞 + V-ing → 動名詞!for performing「上演するための」(=目的・用途)!第41講応用!
3 called No. ▸ 過去分詞による後置修飾 ─ Noと呼ばれる

続く called No.「能(No)と呼ばれる」!

★ 核心: 名詞 + V-ed → 過去分詞による後置修飾!(=第43講応用)
→ called = 過去分詞「呼ばれる」
→ 名詞 the ancient drama を修飾!

★ 本問:
→ 名詞 = the ancient drama「古い演劇」
→ 修飾 = called No「Noと呼ばれる」(=過去分詞句)
→ 「Noと呼ばれる古い演劇」

★ No = 日本の伝統芸能「能」!

★ 1文目全体の修飾の連鎖:
→ S = people
→ V = developed
→ O = a special kind of theater(=劇場)
　→ for performing(=前置詞 + 動名詞)
　　→ the ancient drama(=動名詞の目的語)
　　　→ called No(=過去分詞、drama を修飾)

★ 意訳: 「日本では、人々は能と呼ばれる古い演劇を上演するための特別な種類の劇場を発展させた」

★ 核心: 修飾は左から右へ1つずつ!連鎖を「ほどく」感覚!
名詞 + V-ed → 過去分詞の後置修飾「~された(名詞)」!called No「Noと呼ばれる」(=第43講応用)
4 The masked actors entered the plain, square stage ▸ 2文目 ─ 過去分詞前置修飾 + 形容詞2つ + SVO

2文目 The masked actors entered the plain, square stage「仮面をつけた俳優たちは、飾りのない四角い舞台に入った」!

★ S = The masked actors「仮面をつけた俳優たち」
→ masked = 過去分詞、actors を前から修飾(=1語修飾は前)
→ 「仮面をつけた俳優たち」

★ V = entered「入った」(=他動詞、過去形)

★ O = the plain, square stage「飾りのない四角い舞台」
→ 形容詞₁ = plain「飾りのない/シンプルな」
→ 形容詞₂ = square「四角い」
→ コンマで形容詞2つを連続!
→ 名詞 = stage「舞台」

★ plain の意味:
→ ここでは形容詞「飾りのない/シンプルな」
→ 名詞「平原」ではない!

★ 意訳: 「仮面をつけた俳優たちは、飾りのない四角い舞台に入った」

→ 何を渡って?(=次へ!)
1語修飾は前(masked actors)、形容詞2つはコンマ区切り(plain, square stage)!SVOの第3文型!
5 across a structure like a little bridge. ▸ 副詞句 ─ 小さな橋のような造りを渡って

続く across a structure like a little bridge.「小さな橋のような造りを渡って」!

★ across = 前置詞「~を渡って/横切って」
★ a structure = 名詞「造り/構造物」
★ like a little bridge = 「小さな橋のような」
→ like = ここでは前置詞「~のような」(=動詞「好き」ではない!)
→ a little bridge = 「小さな橋」

★ 修飾の連鎖:
→ across(=前置詞)
　→ a structure(=名詞、across の目的語)
　　→ like a little bridge(=前置詞句、a structure を修飾)

★ 意訳: 「小さな橋のような造りを渡って」

★ 能舞台の構造:
→ 橋掛(はしがかり) = 楽屋から舞台に通じる「橋のような通路」!
→ 英語の a structure like a little bridge はまさにこれ!

★ 2文目全体: 「仮面をつけた俳優たちは、小さな橋のような造りを渡って、飾りのない四角い舞台に入った」
across + 名詞 + like + 名詞。like = 前置詞「~のような」!(動詞「好き」ではない!)
6 There was no scenery. ▸ 3文目 ─ there構文 + no + 名詞

最後 There was no scenery.「背景の道具(=書き割り)はなかった」!

★ there + be 動詞 + 名詞 = 「~がある/いる」(=第9講応用、倒置)
→ S = no scenery「scenery がない」
→ V = was
→ M = there(=副詞「そこに」)

★ no + 名詞 = 「(全く)~がない/1つもない」(=強い否定!)
→ not の名詞版的な働き

★ scenery = 名詞「背景道具(=書き割り)/景色」(=不可算名詞!)
→ 演劇用語では「舞台装置/背景」

★ 意訳: 「背景の道具はなかった」

★ 3文全体のメッセージ:
→ 1文目: 日本人は能のための特別な劇場を発展させた
→ 2文目: 仮面の俳優が、橋のような造りを渡って、シンプルな舞台に入る
→ 3文目: 背景はない

★ 本講の本質: 修飾の連鎖を、左から右へ1つずつ「ほどく」!動名詞・過去分詞の連続も同じ思考で読む!
there + be + 名詞「~がある」。no + 名詞「(全く)~がない」(=強い否定)。能舞台の「シンプルさ」を表現!
▼ ここまでの解析を1枚で見る

6つのステップで、左から右へと考えてきたことを構造図にまとめると、こうなります。色分けで見ると、骨格(メイン)と補足の関係が一気にクリアになるはず。

〈In Japan〉,M(場所) peopleS₁ developedV₁ a special kind of theaterO₁ 〈for performingM(前置詞+動名詞) the ancient drama動名詞のO (called No)〉.過去分詞(=後置修飾) The masked actorsS₂(過去分詞前置修飾) enteredV₂ the plain, square stageO₂(形容詞2つ) 〈across a structureM like a little bridge〉.M(like=前置詞) ThereM(副詞) wasV₃ no scenery.S₃(no+名詞)

骨格 = 1: 〈M〉, S V O 〈for V-ing(=動名詞) + 名詞 + V-ed(=過去分詞)〉. 2: S(過去分詞前置修飾) V O(形容詞2つ) 〈M〉. 3: 〈There〉 V S(no+名詞).(前置詞 + 動名詞、過去分詞による後置修飾、過去分詞による前置修飾、形容詞2つの連続、there構文、no+名詞)
▼ 構造が見えたら、いよいよ訳の仕上げ

構造解析で終わると「結局この文は何を言ってるの？」が宙ぶらりんになりがち。
ここから、直訳 → 中間訳 → 完成訳と、日本語として自然な訳に磨き上げる手順を見ていきます。これも「センス」ではなく、ちゃんと段階的な手順があります。

① 直訳
日本の中で、人々は能と呼ばれる古い演劇を上演することのための特別な種類の劇場を発展させた。仮面をつけた俳優たちは小さな橋のような構造を渡って平原で四角い舞台に入った。そこに背景道具がなかった。 構造どおりの直訳。「上演することのための」「平原で四角い」「そこに~がなかった」が硬い。
▼ 前置詞 + V-ing = 動名詞(=第41講応用)、名詞 + V-ed = 過去分詞の後置修飾(=第43講応用) for performing「上演するための」、called No「Noと呼ばれる」!修飾を左から右へ1つずつほどく!
② 中間訳
日本では、人々は能と呼ばれる古い演劇を上演するための特別な種類の劇場を発展させた。仮面をつけた俳優たちは、小さな橋のような造りを渡って、飾りのない四角い舞台に入った。背景道具はなかった。 「~するための」と動名詞を自然に。「飾りのない」(plain)「造り」(structure)を自然な日本語に。
▼ there + be 動詞 + S 構文(=第9講応用)、no + 名詞「(全く)~がない」(=強い否定) there was no scenery「背景道具はなかった」!no は強い否定!
③ 完成訳
日本では、人々は能(No)と呼ばれる古い演劇を上演するための特別な種類の劇場を発展させた。仮面をつけた俳優たちは、小さな橋のような造りを渡って、何もない四角い舞台に入った。背景の道具(=書き割り)はなかった。 「能(No)」と原語ルビ、「何もない」(plain の自然訳)、「背景の道具(=書き割り)」と日本の演劇用語を補って意訳。これで完成!
💡 自然訳の「型」: 修飾の連鎖をほどく ─ 名詞 + 前置詞句 + 動名詞 + 名詞 + 過去分詞句

★ 第44講で身につけてほしい「修飾の連鎖を順番にほどく読み方」を伝えます。

★ 英語では、1つの名詞に対して複数の修飾語句が連続することが頻繁にあります。
★ 第41〜43講で学んだ V-ing(=動名詞・現在分詞)、V-ed(=過去分詞)が組み合わさる場面!

★ 本問の例:

→ 名詞₁ = a special kind of theater「特別な種類の劇場」
　→ 修飾₁ = for performing ~(=前置詞 + 動名詞、第41講応用)
　　→ 名詞₂ = the ancient drama「古い演劇」(=動名詞の目的語)

★ 核心: 修飾の連鎖を左から右へ1つずつ「ほどく」!

★ 日本語に訳すときの工夫:

★ 前置詞は名詞・代名詞・動名詞を目的語にとる!
★ be 動詞がない → 進行形ではない!

★ 類例(=前置詞 + 動名詞):
・good at swimming「泳ぐのが得意」
・interested in reading「読書に興味がある」
・tired of waiting「待つのに疲れた」
・a tool for cutting「切るための道具」(=本問と同じパターン!)

★ もう一つ ─ 過去分詞による後置修飾(=第43講応用):
★ 名詞 + V-ed → 「~された(名詞)」
★ 受動の関係(=名詞が動作を受ける)を表す!

★ 類例(=過去分詞の後置修飾):
・a man called Tom「Tom と呼ばれる男」
・a book written by him「彼によって書かれた本」
・a sport called sumo「相撲と呼ばれるスポーツ」(=本問と同じ called!)

★ もう一つ ─ 1語修飾は前、2語以上は後ろ(=第42・43講応用):
★ The masked actors(=1語、前置)
★ an actor masked in white(=2語以上、後置)
→ 修飾語の数で位置が変わる!

★ もう一つ ─ like の見分け:
★ like には2つの主な用法!
(1) 動詞「~を好む」
(2) 前置詞「~のような」(=本問!)
→ 文中の位置と前後の品詞で判別!

★ これからの60講で、修飾の連鎖は頻繁に登場します。長い名詞句に出会ったら、「名詞 → 修飾 → 名詞 → 修飾」と1つずつほどく習慣を!

a tool for cutting paper made in Japan 紙を作った日本のための道具を切る (修飾の連鎖が掴めない) 日本で作られた紙を切るための道具 (for cutting = 動名詞、made in Japan = 過去分詞、修飾を順番にほどく)
a method for solving problems used in school 学校で使われた方法のための問題を解く (修飾の関係が逆転) 学校で使われている、問題を解くための方法 (for solving = 動名詞、used in school = 過去分詞)
a book about cooking written by a famous chef 有名なシェフによる料理について書かれた本 (about cooking と written by ~ の関係が混乱) 有名なシェフによって書かれた、料理についての本 (about cooking = 前置詞句、written by ~ = 過去分詞、両方が a book を修飾)
✓ STEP 2 のまとめ ─ 「構造」から「意味」までの一直線
1 左から右へ、1語ずつ品詞と役割を確定する
→
2 骨格と修飾語(M)を色分けで把握する
→
3 直訳 → 中間訳 → 完成訳と日本語に仕上げる

この一連の流れが、英文解釈の全プロセスです。「構造が見えた」だけで満足せず、必ず最後の「自然な訳」まで仕上げる習慣を、今日からつけていきましょう。

STEP 3 — Try It Yourself —

同じ思考で、別の英文を読んでみる

読み方は「使えてナンボ」。今日身につけた思考プロセスを、別の英文で試してみましょう。答えを見る前に必ず自分で考えるのがポイント。
知識として「覚える」のではなく、手を動かして「使える」状態に持っていきます。

Q1 前置詞 + 動名詞 + 名詞修飾

I bought a book for learning English written by a teacher.

修飾の連鎖を整理して訳すと?

分析: 名詞 + 前置詞 + 動名詞 + 名詞 + 過去分詞!
・名詞₁ = a book「本」
・修飾₁ = for learning English(=前置詞 + 動名詞、第41講応用)「英語を学ぶための」
・修飾₂ = written by a teacher(=過去分詞、第43講応用)「先生によって書かれた」
訳: 「私は、先生によって書かれた、英語を学ぶための本を買った」

💡 修飾を左から右へ1つずつほどく!for V-ing「~するための」+ V-ed「~された」!
Q2 like = 前置詞「~のような」

She has a voice like an angel.

like の役割と訳は?

分析: like = ここでは前置詞「~のような」(=動詞「好き」ではない!)
・名詞 = a voice「声」
・修飾 = like an angel「天使のような」(=前置詞句、a voice を修飾)
・S = She、V = has、O = a voice like an angel
訳: 「彼女は天使のような声をしている」

💡 名詞 + like + 名詞 → like = 前置詞「~のような」!動詞「好き」ではない!
Q3 過去分詞の前置修飾 vs 後置修飾

The broken window is the one broken by the storm.

2つの broken の違いと訳は?

分析: 修飾語の数で位置が変わる!(=第42・43講応用)
・The broken window → 1語修飾、前置「割れた窓」
・the one broken by the storm → 2語以上、後置「嵐で割れた窓」
・the one = the window の繰り返しを避ける代名詞
訳: 「その割れた窓が、嵐で割れた窓だ」

💡 1語修飾 → 名詞の前!2語以上 → 名詞の後ろ!過去分詞は「~された」!
STEP 4 — Your Reading Algorithm —

これからの英文に使える「思考フロー」

最後に、今日の学びを初見の英文に使える型として整理しておきます。これを毎回頭の中で回せば、確実に読める英文が増えていきます。

1
修飾の連鎖を左から右へ1つずつほどく
名詞 → 修飾 → 名詞 → 修飾 → ~。長い名詞句は1つずつ整理!
2
前置詞 + V-ing = 動名詞(=第41講応用)
for performing ~「~するための」!be 動詞がなければ進行形ではない!
3
名詞 + V-ed = 過去分詞の後置修飾(=第43講応用)
called No「Noと呼ばれる」!受動の関係!
4
1語修飾は前、2語以上は後ろ(=第42・43講応用)
The masked actors(=1語、前)/ an actor masked in ~(=2語以上、後)!
5
形容詞2つの連続(=コンマで区切る)
the plain, square stage「飾りのない四角い舞台」!複数形容詞 + 名詞!
6
like の見分け
名詞 + like + 名詞 → 前置詞「~のような」!主語 + like + 名詞 → 動詞「好き」!
7
there + be 動詞 + S 構文(=第9講応用)
「~がある/いる」!主語と動詞の語順が変わる(=倒置)!
8
no + 名詞 = 「(全く)~がない」(=強い否定)
not は動詞を否定、no は名詞を否定!no scenery「(全く)背景なし」!
9
plain の意味
ここでは形容詞「飾りのない/シンプルな」!名詞「平原」ではない!
