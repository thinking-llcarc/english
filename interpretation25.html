この講で身につく「読み方」

ついに最終講!関係代名詞の省略シリーズ第6弾、そしてシリーズ全25講の総まとめです。
今日の英文には、これまで学んだ要素が全部詰まっています:
① If SV(=副詞節、第8講) ② 関係代名詞 whom の省略(=第14・20講) ③ view O as C「OをCとして見る」(=第4講のSVO as C 構文) ④ 《名詞+コンマ+名詞》= 同格(=第13講) ⑤ 前置詞 from の終わり(関係代名詞省略との組み合わせ)
この英文が読めれば、あなたは英文解釈の本質を完全にマスターしたと言えます!

1
関係代名詞 whom の省略を、《名詞+名詞+動詞》のルールで見抜けるようになります。
2
view / regard / see / perceive O as C「OをCとして見る/みなす」の構文(=第4講の発展)を覚えます。
3
《名詞+コンマ+名詞》= 同格(第13講)で、難しい表現を言い換えで補足するパターンを見抜けます。
STEP 0 — First Read —

まず、自分で読んでみよう

解説を読む前に必ずやってほしいステップ。「自分はどう読んだか」を意識化することが、読み方を身につける最大の近道です。

If we view each person whom we meet in the course of our daily lives as a potential teacher, someone whom we can learn something from, we will naturally form new, rewarding friendships.

STOP. ここで一度立ち止まって。
① まず辞書を引かずに訳してみてください。
② 訳せなくても OK。「どこで詰まったか」を意識してください。
③ 「ここの構造がよく分からない」「この単語の品詞が判別できない」と感じたら、それがあなたの伸びしろです。
STEP 1 — Common Mistakes —

ありがちな誤読を先につぶしておく

この英文で多くの生徒がハマる罠が 5つ あります。先に見ておくことで、自分が同じ罠にハマっていないかチェックできます。

! each person whom we meet の構造を見落とす
「(whomの後ろのwe meetの構造が分からず止まる)」

これは関係代名詞 whom 節!
★ 《名詞 + 名詞 + 動詞》= 関係代名詞の省略(第20講)。
本来の形: each person (whom) we meet「私たちが出会う人」(=whomは省略可能)
meet「~に会う」(他動詞)の目的語が後ろに無い(=「名詞の欠落」)→ whom が省略されたサイン!
※ 今回は省略されずに whom が明示されているが、構造は同じ。

! view ... as ... の SVO as C 構文を見落とす
「(asの働きが分からず混乱)」

view O as C = 「OをCとして見る/みなす」(第4講のregard O as C と同じパターン)
★ 同類の動詞: view / regard / see / perceive / look on O as C 全て「OをCとみなす/と見る」
今回: view each person ... as a potential teacher ... = 「一人一人を~としての教師として見る」
= 「一人一人を教師として見る/考える」
※ as の後ろは名詞だけでなく形容詞も来る(例: I regard education as essential to ...「教育を不可欠だとみなす」)。

! a potential teacher, someone whom we can learn something from の関係を見落とす
「(コンマで何が起きているか分からず混乱)」

★ 《名詞+コンマ+名詞》= 同格(第13講のルール)
→ a potential teacher, someone の二つの名詞は同じものを指す(=同格)
→ a potential teacher「自分の教師になり得る人」が抽象的なので、後で someone whom we can learn something from「何かを学び取れる人」と具体的に言い換えている。
→ 「自分の教師になり得る人、つまり何かを学び取れる人」と「つまり」を入れて訳すと自然!

! whom we can learn something from の from の意味が分からない
「(文末のfromが何を意味するか分からない)」

someone whom we can learn something from の from はlearn ~ from someone「誰かから~を学ぶ」の from!
関係代名詞 whom を人称代名詞に置換すると: we can learn something from him/her「私たちは彼/彼女から何かを学べる」
★ 注意: この from は日本語訳では「~から」と表現されるが、英文を見ただけだと文末で浮いている印象を受けやすい。
類例: I met the man (whom) I had borrowed money from.「私はお金を借りた男性と会った」(borrow money from someone「人からお金を借りる」のfromが文末に)

! in the course of our daily lives の course を「コース」と訳す
「日々の生活のコースで出会う…」

in the course of ~ = 「~の過程で / ~の中で / ~を送る中で」(熟語表現)
「コース」と訳すのは不自然。
「日々の生活を送る中で」「日常生活の中で」と意訳すると自然な日本語に。

STEP 2 — Read Along —

左から右へ、頭の中の実況中継

読める人は、英文を読みながら頭の中で常に何かを「考えて」います。その思考プロセスを 1語ずつ覗いてみましょう。これが英文解釈の正体です。

1 If we view ▸ If 副詞節のスタート

文頭の If we view「もし私たちが見るなら」。If 副詞節(第8講)です。

★ 第8講のルール: 文頭の If ~ は自動的に副詞節「もし~なら」
→ we = 一般論を示す we(=人々、人類)
→ view「~を見る」(他動詞) → 後ろに目的語(O)が必要。

★ 全体予測: If S'V', S V の構造になるはず。最後にカンマ + 主節が来る。
副詞節スタート: 〈If we view ~〉「もし私たちが~を見るなら」
2 each person ▸ view の目的語O

each person「一人一人(の人)」が view の目的語(O)。

each + 単数名詞 = 「それぞれの~/~一人一人」
→ each person = 「一人一人の人」 → 「出会う人一人一人」と意訳できる。
O' = each person「一人一人」
3 whom we meet ▸ 関係代名詞 whom 節

whom we meet「私たちが出会う」が関係代名詞節。each person を修飾。

whom = 関係代名詞(目的格、人を指す)
→ whom we meet = 「私たちが出会う(人)」
→ meet「~に会う」(他動詞)の目的語が無い → whom が前に出ているサイン!

★ 第20講ルールの確認: もし whom が省略されていたら、each person we meet(名詞+名詞+動詞)の形になる。これも関係代名詞省略のパターン。
→ 今回は whom が明示されている版。

※ whom は人を指す目的格関係代名詞。前置詞 + whom の場合は省略不可だが、今回のように単独で使われる場合は省略可能。
(whom we meet) = 関係代名詞節、each person を修飾「私たちが出会う(人)」
4 in the course of our daily lives ▸ 熟語 in the course of ~

in the course of our daily lives「日々の生活を送る中で」が登場。

★ in the course of ~ = 「~の過程で / ~を送る中で」(熟語)
→ 「コース」と訳さない!
→ our daily lives = 「私たちの日々の生活」
→ 全体: 「日々の生活を送る中で」「日常生活の中で」

→ これは meet(=私たちが会う)を修飾する副詞句。
M'' = 〈in the course of our daily lives〉「日々の生活を送る中で」(meet を修飾)
5 as a potential teacher ▸ view O as C 構文の C

as a potential teacher「自分の教師になり得る人として」が登場。これは view O as C 構文の C !

★ view O as C = 「OをCとして見る/みなす」
→ 第4講で学んだ regard O as C と同じ仲間!
→ 同類の動詞: view / regard / see / perceive / look on O as C

→ 全体構造: view each person ... as a potential teacher「一人一人を~として見る」
→ a potential teacher = 「自分の教師になり得る人」「潜在的な教師」(=potential「可能性のある」)

※ as の後ろは名詞のことが多いが、形容詞も来うる(例: regard O as essential「Oを不可欠だとみなす」)。
C' = a potential teacher「自分の教師になり得る人」(view O as C 構文の C)
6 , someone ▸ 《名詞+コンマ+名詞》= 同格！

, someone「(つまり)~人」が登場。《名詞+コンマ+名詞》= 同格パターン!

★ 第13講のルール: 《名詞+コンマ+名詞》= 同格
→ a potential teacher, someone ~
= 「a potential teacher = someone ~」(=同じものを指す)
→ a potential teacher「自分の教師になり得る人」がやや抽象的なので、後で someone ~「~な人」と具体的に言い換えている!
→ 訳: 「自分の教師になり得る人、つまり~な人」と「つまり」を入れると自然。
a potential teacher = someone(同格関係)。後で具体的に言い換え。
7 whom we can learn something from ▸ 関係代名詞 whom + 文末の from

whom we can learn something from「~から私たちが何かを学べる」が関係代名詞節。someone を修飾。

whom = 関係代名詞(目的格、人を指す)
→ 後ろを見ると we can learn something from ... from の目的語が無い!
→ これが「名詞の欠落」 → whom が前に出ているサイン!

★ 人称代名詞置換(第14講): whom = him/her に置換
→ 元の文: we can learn something from him/her (= someone)「私たちは彼/彼女から何かを学べる」
→ learn ~ from someone「人から~を学ぶ」のfromの目的語が前に出た形。

★ 注意: この英文の from は日本語訳には「~から」として表れるが、文末に残っているように見えて違和感を持つかも。
→ 慣れが必要!類例: the man (whom) I had borrowed money from「私がお金を借りた男性」

→ 全体: 「私たちが何かを学び取れる人」と訳す。
(whom we can learn something from) = 関係代名詞節、someone を修飾「私たちが何かを学び取れる人」
8 we will naturally form ▸ 主節スタート、SV

カンマ後の主節: we will naturally form「私たちは自然と形成するだろう」。

we = 主節の主語(=副詞節と同じ「私たち」)
will form「形成するだろう」(未来形)
naturally「自然と」(副詞、will と form の間)
→ 主節は SV(O) の構造。
S = we / 助 = will / M = naturally / V = form。後ろに目的語O。
9 new, rewarding friendships ▸ 形容詞2つ + 名詞

new, rewarding friendships「新しい、価値ある友情」が目的語(O)。

new「新しい」と rewarding「価値のある/見返りのある」が両方 friendships を修飾(=並列の形容詞)。
→ コンマで2つの形容詞を並べるのは英語の慣用。
→ rewarding = 「(時間や努力に対して)価値のある」「やりがいのある」(=見返りがある、というニュアンス)。「見返りのある」だとやや不自然な日本語なので、「価値のある」「意義のある」と訳すのが自然。
→ friendships(=複数形の友情)「友情(のかたち)」「人間関係」
→ 全体: 「新たな、また価値のある友情」
O = new, rewarding friendships「新しく、価値のある友情」
▼ ここまでの解析を1枚で見る

9つのステップで、左から右へと考えてきたことを構造図にまとめると、こうなります。色分けで見ると、骨格(メイン)と補足の関係が一気にクリアになるはず。

〈IfM₁→接 weS' viewV' each personO' {whomO''(関代) weS'' meetV'' 〈in the course (of our daily lives)〉}M'' as a potential teacher,C' someone同格 {whomO'''(関代) weS''' can助 learnV''' somethingO''' from}〉,M''' weS will助 naturallyM₂ formV new, rewarding friendshipsO.

骨格 = 〈If S'V'O' {関代節} as C'(=同格 + 関代節)〉, S 助 M₂ V O(If 副詞節 + 主節。副詞節の中でview O as C構文、Cが同格関係で具体化、from が関係代名詞節の文末に)
▼ 構造が見えたら、いよいよ訳の仕上げ

構造解析で終わると「結局この文は何を言ってるの？」が宙ぶらりんになりがち。
ここから、直訳 → 中間訳 → 完成訳と、日本語として自然な訳に磨き上げる手順を見ていきます。これも「センス」ではなく、ちゃんと段階的な手順があります。

① 直訳
もし私たちが日々の生活の中で出会うそれぞれの人を、自分の教師になり得る人、つまり私たちが何かをそこから学べる人として見るならば、私たちは自然と新しい、価値のある友情を形成するだろう。 構造どおりの直訳。意味は通るが硬い。「のコース」「~として見る」が機械的すぎる。
▼ in the course of ~ を「~を送る中で」と意訳 「コース」と訳すと不自然。「~の過程で / ~を送る中で / ~の中で」と意訳。
② 中間訳
もし私たちが、日々の生活を送る中で出会う人一人一人を、自分の教師になり得る人、つまり何かを学び取れる人として考えれば、新しい価値のある友情を自然と形成するだろう。 「コース」を「送る中で」、「~として見る」を「~として考える」、「われわれ」を省略するなどの工夫。
▼ 同格を「つまり」でつなぐ a potential teacher, someone ~ の同格を「自分の教師になり得る人、つまり~な人」と接続詞「つまり」を補うと自然。
③ 完成訳
もし私たちが、日々の生活を送る中で出会う人一人一人を、自分の教師になり得る人、つまり何かを学び取れる人だと考えれば、新たな、また価値のある友情を自然と形成できるだろう。 「として考える」を「だと考える」と簡潔に、「新しい価値のある友情」を「新たな、また価値のある友情」と表現を整えて、これで完成。
💡 自然訳の「型」: view / regard / see / perceive O as C ファミリー

第4講で学んだ regard O as C「OをCとみなす」と同じパターンの動詞ファミリー:
① view O as C「OをCと見る/見る」
② regard O as C「OをCとみなす」
③ see O as C「OをCと見る」
④ perceive O as C「OをCと認識する」
⑤ look on O as C「OをCとみなす」
これらは全て「だいたい等しい」を示す asを使って、「OをCのようなものだとみなす」というニュアンスを表します。
※ as の後ろは名詞だけでなく形容詞も来る(例: I regard education as essential to ...「教育を不可欠だとみなす」)。

I regard education as essential to the existence of society. 私は教育を社会の存続のための必須として尊敬する 私は、教育は社会の存続には不可欠であるととらえている (regard O as C 構文)
She views her job as a calling. 彼女は仕事を呼び出しとして見る 彼女は自分の仕事を天職だと考えている (view O as C 構文)
We see this problem as an opportunity. 私たちはこの問題を機会として見る 私たちはこの問題を(成長の)機会だと考えている (see O as C 構文)
✓ STEP 2 のまとめ ─ 「構造」から「意味」までの一直線
1 左から右へ、1語ずつ品詞と役割を確定する
→
2 骨格と修飾語(M)を色分けで把握する
→
3 直訳 → 中間訳 → 完成訳と日本語に仕上げる

この一連の流れが、英文解釈の全プロセスです。「構造が見えた」だけで満足せず、必ず最後の「自然な訳」まで仕上げる習慣を、今日からつけていきましょう。

STEP 3 — Try It Yourself —

同じ思考で、別の英文を読んでみる

読み方は「使えてナンボ」。今日身につけた思考プロセスを、別の英文で試してみましょう。答えを見る前に必ず自分で考えるのがポイント。
知識として「覚える」のではなく、手を動かして「使える」状態に持っていきます。

Q1 関係代名詞 whom + 文末の前置詞

I met the man whom I had borrowed money from.

構造分析と訳は？

分析: whom = 関係代名詞(目的格)、from の目的語が前に出た形。
人称代名詞置換: I had borrowed money from him/her (= the man).「私はその男性からお金を借りた」
訳: 「私はお金を借りた男性と会った」

💡 文末に残った from が日本語の「~から」を意味する。日本語訳では「~から」と表現される。
Q2 view / regard O as C 構文

Many people regard social media as a necessary evil.

O・C は何？　訳は？

O: social media
C: a necessary evil「必要悪」
訳: 「多くの人がソーシャルメディアを必要悪だとみなしている」

💡 view / regard / see / perceive O as C は同じファミリー。「OをCとみなす/と見る/と考える」と訳す。
Q3 《名詞+コンマ+名詞》= 同格

My grandmother, a wise woman, taught me many things.

同格関係と訳は？

同格: My grandmother = a wise woman(コンマで挿入された言い換え)
訳: 「私の祖母は、賢い女性で、私に多くのことを教えてくれた」
または: 「賢い女性であった私の祖母は、私に多くのことを教えてくれた」

💡 同格は「AであるB」「BであるA」「A、つまりB」など、文脈に応じて訳す。第13講の総復習。
STEP 4 — Your Reading Algorithm —

これからの英文に使える「思考フロー」

最後に、今日の学びを初見の英文に使える型として整理しておきます。これを毎回頭の中で回せば、確実に読める英文が増えていきます。

1
関係代名詞 whom(人を指す目的格)を見たら、人称代名詞 him/her に置換
独立した一文として書き直すと意味が明確に(第14講のルール)。
2
《名詞 + 名詞 + 動詞》= 関係代名詞の省略のサイン(第20講)
each person we meet も each person whom we meet も同じ意味。whom は省略可能。
3
view / regard / see / perceive O as C「OをCとみなす/と見る」
第4講のregard O as Cと同じファミリー。as は「だいたい等しい」を示す。
4
《名詞 + コンマ + 名詞》= 同格(第13講)
前の名詞を後ろの名詞が言い換え/具体化。「つまり」「~である」と訳すと自然。
5
関係代名詞節の文末の前置詞に注意
whom we can learn something from の from は learn ~ from someone の from。文末で浮いているように見える。
6
If 副詞節(第8講)の処理 + 主節SV
文頭の If は自動的に副詞節「もし~なら」。カンマで主節の境界が分かる。
7
熟語表現を覚えておく
in the course of ~「~の過程で/中で」、a potential teacher「~になり得る人」など。
