STEP 0 — First Read —

まず、自分で読んでみよう

解説を読む前に必ずやってほしいステップ。「自分はどう読んだか」を意識化することが、読み方を身につける最大の近道です。

As you know, incandescent bulbs emit light by heating a metal filament inside them, so they need much electricity and become very hot.

STOP. ここで一度立ち止まって。
① まず辞書を引かずに訳してみてください。
② 訳せなくても OK。「どこで詰まったか」を意識してください。
③ 「ここの構造がよく分からない」「この単語の品詞が判別できない」と感じたら、それがあなたの伸びしろです。
STEP 1 — Common Mistakes —

ありがちな誤読を先につぶしておく

この英文で多くの生徒がハマる罠が 7つ あります。先に見ておくことで、自分が同じ罠にハマっていないかチェックできます。

! As you know の As を「~として」と取る
「あなたが知るとして」(=前置詞「~として」と勘違い)

★ 核心 ─ 関係代名詞 as!
★ As you know = 「ご存知のように」(=慣用、関係代名詞 as の特殊用法)
→ as は関係代名詞!主節全体を先行詞とする!
★ 本問: As you know, incandescent bulbs emit light ~
→ As you know「ご存知のように」(=主節全体を修飾する副詞句的な働き)
→ メイン文 = incandescent bulbs emit light ~
★ 関係代名詞 as の特徴:
(1) 先行詞 = 主節全体(=文全体の内容!)
(2) 「~するように/~の通り」と訳す
(3) 関係代名詞 which と似た働きだが、節の意味が違う!
★ 関係代名詞 as の用例:
・As you know「ご存知のように」
・As you can see「見ての通り」
・As I said before「前に言ったように」
・As is often the case「よくあることだが」
★ as 接続詞 vs 関係代名詞の違い:
(1) 接続詞: as + S V → 「~するときに/~なので/~のように」(=L54応用)
(2) 関係代名詞: As + S V (=主節全体を先行詞) → 「~するように」(=本問!)
★ 判別の手がかり:
→ As you know(=コンマで区切られている) + メイン文 → 関係代名詞 as の慣用表現!
★ 意訳: 「ご存知のように」
★ 類例(=関係代名詞 as):
・As you can see, the situation is bad.「見ての通り、状況は悪い」
・As I mentioned, we need more time.「言及したように、もっと時間が必要だ」

! incandescent bulbs の意味を取り違える
「(incandescent の意味を取り違え)」

★ incandescent = 形容詞「白熱の/白熱光を発する」(=科学用語)
→ ラテン語起源、「白く輝く」の意味
★ incandescent bulb = 「白熱電球」(=エジソンが発明した電球)
★ 本問: incandescent bulbs emit light by heating a metal filament inside them
→ S = incandescent bulbs「白熱電球(複数)」(=形容詞 + 名詞)
→ V = emit「放つ/出す」(=他動詞)
→ O = light「光」
★ emit = 他動詞「(光・音・熱などを)放つ/出す」
→ emit light「光を放つ」
→ emit sound「音を出す」
→ emit heat「熱を放つ」
★ 白熱電球の歴史と仕組み:
→ 1879年、トーマス・エジソンが実用化
→ 細い金属線(=フィラメント、主にタングステン)に電気を流して高温で発光させる
→ 効率が悪い(=エネルギーの90%が熱になる、光は10%)
→ 2010年代以降、LED に置き換わりつつある(=省エネ・長寿命のため)
★ 意訳: 「白熱電球は光を放つ」
★ 類例(=ラテン語起源の科学用語):
・fluorescent「蛍光の」(=蛍光灯)
・phosphorescent「燐光の」

! by heating a metal filament inside them の by V-ing を取り違える
「(by V-ing を「~による」とだけ取って混乱)」

★ 核心: by V-ing = 「~することによって」(=動名詞、手段、第41講応用)
→ by(=前置詞)+ V-ing(=動名詞、=「~すること」)
→ 手段・方法を表す!
★ 本問: by heating a metal filament inside them
→ by(=前置詞)
→ heating「熱すること」(=動名詞、heat の現在分詞形)
→ a metal filament「金属フィラメント」(=heating の目的語)
→ inside them「それらの内部の」(=前置詞句、a metal filament を修飾)
★ 分解:
→ V-ing = heating「熱すること」
→ heating の意味上のS = the bulb (省略、文脈で明確)
→ heating の目的語 = a metal filament
→ heating a metal filament「金属フィラメントを熱すること」
★ by V-ing の用法:
→ 手段・方法を表す!「~することによって」
→ メインの動詞(=ここでは emit)の方法を説明!
→ 「光を放つ」 ← どうやって? ← 「フィラメントを熱することによって」
★ 意訳: 「内部の金属フィラメントを熱することによって」
★ inside them:
→ inside = 前置詞「~の内部に」(=in より「内部」を強調)
→ them = bulbs を指す代名詞
→ 「電球の内部にある」
★ 類例(=by V-ing):
・She passed the exam by studying hard.「一生懸命勉強することによって、試験に合格した」
・We can save the planet by using renewable energy.「再生可能エネルギーを使うことによって、地球を救える」
・He earned money by selling old books.「古い本を売ることによって、彼は金を稼いだ」
★ 類似表現:
(1) by V-ing「~することによって」(=本問!、手段)
(2) through V-ing「~することを通じて」
(3) with N「~を使って」
(4) by N「~によって」(=手段、人・物)

! a metal filament の metal を取り違える
「(metal を名詞「金属」とだけ取って混乱)」

★ metal = ここでは形容詞的に「金属の/金属製の」(=名詞 + 名詞、複合名詞)
→ metal(=名詞)+ filament(=名詞)= 「金属フィラメント」(=金属でできたフィラメント)
★ 名詞の形容詞的用法:
→ 名詞 + 名詞 で複合名詞を作る場合、前の名詞は形容詞的に働く!
→ metal filament「金属フィラメント」
→ paper bag「紙袋」
→ stone wall「石の壁」
★ 本問: a metal filament inside them
→ a metal filament「金属フィラメント」(=metal は形容詞的)
→ inside them「それらの内部の」(=修飾)
→ 「内部の金属フィラメント」
★ filament:
→ 名詞「フィラメント/細い糸/細線」
→ 電球内の細い金属線(=主にタングステン)
→ 高温になると発光する!
★ 意訳: 「内部の金属フィラメント」
★ 類例(=名詞の形容詞的用法、複合名詞):
・a metal box「金属の箱」
・a wooden table「木製のテーブル」(=wooden は形容詞)
・a stone bridge「石の橋」
・a wool sweater「ウールのセーター」

! so they need much electricity の so を「とても」と取る
「とても多くの電気を必要とする」(=副詞「とても」と勘違い)

★ 核心: so = ここでは結果接続詞「だから/それで」(=第29・55講応用)
→ 副詞「とても」(=very)ではない!
★ 本問: ~ emit light by heating ~ , so they need much electricity ~
→ 前: incandescent bulbs emit light by heating ~「白熱電球はフィラメントを熱して光を放つ」(=原因)
→ so(=結果接続詞)
→ 後: they need much electricity ~「(白熱電球は)多くの電気を必要とする」(=結果)
→ 因果関係!
★ so vs because の対比:
(1) so: A so B「Aなので B」(=結果が後ろ、本問!)
(2) because: B because A「BなのはAから」(=理由が後ろ)
→ 同じ事実、語順が逆!
★ so の意味の判別:
(1) 結果接続詞「だから」(=本問!): A, so B
(2) 副詞「とても」: so + 形容詞 + 名詞(例: so much/so many/so good)
(3) 副詞「そう」: I think so.「そう思う」
(4) so that 構文「~するために」(=目的)
★ 判別の決め手:
→ コンマ + so + S V → 結果接続詞!
→ so + 形容詞/副詞 → 副詞「とても」
★ 意訳: 「だから、(白熱電球は)多くの電気を必要とする」
★ 類例(=結果接続詞 so):
・It was raining, so we stayed home.「雨だったので、家にいた」
・He worked hard, so he succeeded.「一生懸命働いたので、成功した」
・She was tired, so she went to bed early.「疲れていたので、早く寝た」

! they need much electricity の much を取り違える
「(much の使い方を取り違え)」

★ much = ここでは形容詞「多くの」(=不可算名詞を修飾、第36・57講応用)
→ 不可算名詞の前!
★ 本問: they need much electricity「(白熱電球は)多くの電気を必要とする」
→ S = they(=incandescent bulbs を指す)
→ V = need「必要とする」
→ O = much electricity「多くの電気」(=much + 不可算名詞)
★ much vs many の使い分け:
(1) much + 不可算名詞(=本問!): much electricity「多くの電気」、much water「多くの水」、much money「多くのお金」
(2) many + 可算名詞: many books「多くの本」、many people「多くの人」
★ electricity = 不可算名詞「電気」
→ 「いくつの電気」(=可算)とは数えない!
→ a lot of electricity / much electricity と表現!
★ much の用法:
(1) 形容詞「多くの」(=不可算名詞修飾、本問!)
(2) 副詞「とても/はるかに」(=much + 比較級、第36・57講応用)
(3) 代名詞「多く」(=much + of ~)
★ 意訳: 「多くの電気を必要とする」
★ 類例(=much + 不可算名詞):
・much time「多くの時間」
・much information「多くの情報」
・much effort「多くの努力」
・much electricity「多くの電気」(=本問!)

! they need much electricity and become very hot の and の繋ぎを取り違える
「(and の繋ぎを取り違え)」

★ and = ここでは動詞句の並列!(=第15講応用)
→ V₁ + and + V₂、共通の主語!
★ 本問: they need much electricity and become very hot.
→ S = they(=incandescent bulbs)
→ V₁ = need much electricity「多くの電気を必要とする」(=他動詞 + O)
→ and
→ V₂ = become very hot「非常に熱くなる」(=自動詞 + C、第54講応用)
★ 並列の構造:
→ they (need much electricity) and (become very hot).
→ V₁ + V₂、共通の主語 they!
★ become + 形容詞 = 「(形容詞)になる」(=変化、第54・57講応用)
→ become very hot「非常に熱くなる」
★ 意訳: 「(白熱電球は)多くの電気を必要とし、非常に熱くなる」
★ 本問の科学的背景:
→ 白熱電球は、エネルギーの約90%が熱になり、光は10%!
→ だから「電気を多く使う」(=効率が悪い)
→ 「熱くなる」(=エネルギーの大半が熱)
→ LED は逆: 90%が光、10%が熱(=効率が良い、省エネ)!
★ 類例(=and で動詞並列、共通の主語):
・She studies hard and gets good grades.「彼女は一生懸命勉強し、いい成績を取る」
・He runs fast and jumps high.「彼は速く走り、高く跳ぶ」
・The dog barks and wags its tail.「犬は吠えて、しっぽを振る」

Q3 so 結果接続詞 vs because

A: It was cold, so I wore a coat. / B: I wore a coat because it was cold.

so と because の違いを分析して訳すと?

分析: 同じ事実を、語順を逆にして表現!
・A: A so B「Aなので B」(=結果が後ろ)
　→ It was cold(=原因) + so + I wore a coat(=結果)
・B: B because A「BなのはAから」(=理由が後ろ)
　→ I wore a coat(=結果) + because + it was cold(=原因)
・同じ事実、語順が逆!
訳:
・A: 「寒かったので、コートを着た」
・B: 「寒かったから、コートを着た」(=同じ意味)
