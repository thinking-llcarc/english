STEP 0 — First Read —

まず、自分で読んでみよう

解説を読む前に必ずやってほしいステップ。「自分はどう読んだか」を意識化することが、読み方を身につける最大の近道です。

Women wearing trousers used to be an unusual sight; now it is completely normal.

STOP. ここで一度立ち止まって。
① まず辞書を引かずに訳してみてください。
② 訳せなくても OK。「どこで詰まったか」を意識してください。
③ 「ここの構造がよく分からない」「この単語の品詞が判別できない」と感じたら、それがあなたの伸びしろです。
STEP 1 — Common Mistakes —

ありがちな誤読を先につぶしておく

この英文で多くの生徒がハマる罠が 6つ あります。先に見ておくことで、自分が同じ罠にハマっていないかチェックできます。

! Women wearing trousers を「ズボンを履いている女性」と訳す
「ズボンを履いている女性は、かつては珍しい光景だった~」

★ Women wearing trousers の判別がカギ!
★ wearing trousers を:
(1) 動名詞とすると → 「女性がズボンを履いていること」(=単数扱い)
(2) 現在分詞とすると → 「ズボンを履いている女性」(=複数扱い)
★ 判別のヒント:
(1)動名詞なら単数形の扱い → is(単数 be 動詞)が来るはず
(2)現在分詞なら複数形の扱い(=Women は複数) → are が来るはず
★ しかし、今回は used to be(=助動詞 used to + 動詞 be、単複どちらでもOK)なので、この基準は使えない!
★ そこで、補語に注目: an unusual sight「珍しい光景」
★ 「女性」=「光景」と考えるのは不自然!
→ よって、(1)動名詞「女性がズボンを履いていること」が適切!

! used to be を「使われた」と誤読
「~は使われた~」

★ used to V = 「かつてはVだった」「以前はVしていた」(=過去の習慣・状態)
★ ≠ 受動態の be used to ~「~に使われる」
★ ≠ be used to V-ing「~することに慣れている」
★ 区別:
① used to V(=動詞の原形)「かつてVだった」(=過去)
② be used to V-ing「Vすることに慣れている」(=現在の慣れ)
③ be used to V「Vするために使われる」(=受動態+to不定詞)
★ 今回 used to be = 「かつては~だった」!
★ used to be an unusual sight = 「かつては珍しい光景だった」

! セミコロン(;)の働きを誤解
「(セミコロンが何を意味するか分からない)」

★ セミコロン(;)の3つの働き:

(1) 切れ目を明確に示す:
例: Science is empirical, rational, general, and cumulative; and it is all four at once.「科学は、経験的で、合理的で、普遍的で、累積的なものであり、この四つを同時に併せもったものである」
→ 複数のand が登場して文がややこしいときに、コンマより大きな切れ目にセミコロンを置く!

(2) 対比を示す:
例: Speech is silver; silence is golden.「雄弁は銀、(一方)沈黙は金」
→ 形式: S₁ V₁; S₂ V₂.(=形からも対比であることが明らか)
→ 訳に「一方」を加えると意味が鮮明に!

(3) 《セミコロン+副詞》で接続詞の代わり:
例: I think; therefore I am.「我思う、故に我あり」
→ ; therefore「それ故」、; on the other hand「一方」、; however「しかしながら」

★ 今回 used to be an unusual sight; now it is completely normal
= (2) 対比を示すセミコロン!
→ 「かつて」 vs 「今」の対比!

! it を「それ」と訳す
「~それはごく普通のことだ」

★ now it is completely normal の it = 前文の主語と同じ内容を指す!
★ つまり、Women wearing trousers(=「女性がズボンを履いていること」)を指す!
★ よって、訳は「(女性がズボンを履いていることは)今ではごく普通のことだ」(=主語を補って訳す or 「それは」と省略)
★ it を「それ」と機械訳すると不自然!

! unusual を「ユニークな」と訳す
「~ユニークな光景~」

★ unusual = 「珍しい/普通でない/異常な」
★ an unusual sight = 「珍しい光景」
★ 同類の訳:
・「あまりない」
・「めったにない」
・「普通でない」
★ 「ユニークな」(=独自の)と訳すのは意味が違う!
★ unique「独特な/比類のない」とは別!

! completely normal を「完全に普通の」と訳す
「完全に普通のこと」

★ completely normal = 「ごく普通の」「まったく普通の」
★ 「完全に普通の」「完全に正常な」は不自然!
★ completely = 「完全に」だが、normal と組み合わさると「ごく」「まったく」と訳す方が自然!
★ 例: It is completely normal to feel nervous before an exam.「試験の前に緊張するのはごく普通のことだ」

STEP 2 — Read Along —

左から右へ、頭の中の実況中継

読める人は、英文を読みながら頭の中で常に何かを「考えて」います。その思考プロセスを 1語ずつ覗いてみましょう。これが英文解釈の正体です。

1 Women wearing trousers ▸ 《名詞+(V)ing》の判別 ─ 動名詞 or 現在分詞？

主語 Women wearing trousers「女性がズボンを履いていること/ズボンを履いている女性」が登場。

★ 《名詞+(V)ing》の判別!(=第44・47講)
→ 2通りの可能性:
(1) 動名詞: wearing trousers が名詞(=動名詞句)
→ Women wearing trousers = 「女性がズボンを履いていること」
→ Women は動名詞の意味上の主語(=単数扱い、第48講)
(2) 現在分詞: wearing trousers が形容詞(=分詞)
→ Women wearing trousers = 「ズボンを履いている女性」(=複数扱い)

★ 判別のヒント:
(1)動名詞なら単数扱い → is が来るはず
(2)現在分詞なら複数扱い → are が来るはず

→ 続きを見て判別!
《名詞+(V)ing》= 動名詞か現在分詞か?(=後ろの動詞で判別)
2 used to be ▸ used to + 動詞 = かつては~だった

used to be「かつては~だった」が動詞句!

★ used to V(=動詞の原形)= 「かつてはVだった」「以前はVしていた」(=過去の習慣・状態)
→ ≠ 受動態の be used to ~「~に使われる」
→ ≠ be used to V-ing「~することに慣れている」

★ used to be ~ = 「かつては~だった」

★ 注意: used to + 動詞は単複どちらでも使える(=助動詞的)!
→ よって、Women wearing trousers が動名詞か現在分詞かを判別する基準としては使えない!

→ 補語に注目して判別!
used to be = 「かつては~だった」(過去の状態)。単複の判別には使えない!
3 an unusual sight ▸ 補語 ─ 「光景」 → 主語の判別ヒント！

補語 an unusual sight「珍しい光景」が登場!

★ an unusual sight = 「珍しい光景」(=補語C)
★ unusual = 「珍しい/普通でない/あまりない/めったにない」

★ 主語の判別!
→ 主語 = 補語 の関係を考える:
(1)動名詞なら「女性がズボンを履いていること」=「珍しい光景」 → ○ 自然!
(2)現在分詞なら「ズボンを履いている女性」=「珍しい光景」 → △ 不自然!(=「女性」=「光景」とは言いにくい)

★ よって、(1)動名詞と判定!
→ Women wearing trousers = 「女性がズボンを履いていること」(=単数扱い)

★ 意味: Women wearing trousers used to be an unusual sight.
= 「女性がズボンを履いていることは、かつては珍しい光景だった」
C = an unusual sight「珍しい光景」 → 主語は動名詞(=「女性がズボンを履いていること」)と確定!
4 ; ▸ セミコロン ─ 対比を示す！

来ました セミコロン(;)!

★ セミコロン(;)の3つの働き:
(1) 切れ目を明確に示す(=複数のand があるときに、より大きな切れ目)
(2) 対比を示す(=形式 S₁ V₁; S₂ V₂、形からも対比が明らか)
(3) 《セミコロン+副詞》で接続詞の代わり(=; therefore / ; on the other hand / ; however)

★ 判別: 今回はセミコロンの後に now(=副詞だが対比的)+ it is という新しい文!
→ セミコロンの前後の文が対比している!
→ 前: 「かつては珍しい光景だった」
→ 後: 「今ではごく普通のことだ」
→ (2) 対比を示すセミコロン!

★ 訳のコツ: セミコロンを「が」「一方」と訳すと、対比が鮮明に!
; = 対比を示すセミコロン!「が」「一方」と訳す。
5 now it is completely normal ▸ 対比の後半 ─ 「今」 vs 「かつて」

後半 now it is completely normal「今ではごく普通のことだ」が登場。

★ now = 「今」(=副詞、前半の used to「かつて」と対比)
★ it = 前文の主語 Women wearing trousers(=「女性がズボンを履いていること」)を指す!
→ 「それ」と機械訳しない!主語を補って訳すと自然。

★ completely normal = 「ごく普通の」「まったく普通の」
→ 「完全に普通の」「完全に正常な」は不自然!

★ 全体の意訳:
直訳: 「女性がズボンを履いていることは、かつては珍しい光景だった。今、それは完全に普通のことだ」
→ 自然な日本語: 「女性がズボンを履いているのは、かつては珍しい光景であったが、今ではごく普通のことだ」
(=セミコロンを「が」と訳して対比、「それは」を主語に補ってもOK)
now it is completely normal = 「今ではごく普通のことだ」(対比の後半)
▼ ここまでの解析を1枚で見る

5つのステップで、左から右へと考えてきたことを構造図にまとめると、こうなります。色分けで見ると、骨格(メイン)と補足の関係が一気にクリアになるはず。

[WomenS₁→S' wearingV' trousers]O' used to助₁ beV₁ an unusual sight;C₁ nowM₂₋₁ itS₂ isV₂ completelyM₂₋₂ normal.C₂.

骨格 = [S₁→動名詞句(Women wearing trousers)] 助₁ V₁ C₁; M₂(now) S₂(it) V₂ M₂(completely) C₂(主語=動名詞句、used to be が動詞、セミコロン=対比、後半は前半と対比した文)
▼ 構造が見えたら、いよいよ訳の仕上げ

構造解析で終わると「結局この文は何を言ってるの？」が宙ぶらりんになりがち。
ここから、直訳 → 中間訳 → 完成訳と、日本語として自然な訳に磨き上げる手順を見ていきます。これも「センス」ではなく、ちゃんと段階的な手順があります。

① 直訳
ズボンを履いている女性は、かつては珍しい光景だった。今、それは完全に普通だ。 構造どおりの直訳。「ズボンを履いている女性」(=動名詞を分詞と誤読)、「完全に普通」が不自然。
▼ 動名詞「女性がズボンを履いていること」と判別 《名詞+(V)ing》の判別!補語「光景」と主語の関係から、動名詞(=単数扱い)と判定。「ズボンを履いている女性」(=分詞)は誤り。
② 中間訳
女性がズボンを履いていることは、かつては珍しい光景であったが、今ではごく普通だ。 「ズボンを履いている女性」を「女性がズボンを履いていること」(=動名詞)に訂正、セミコロンを「が」と意訳、「完全に普通」を「ごく普通」に。
▼ セミコロン(;)を「が」「一方」と意訳 対比を示すセミコロン。前後の文が対比なので、「が」「一方」と訳すと対比が鮮明に。
③ 完成訳
女性がズボンを履いているのは、かつては珍しい光景であったが、今ではごく普通のことだ。 「~ていること」を「~ているのは」と簡潔に、「ごく普通だ」を「ごく普通のことだ」と整える。これで完成。
💡 自然訳の「型」: セミコロン(;)の3つの働き

★ semi- は「半」の意味!例えば a semicircle「半円」、a semiconductor「半導体」。
★ ですから「セミコロン(semicolon)」=「半コロン」!
★ ただし、実際には「セミコロン」の方が「コロン」より用途は多く、「半コロン」と呼ばれるのは少々可哀想なくらい!

★ セミコロンの3つの代表的な用法:

★ (1) 切れ目を明確に示す:
複数の and が登場して文がややこしいときに、「コンマより大きな切れ目」にセミコロンを置くことで、文を分かりやすくする。
例: Science is empirical, rational, general, and cumulative; and it is all four at once.「科学は、経験的で、合理的で、普遍的で、累積的なものであり、この四つを同時に併せもったものである」
→ セミコロン直後の and が「文と文をつなぐ and」であることを明確に示す!
→ セミコロンを訳す必要はない。

★ (2) 対比を示す:
形式: S₁ V₁; S₂ V₂.(=形からも対比であることが明らか)
例: Speech is silver; silence is golden.「雄弁は銀、(一方)沈黙は金」
→ セミコロンの後に and などの接続詞がないことに注意!
→ 訳に「一方」「が」を加えると対比が鮮明に!

★ (3) 《セミコロン+副詞》で接続詞の代わりとして使う:
接続詞を使う煩雑を回避するために、; therefore「それ故」、; on the other hand「一方」、; however「しかしながら」 などの形で用いる。
例: I think; therefore I am.「我思う、故に我あり」

★ 注意: コロン(:)は、主に具体化の役割で用いられる(=セミコロンとは別!)。
例: There are three reasons for the success of Roman Holiday: the story, the location, and the casting.「『ローマの休日』が成功した理由は三つある、物語そのものとその場所、そして配役だ」

Speech is silver; silence is golden. 雄弁は銀、沈黙は金 雄弁は銀、(一方)沈黙は金 (セミコロン = 対比、「一方」を補うと鮮明に)
I think; therefore I am. 我思う、私はある 我思う、故に我あり (; therefore = 「それ故」、接続詞の代わり)
There are three reasons: the story, the location, and the casting. (コロンの役割を理解しない) 三つの理由がある、物語、場所、配役だ (コロン = 具体化、セミコロンとは別)

STEP 3 — Try It Yourself —

同じ思考で、別の英文を読んでみる

読み方は「使えてナンボ」。今日身につけた思考プロセスを、別の英文で試してみましょう。答えを見る前に必ず自分で考えるのがポイント。

Q1 《名詞+(V)ing》= 動名詞 vs 現在分詞

People drinking too much coffee often have trouble sleeping.

People drinking too much coffee の判別と訳は？

判別: 動詞 have(=複数主語に対応) → 主語は複数!
→ よって、現在分詞(=People を修飾)!
訳: 「コーヒーを飲み過ぎる人々はしばしば眠れない」

💡 動名詞なら単数扱い、現在分詞なら複数扱い(=主語が複数の場合)。動詞の単複や補語との関係で判別!
Q2 セミコロン(;)= 対比

In the past, people read books; now, they watch videos.

セミコロンの役割と訳は？

役割: セミコロン = 対比を示す!(=「過去」 vs 「今」)
訳: 「過去には人々は本を読んだ、今では動画を見ている」
または: 「過去には人々は本を読んでいたが、今では動画を見ている」

💡 セミコロン = 「が」「一方」と意訳すると対比が鮮明に!
Q3 used to V vs be used to V-ing

I used to live in Tokyo, but now I am used to living in Osaka.

2つの used to の違いは？

違い:
・used to V(=動詞の原形)= 「かつてはVだった」(=過去)
・be used to V-ing(=動名詞)= 「Vすることに慣れている」(=現在の慣れ)
訳: 「私はかつて東京に住んでいたが、今は大阪に住むことに慣れている」

💡 後の動詞の形(V or V-ing)で区別!be 動詞の有無も大事。
