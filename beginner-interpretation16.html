▶ 節の登場

節を含む文を、左から右に丁寧に読む

Online Cram School THINKING
▶ THIS LESSON

この講で身につく「読み方」

第16講のテーマは 「節(=SVを含むかたまり)を扱う」。
ここから標準編。文章の中に「主語+動詞」を含むかたまり(=節)が登場します。
because, while, so といった接続詞が、節と節を結びます。
でも怖がらないで ─ 左から右に追って、節の境目を見つけながら積み上げるのが基本姿勢です。

今日のキー:
① 節 = SVを含むかたまり(=主節と従属節)
② because S V「~なので」(=理由を表す副詞節)
③ so「~なので/だから」(=結果を表す等位接続詞、文と文をつなぐ)
④ while S V「~する間」(=時を表す副詞節)
⑤ 群動詞 ran into ~「~に駆け込む」(=第6講・第10講応用)
靴職人との出会いを描く物語を題材に、節を含む文を読み解きます!

1
節(=SVを含むかたまり)を見抜く力を養います。
2
従属接続詞(because, while)と等位接続詞(so)を区別します。
3
群動詞 run into ~「~に駆け込む」を覚えます。
STEP 0 — First Read —

まず、自分で読んでみよう

解説を読む前に必ずやってほしいステップ。「自分はどう読んだか」を意識化することが、読み方を身につける最大の近道です。

I met him first on a summer day in 1936. I ran into his poor little shop because the heels of my shoes needed to be repaired. It didn't seem a difficult job, so I waited while he did it.

STOP. ここで一度立ち止まって。
① まず辞書を引かずに訳してみてください。
② 訳せなくても OK。「どこで詰まったか」を意識してください。
③ 「ここの構造がよく分からない」「この単語の品詞が判別できない」と感じたら、それがあなたの伸びしろです。
STEP 1 — Common Mistakes —

ありがちな誤読を先につぶしておく

この英文で多くの生徒がハマる罠が 6つ あります。先に見ておくことで、自分が同じ罠にハマっていないかチェックできます。

! I met him first on a summer day in 1936. の first を「最初の」と形容詞で訳す
「私は最初の彼に会った~」(=不自然)

★ first = 多義語!
(1) 形容詞「最初の」(=順序)
(2) 副詞「初めて」(=本問)
★ 本問: I met him first = 「私は彼に初めて会った」(=副詞用法)
→ first は動詞 met を修飾!
★ 意訳: 「私が初めて彼に会ったのは~」(=主題を強調する自然な訳)
★ on a summer day in 1936 = 「1936年の夏の日に」(=前置詞句で時間を示す)
★ 類例:
・I first met him in 2010.「私は2010年に初めて彼に会った」
・She first came to Japan last year.「彼女は去年、初めて日本に来た」

! ran into を「~に走り込んだ」とそのまま訳す
「~に走り込んだ~」(=やや硬い)

★ run into ~ = 群動詞(=動詞+前置詞、第10講応用)!
★ 意味:
(1) 「~に駆け込む」(=本問、急いで入る)
(2) 「~にばったり出会う」(=偶然)
(3) 「~に衝突する」
★ 本問: I ran into his poor little shop = 「彼の小さな粗末な店に駆け込んだ」
→ 急いで店に入った、というニュアンス!
★ poor little shop:
→ poor = 「貧しい/粗末な」(=形容詞)
→ little = 「小さい」(=形容詞)
→ 「小さな粗末な店」
★ 類例(=run の群動詞):
・run into a friend「友達にばったり会う」
・run out of ~「~を使い果たす」
・run after ~「~を追いかける」

! because S V の従属節を、文の骨格と勘違いする
「(because節を文のメインだと思って混乱)」

★ because = 従属接続詞「~なので/~だから」
★ because S V = 副詞節「~なので」(=理由を表す)
★ 本問: I ran into his poor little shop because the heels of my shoes needed to be repaired.
→ 主節: I ran into his poor little shop「彼の小さな粗末な店に駆け込んだ」
→ 従属節: because the heels of my shoes needed to be repaired「靴のかかとを修理してもらう必要があったので」
★ 従属節は文の骨格(=主節)に対する補足!
★ 判別: because の後ろはSV(=主語+動詞のかたまり)が必ず来る!
★ 類似の従属接続詞:
・because「~なので」(=理由)
・when「~するとき」(=時)
・while「~する間」(=時)
・if「もし~なら」(=条件)
・although「~だけれども」(=譲歩)
★ いずれもSV を後ろに従えて副詞節を作る!

! needed to be repaired の to be repaired の役割を取り違える
「(to be repaired が何の役割か分からない)」

★ to be repaired = 不定詞 + 受動態!
→ to be + 過去分詞 = 「~される」(=不定詞の受動態)
★ 本問: the heels of my shoes needed to be repaired
→ need = 他動詞「~を必要とする」(=後ろに目的語が必要)
→ 目的語 = to be repaired「修理されることを」(=不定詞の名詞的用法)
→ つまり、「靴のかかと(=主語) は 修理されることを必要としていた」
★ 意訳: 「靴のかかとを修理してもらう必要があった」(=主語の視点を変えて自然に)
★ 不定詞の3用法(=第11講応用):
(1) 名詞的用法「~すること」(=本問、needの目的語)
(2) 形容詞的用法「~するための」
(3) 副詞的用法「~するために」
★ to be repaired(=受動の不定詞)も同じく3用法あるが、本問は名詞的用法!

! It didn't seem a difficult job の It を「それ」と訳す
「それは難しい仕事ではなさそうだった~」

★ It は前文の内容(=靴のかかとを修理すること)を受ける代名詞(=第14講応用)
★ It didn't seem a difficult job = 「(それは)難しい仕事ではなさそうだった」
★ seem = 「~のように見える/~のように思われる」(=不完全自動詞、補語が必要)
★ seem + 名詞/形容詞 = 「~であるように見える」
★ 本問: seem a difficult job「難しい仕事のように見える」
→ 否定 didn't で「難しい仕事ではなさそう」
★ 意訳: 「難しい仕事ではなさそうだった」(=「それ」を省略して自然に)
★ 類似の動詞:
・seem「~に見える/思われる」
・look「~に見える」
・appear「~のように見える」
・become「~になる」

! so と while を区別せずに訳す
「(so と while の役割を一括で「~なので」と取る)」

★ so ≠ while!

★ so = 等位接続詞「~なので/だから」(=結果)
→ 文と文をつなぐ(=本問: It didn't seem ~, so I waited ~)
→ 「~ので、(その結果)~した」
★ while = 従属接続詞「~する間」(=時)
→ 副詞節を作る(=本問: while he did it「彼がそれをする間」)
→ 主節に対する補足情報
★ 本問の構造:
→ It didn't seem a difficult job「(それは)難しい仕事ではなさそうだった」
→ , so(=結果、文をつなぐ)
→ I waited「私は待った」
→ while he did it「彼が(それを)する間」(=副詞節、I waited の補足)
★ 意訳: 「難しい仕事ではなさそうだったので、彼が作業をする間、私は待っていた」

STEP 2 — Read Along —

左から右へ、頭の中の実況中継

読める人は、英文を読みながら頭の中で常に何かを「考えて」います。その思考プロセスを 1語ずつ覗いてみましょう。これが英文解釈の正体です。

1 I met him first on a summer day in 1936. ▸ 1文目 ─ 初めて出会った日

1文目 I met him first on a summer day in 1936.「私は1936年の夏の日に初めて彼に会った」!

★ S = I「私」
★ V = met「会った」(=他動詞)
★ O = him「彼を」
★ first = 副詞「初めて」(=形容詞「最初の」ではない!)
→ 動詞 met を修飾

★ on a summer day in 1936 = 前置詞句「1936年の夏の日に」(=時間)
→ 〈前置詞句〉は骨格に入らない補足情報(=第6講)

★ 骨格: SVO「私は彼に会った」
★ 意訳: 「私が初めて彼に会ったのは1936年の夏の日だった」
→ 「初めて」を主題化、「~のは~だった」と日本語的に
S=I / V=met / O=him / 副 first / 〈時間補足〉。「私が初めて彼に会ったのは1936年の夏の日だった」
2 I ran into his poor little shop ▸ 2文目 ─ 群動詞 run into で店に駆け込む

2文目スタート I ran into his poor little shop「彼の小さな粗末な店に駆け込んだ」!

★ S = I「私」
★ V = ran into(=群動詞、第10講応用)
→ 「~に駆け込む」(=本問の意味)
→ 「~に偶然出会う」「~に衝突する」も!

★ O = his poor little shop「彼の小さな粗末な店」
→ poor「貧しい/粗末な」
→ little「小さい」
→ 形容詞2つで shop を修飾!

★ 骨格: SVO(=ran into を1つの他動詞として捉える)
★ 意訳: 「彼の小さな粗末な店に駆け込んだ」

→ 後ろに「なぜ駆け込んだか?」が来るはず!
S=I / V=ran into(=群動詞) / O=his poor little shop。「彼の小さな粗末な店に駆け込んだ」
3 because the heels of my shoes needed to be repaired. ▸ because節 ─ 理由を表す副詞節

来ました because the heels of my shoes needed to be repaired.「靴のかかとを修理してもらう必要があったので」!

★ because = 従属接続詞「~なので/~だから」(=理由)
→ 後ろにSV を含む節(=副詞節)が来る!

★ because節の中:
→ S' = the heels of my shoes「靴のかかと」
→ V' = needed「必要としていた」(=他動詞)
→ O' = to be repaired「修理されること」(=不定詞の名詞的用法、受動)

★ 不定詞の受動 to be + 過去分詞「~されること」
→ to be repaired = 「修理されること」
→ 「靴のかかと」は修理する側ではなく、修理される側!

★ 意訳:
→ 直訳: 「靴のかかとが修理されることを必要としていた」
→ 自然: 「靴のかかとを修理してもらう必要があった」

★ because 節は主節 I ran into his poor little shop の理由を示す!
→ 「修理してもらう必要があったので、駆け込んだ」

★ 2文目の意訳: 「靴のかかとを修理してもらう必要があったので、彼の小さな粗末な店に駆け込んだ」
because節 = 副詞節「~なので」(=主節の理由)。中身は SVO(=needed の O が to be repaired)
4 It didn't seem a difficult job, ▸ 3文目スタート ─ It seem ~「~のように見えた」

3文目 It didn't seem a difficult job,「(それは)難しい仕事ではなさそうだった」!

★ S = It「それ」(=前文の修理作業を指す代名詞、第14講応用)
★ V = didn't seem「~のように思われなかった」
★ C = a difficult job「難しい仕事」(=補語)

★ seem = 「~のように見える/思われる」(=不完全自動詞)
→ seem + 名詞/形容詞 = 「~であるように見える」
→ 否定形 didn't seem で「~ではないように見えた」

★ 意訳: 「難しい仕事ではなさそうだった」(=「それは」を省略)

★ コンマ → 後ろに何か続く!
S=It(=前文の修理を指す) / V=didn't seem / C=a difficult job「難しい仕事ではなさそうだった」
5 so I waited ▸ so ─ 等位接続詞「~なので/だから」

来ました so I waited「だから私は待った」!

★ so = 等位接続詞「~なので/だから」(=結果)
→ 文と文をつなぐ!
→ 「~ので、(その結果)~した」

★ because との違い:
→ because = 従属接続詞、後ろに理由(=副詞節)
→ so = 等位接続詞、後ろに結果(=主節)
→ どちらも因果関係を示すが、因と果の位置が逆!

★ 本問の流れ:
→ 「難しい仕事ではなさそうだった(=因)」
→ so「だから/その結果」
→ 「私は待った(=果)」

★ S = I「私」
★ V = waited「待った」(=自動詞)

→ 後ろに「いつ待ったか」が来るはず!
so = 等位接続詞「だから」(=結果、文と文をつなぐ)。S=I / V=waited「だから私は待った」
6 while he did it. ▸ while節 ─ 時を表す副詞節

最後に while he did it.「彼がそれをする間」!

★ while = 従属接続詞「~する間」(=時)
→ 後ろにSV を含む節(=副詞節)が来る!

★ while節の中:
→ S' = he「彼」
→ V' = did「した」(=他動詞)
→ O' = it「それ(=修理作業)」

★ while he did it = 「彼がそれ(=修理)をする間」
→ 主節 I waited「私は待った」の時を表す副詞節!
→ 「彼が作業をする間、私は待った」

★ 3文目の意訳: 「難しい仕事ではなさそうだったので、彼が作業をする間、私は待っていた」

★ 全体の流れ:
→ 1文目: 出会いの設定(=1936年の夏)
→ 2文目: なぜ店に駆け込んだか(=靴の修理)
→ 3文目: 仕事を待つ間の様子
→ 物語の自然な流れ!

★ 節を含む文でも、左から右に追えば自然に意味が見えてくる!
while節 = 副詞節「~する間」(=主節の時を補足)。「彼が作業をする間、私は待っていた」
▼ ここまでの解析を1枚で見る

6つのステップで、左から右へと考えてきたことを構造図にまとめると、こうなります。色分けで見ると、骨格(メイン)と補足の関係が一気にクリアになるはず。

I met him firstS V O 副 〈on a summer day in 1936〉. M I ran into his poor little shopS V O [because the heels of my shoes needed to be repaired]. 副詞節 It didn't seem a difficult jobS V C , so等位接 I waitedS V [while he did it].副詞節.

骨格 = 1文目: SVO 副 〈M〉. 2文目: SVO [because S' V' O']. 3文目: SVC, so SV [while S' V' O'].(節を含む文。because/while=従属接続詞で副詞節、so=等位接続詞で文をつなぐ。各節を「左から右に」処理!)
▼ 構造が見えたら、いよいよ訳の仕上げ

構造解析で終わると「結局この文は何を言ってるの？」が宙ぶらりんになりがち。
ここから、直訳 → 中間訳 → 完成訳と、日本語として自然な訳に磨き上げる手順を見ていきます。これも「センス」ではなく、ちゃんと段階的な手順があります。

① 直訳
私は1936年の夏の日に最初に彼に会った。私の靴のかかとは修理されることを必要としていたので、私は彼の貧しい小さな店に走り込んだ。それは難しい仕事のように思えなかったので、私は彼がそれをする間、待った。 構造どおりの直訳。「最初に」「修理されることを必要としていた」「走り込んだ」「思えなかった」が硬く、物語的でない。
▼ 節 = SV を含むかたまり 本問は because節 / while節 を含む文!各節を左から右に処理!
② 中間訳
私は1936年の夏の日に初めて彼に会った。靴のかかとを修理してもらう必要があったので、彼の小さな粗末な店に駆け込んだ。難しい仕事ではなさそうだったので、彼が作業をする間、私は待った。 「最初に」を「初めて」、「貧しい小さな店」を「小さな粗末な店」、「走り込んだ」を「駆け込んだ」、「思えなかった」を「~なさそうだった」に意訳。
▼ because S V「~なので」(=理由を表す副詞節) 従属接続詞!後ろにSV を含む節が必ず来る。主節に対する補足情報。
③ 完成訳
私が初めて彼に会ったのは1936年の夏の日だった。靴のかかとを修理してもらう必要があったので、彼の小さな粗末な店に駆け込んだ。難しい仕事ではなさそうだったので、彼が作業をする間、私は待っていた。 「初めて~したのは~だった」と主題を強調。「待った」を「待っていた」(=継続)に。物語の臨場感が出る!
💡 自然訳の「型」: 節を含む文 ─ 怖がらず左から右に追う

★ 節とは?

★ (1) 主節: 文の骨格となる節(=なくてはならない)
★ (2) 従属節: 主節に従属する節(=補足情報)

★ 従属接続詞(=従属節を導く):
・because「~なので」(=理由)
・when「~するとき」(=時)
・while「~する間」(=時)
・if「もし~なら」(=条件)
・although「~だけれども」(=譲歩)
・that「~ということ」(=名詞節)

・and「そして」
・but「しかし」
・or「または」

★ 本問の構造:

(1) 主節をまず把握
(2) 従属接続詞が出たら、そこから先は副詞節と認識
(3) 副詞節の中身もSVを含むので、その内部もSVO等の構造で読む
(4) 副詞節が終わったら(=ピリオドやコンマで)、主節の続きへ

★ 大事なのは、節の境目をはっきり認識すること!
★ そうすれば、いくら長い文でも左から右に処理できる!

★ これからの60講では、節を含む文がどんどん登場します。節の境目を見抜き、ひとつずつ処理する姿勢を!

I went home because I was tired. (because節を文のメインと取る) 私は疲れていたので、家に帰った (主節=I went home / 副詞節=because I was tired)

1 左から右へ、1語ずつ品詞と役割を確定する
→

→

この一連の流れが、英文解釈の全プロセスです。「構造が見えた」だけで満足せず、必ず最後の「自然な訳」まで仕上げる習慣を、今日からつけていきましょう。

STEP 3 — Try It Yourself —

同じ思考で、別の英文を読んでみる

読み方は「使えてナンボ」。今日身につけた思考プロセスを、別の英文で試してみましょう。答えを見る前に必ず自分で考えるのがポイント。
知識として「覚える」のではなく、手を動かして「使える」状態に持っていきます。

Q1 because 副詞節 ─ 理由

I stayed home because it was raining.

because節の役割と訳は？

分析: because S V = 副詞節「~なので」
・主節: I stayed home「私は家にいた」
・副詞節: because it was raining「雨が降っていたので」
訳: 「雨が降っていたので、私は家にいた」

💡 because は従属接続詞!後ろにSV(=主語+動詞)が必ず来る!
Q2 so 等位接続詞 ─ 結果

It was hot, so we went swimming.

so の役割と訳は？

分析: so = 等位接続詞「~なので/だから」(=結果)
→ 文と文をつなぐ!
・前: It was hot「暑かった」(=因)
・後: we went swimming「泳ぎに行った」(=果)
訳: 「暑かったので、泳ぎに行った」

💡 because と so の違い: because=後ろが理由、so=後ろが結果!
Q3 while 副詞節 ─ 時

I read a book while she was cooking.

while節の役割と訳は？

分析: while S V = 副詞節「~する間」
・主節: I read a book「私は本を読んだ」
・副詞節: while she was cooking「彼女が料理をしている間」
訳: 「彼女が料理をしている間、私は本を読んだ」

💡 while も従属接続詞!主節の時を補足する副詞節!
STEP 4 — Your Reading Algorithm —

これからの英文に使える「思考フロー」

最後に、今日の学びを初見の英文に使える型として整理しておきます。これを毎回頭の中で回せば、確実に読める英文が増えていきます。

1
節 = SV を含むかたまりと理解
1つの文に複数のSVが並ぶことがある(=接続詞があるから)。
2
主節と従属節を区別
主節=文の骨格、従属節=主節に従属する補足情報。
3
従属接続詞(because, when, while, if, although, that等)
後ろにSV を含む節が来て、副詞節 or 名詞節を作る!
4
等位接続詞(and, but, or, so)
対等な要素(=単語、句、節)をつなぐ!so は「結果」のニュアンス。
5
because と so の違い
because後=理由、so後=結果!因と果の位置が逆。
6
節の境目をはっきり認識
従属接続詞・等位接続詞の位置で節を区切り、ひとつずつ処理!
7
群動詞 run into ~「~に駆け込む/~に出会う」
run + 前置詞 で1つの動詞のように働く(=第10講応用)。
8
不定詞の受動 to be + 過去分詞「~されること」
to be repaired「修理されること」(=不定詞の名詞的用法)!主語が動作の対象。

  • 従属接続詞(because, when, while, if, although, that等)を覚えた
  • 等位接続詞(and, but, or, so)との違いを理解した
  • because と soの違い(=因と果の位置が逆)が分かる

  • 不定詞の受動 to be + 過去分詞「~されること」を理解
  • 多義語 first(形容詞「最初の」 vs 副詞「初めて」)を区別
  • 多義語 seem「~のように見える/思われる」を覚えた
