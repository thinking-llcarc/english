STEP 0 — First Read —

まず、自分で読んでみよう

解説を読む前に必ずやってほしいステップ。「自分はどう読んだか」を意識化することが、読み方を身につける最大の近道です。

It is tough to live in Antarctica for a number of reasons. The biggest problem is that Antarctica is the coldest place on Earth, and about 98% is covered in ice.

STOP. ここで一度立ち止まって。
① まず辞書を引かずに訳してみてください。
② 訳せなくても OK。「どこで詰まったか」を意識してください。
③ 「ここの構造がよく分からない」「この単語の品詞が判別できない」と感じたら、それがあなたの伸びしろです。
STEP 1 — Common Mistakes —

ありがちな誤読を先につぶしておく

この英文で多くの生徒がハマる罠が 6つ あります。先に見ておくことで、自分が同じ罠にハマっていないかチェックできます。

! It is tough to live in Antarctica の It を「それ」と訳す
「それは南極に住むには厳しい~」(=形式主語を見落とす)

★ It is ~ to V = 形式主語の構文!
→ It = 仮主語(=訳さない!)
→ to V = 真主語「~すること」
★ 本問: It is tough to live in Antarctica
→ It = 仮主語
→ to live in Antarctica = 真主語「南極で生活すること」
→ tough = 形容詞「厳しい/大変な」
★ 意訳: 「南極で生活するのはとても大変だ」(=「~するのは~だ」のリズム)
★ 判別ヒント: It を「それ」と訳して意味不明 → 形式主語を疑う!
★ It is ~ to V パターン:
・It is fun to study English.「英語を学ぶのは楽しい」
・It is important to be honest.「正直であることは大切だ」
・It is hard to wake up early.「早起きは難しい」
★ 核心: 主語が長い to V のとき、それを後ろに置いて、形式主語 It を頭に立てる!読みやすくするため!

! tough を「タフ」とカタカナで訳す
「タフに~」(=やや硬い)

★ tough = 形容詞「厳しい/大変な/つらい」
★ 本問: It is tough to live ~「~するのは大変だ」
★ tough の用法:
(1) 「厳しい/大変な」(=本問)
(2) 「丈夫な/頑丈な」
(3) 「強い/タフな」(=人の性格)
★ 類例:
・a tough day「大変な一日」
・tough conditions「厳しい条件」
・a tough question「難しい質問」
★ 意訳: 「とても大変だ/厳しい」(=自然な日本語)
★ カタカナ「タフ」を避けるが、文脈によっては意味がわかりやすいことも

! for a number of reasons の a number of を「~の数」と取る
「(a number of の慣用を取り違える)」

★ a number of ~ = 慣用「いくつもの~/たくさんの~」(=不定冠詞、第24講応用)
★ 注意: the number of ~(=「~の数」)とは違う!
(1) the number of ~「~の数」(=定冠詞、第24・32講)
(2) a number of ~「いくつもの~/多くの~」(=不定冠詞、本問)
★ 本問: for a number of reasons = 「いくつもの理由で」
★ 類例:
・a number of students「いくつもの生徒/多くの生徒」
・a number of problems「いくつもの問題」
・a number of ways「いくつもの方法」
★ 意訳: 「いくつもの理由で」(=複数の理由を含意)
★ for ~ = 前置詞「~のために/~の理由で」

! The biggest problem is that ~ の that 節 の役割を取り違える
「(that 節を関係詞節と取って混乱)」

★ 核心: that 節が be 動詞の補語(=C)として働く!
★ 本問: The biggest problem is that ~
→ S = The biggest problem「最大の問題」
→ V = is(=be動詞)
→ C = that 節「~ということ/~であること」
→ 第2文型 SVC「S = C(=that 以下)」
★ 意訳: 「最大の問題は~であることだ」
★ that = 名詞節を作る接続詞「~ということ」(=第18・22講応用)
→ that 節は名詞節!
→ 文中の主語・目的語・補語のいずれにもなる!
★ 類例(=be C(=that 節)):
・The fact is that he lied.「事実は彼が嘘をついたことだ」
・The truth is that I don't know.「真実は私が知らないことだ」
・My hope is that you succeed.「私の希望は君が成功することだ」
★ The biggest problem = 最上級「最大の問題」(=big の最上級+定冠詞 the)

! the coldest place on Earth の最上級を見落とす
「(coldest の最上級を見落とす)」

★ the coldest place = 最上級「最も寒い場所」
→ cold(=寒い)+ -est(=最上級語尾)+ 定冠詞 the
→ 短い形容詞の最上級は -est!
★ 本問: Antarctica is the coldest place on Earth
→ S' = Antarctica「南極大陸」
→ V' = is(=be動詞)
→ C' = the coldest place「最も寒い場所」
→ on Earth = 前置詞句「地球で」(=最上級の範囲を限定)
★ 意訳: 「南極は地球で最も寒い場所」
★ on Earth = 「地球上で/地球で」(=on は接触の意味)
★ 最上級の作り方(=第32講応用):
・短い形容詞: -est(=cold→coldest, big→biggest)
・長い形容詞: most + 形容詞(=most beautiful)
・不規則: good→best, bad→worst
★ place on Earth「地球上の場所」 ─ 範囲を限定!

! about 98% is covered in ice の主語を取り違える
「(主語が省略されているように見えて混乱)」

★ about 98% = 主語「約98%」(=数値が主語!)
→ about「およそ/約」(=第19講応用)
→ 98% = 名詞(=主語)
★ 本問: about 98% is covered in ice
→ S' = about 98%「約98%」(=of Antarctica が省略、文脈で南極の98%)
→ V' = is covered「覆われている」(=受動態、第19講応用)
→ in ice = 前置詞句「氷に」
★ be covered in ~ = 「~に覆われている」(=受動態の慣用、第19講応用)
★ 意訳: 「(その)約98%は氷に覆われている」
★ and が文と文をつなぐ(=第15講応用):
→ 前: Antarctica is the coldest place on Earth
→ 後: about 98% is covered in ice
→ 主語が「南極」と「南極の約98%」(=連動)
★ 受動態の構造: be + 過去分詞 = 「~される」
→ cover(=他動詞「覆う」)→ covered(=過去分詞)→ be covered(=覆われる)

STEP 3 — Try It Yourself —

同じ思考で、別の英文を読んでみる

読み方は「使えてナンボ」。今日身につけた思考プロセスを、別の英文で試してみましょう。答えを見る前に必ず自分で考えるのがポイント。
知識として「覚える」のではなく、手を動かして「使える」状態に持っていきます。

Q1 形式主語 It is ~ to V

It is fun to play soccer.

It の役割と訳は？

分析: It = 仮主語(=訳さない!)
・to play soccer = 真主語「サッカーをすること」
・fun = 形容詞「楽しい」(=補語)
訳: 「サッカーをするのは楽しい」

💡 文頭 It is ~ + to V → 形式主語!It は訳さず、to V を主語として読む!
Q2 be C(=that 節)

The problem is that I have no money.

that 節の役割と訳は？

分析: be 動詞の後ろの that 節 = 補語C!
・S = The problem「問題」
・V = is
・C = that I have no money「お金がないこと」
訳: 「問題は、お金がないことだ」

💡 be C(=that 節) = 「~は~であることだ」!主語の核心を that 節で説明!
Q3 be covered in ~

The mountain is covered in snow.

構造と訳は？

分析: be covered in/with ~ = 受動態の慣用「~に覆われている」(=第19講応用)
・S = The mountain「山」(=覆われる側)
・V = is covered(=受動態)
・in snow = 前置詞句「雪に」
訳: 「その山は雪に覆われている」

💡 be + 過去分詞 = 受動態「~される」!主語が動作の対象!
STEP 4 — Your Reading Algorithm —

これからの英文に使える「思考フロー」

最後に、今日の学びを初見の英文に使える型として整理しておきます。これを毎回頭の中で回せば、確実に読める英文が増えていきます。

1
形式主語 It is ~ to V「~するのは~だ」
It = 仮主語(=訳さない!)、to V = 真主語!主語が長くなりすぎないようにする!
2
形式主語のバリエーション
It is ~ to V / It is ~ that S V / It is ~ V-ing!
3
頻出パターン
It is fun/important/hard/necessary/tough to V!
4
be C(=that 節)「~は~であることだ」
be 動詞の後ろの that 節 = 補語!The problem/fact/truth is that ~!
5
受動態 be covered in ~「~に覆われている」(=第19講応用)
be + 過去分詞 = 受動態「~される」!主語が動作の対象!
6
a number of ~「いくつもの~」(=第24講応用)
the number of ~「~の数」(=定冠詞)とは違う!不定冠詞 a で「多数」!
7
最上級 the + -est(=第32講応用)
the coldest place / the biggest problem!短い形容詞は -est、長い形容詞は most + 形容詞!
8
最上級の範囲限定: on Earth, in the world
the coldest place on Earth「地球で最も寒い場所」!範囲を前置詞句で限定!
