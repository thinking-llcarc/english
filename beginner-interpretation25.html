第25講のテーマは 「since の2つの顔」+「so ~ that の結果構文」。
since は時間「~以来」と理由「~なので」の2つの顔を持つ多義の接続詞。
また so ~ that は「あまりに~なので~」を作る頻出の構文です。

STEP 0 — First Read —

まず、自分で読んでみよう

解説を読む前に必ずやってほしいステップ。「自分はどう読んだか」を意識化することが、読み方を身につける最大の近道です。

Since the history of mankind began, we have worked very hard to make our lives better. We worked so hard that we damaged the environment without caring. Now the earth has many problems because of us.

STOP. ここで一度立ち止まって。
① まず辞書を引かずに訳してみてください。
② 訳せなくても OK。「どこで詰まったか」を意識してください。
③ 「ここの構造がよく分からない」「この単語の品詞が判別できない」と感じたら、それがあなたの伸びしろです。
STEP 1 — Common Mistakes —

ありがちな誤読を先につぶしておく

この英文で多くの生徒がハマる罠が 6つ あります。先に見ておくことで、自分が同じ罠にハマっていないかチェックできます。

! Since the history of mankind began の Since を「~なので」と訳す
「人類の歴史が始まったので~」(=理由と取って意味不明に)

★ since = 多義の接続詞!
(1) 「~以来/~してから」(=時間、本問!)
(2) 「~なので/~だから」(=理由)
★ 判別ルール:
→ 時間表現と一緒、主節が現在完了 → 時間「~以来」!
→ 主節が因果関係を含む内容 → 理由「~なので」!
★ 本問: Since the history of mankind began, we have worked ~
→ 主節 have worked = 現在完了!(=第13講応用)
→ 「~以来、ずっと~してきた」のパターン!
→ Since = 「~以来」!
★ 意訳: 「人類の歴史が始まって以来、私たちは~してきた」
★ 類例:
・Since I came to Japan, I have lived in Tokyo.「日本に来て以来、東京に住んでいる」(=時間)
・Since you are tired, you should rest.「疲れているのだから、休んだ方がいい」(=理由)
★ 核心: since + 過去の出来事 + 主節が現在完了 → 「~以来」!

! we have worked very hard を単純過去で訳す
「私たちは懸命に働いた~」(=現在完了のニュアンスが消える)

★ have worked = 現在完了(=継続、第13講応用)!
→ 「(過去から現在まで)~してきた」
★ 本問: we have worked very hard = 「私たちは懸命に働いてきた」
→ 単純過去 worked(=過去で完結)とは違う!
→ 過去から現在まで継続している!
★ very hard = 副詞「とても懸命に」(=程度)
★ hard は副詞・形容詞両方!
・形容詞: a hard task「難しい仕事」
・副詞: work hard「懸命に働く」(=本問)
★ 意訳: 「懸命に働いてきた」

! to make our lives better を「私たちの生活が良いことを作る」と直訳
「(make + O + C のパターンを取り違える)」

★ to make our lives better = 不定詞の副詞的用法「私たちの生活をより良くするために」(=目的、第8講応用)
★ make A B = 第5文型「AをBにする」(=第13講応用)
→ A = our lives「私たちの生活」
→ B = better「より良い」(=形容詞 good の比較級)
→ 「生活をより良くする」
★ 不定詞の副詞用法: to V「~するために」
→ 動詞 have worked を修飾(=なぜ働いてきたか?)
★ 意訳: 「生活をより良くするために、(懸命に)働いてきた」
★ our lives = 「私たちの生活」(=lifeの複数形)
★ better = good の比較級「より良い」

! We worked so hard that we damaged ~ の構造を取り違える
「(so と that を別々に取って混乱)」

★ so ~ that ~ = 結果構文「あまりに~なので~」
★ 本問: We worked so hard that we damaged the environment without caring.
→ 前: so hard「あまりに懸命に」(=so + 副詞)
→ 後: that we damaged the environment ~「(その結果)環境を傷つけた」
★ 意訳: 「あまりに懸命に働いた結果、環境を傷つけた」
★ パターン:
・so + 形容詞/副詞 + that S V「あまりに~なので、SはVする」
・前=原因(=程度がひどい)、後=結果
★ 類例:
・She is so kind that everyone loves her.「彼女はとても親切なので、皆に愛される」
・It was so cold that I couldn't go out.「あまりに寒くて、外出できなかった」
★ 判別: so + 形容詞/副詞 を見たら、後ろに that 節が来るかチェック!

! without caring の caring の役割を取り違える
「(caring が動名詞だと気づかない)」

★ without caring = 「気にせずに/気にかけることなしに」(=前置詞句)
★ without = 前置詞「~なしに」
★ caring = 動名詞「気にかけること」
→ care(=動詞「気にかける」)+ -ing で動名詞「気にかけること」
★ 前置詞 + 動名詞のパターン!
→ 前置詞の後ろは名詞 → 動詞を名詞化(=動名詞)して使う
★ 本問: we damaged the environment without caring
→ 「気にもかけずに環境を傷つけた」
★ 類例(=前置詞+動名詞):
・without thinking「考えずに」
・before going「行く前に」
・after eating「食べた後で」
・by reading「読むことによって」
★ 意訳: 「気にも留めずに/気にかけることなく」(=自然な日本語)

! because of us の because of を because と区別しない
「(because と because of の違いを意識しない)」

★ because ≠ because of!
(1) because = 接続詞「~なので」(=後ろに SV)
(2) because of = 群前置詞「~のせいで」(=後ろに名詞)
★ 本問: because of us = 「私たちのせいで」
→ us(=代名詞、目的格)が後ろに来る → 群前置詞!
★ 類例:
・because of the rain「雨のせいで」
・because of you「あなたのせいで/おかげで」
・because of his help「彼の助けのおかげで」
★ 判別ルール:
→ 後ろに名詞 → because of(=群前置詞)
→ 後ろに SV → because(=接続詞)
例: because it rained(=接続詞)/ because of the rain(=群前置詞)
★ 意訳: 「私たちのせいで」(=ネガティブな原因)

★ 第25講で身につけてほしい多義語の判別力を伝えます。

★ 英語の中には、文脈によって意味が変わる多義語があります。第25講のテーマは since!

★ since の2つの顔:

STEP 3 — Try It Yourself —

同じ思考で、別の英文を読んでみる

読み方は「使えてナンボ」。今日身につけた思考プロセスを、別の英文で試してみましょう。答えを見る前に必ず自分で考えるのがポイント。

Q1 since の時間用法

Since 2010, I have lived in Tokyo.

since の用法と訳は？

分析: since 2010 = 「2010年以来」(=時間)
・主節: I have lived in Tokyo「東京に住んでいる」(=現在完了)
・since + 過去の年 + 主節が現在完了 → 「~以来」!
訳: 「2010年以来、東京に住んでいる」

💡 since + 時間表現 + 主節が現在完了 → 「~以来」!
Q2 結果構文 so ~ that ~

It was so hot that I couldn't sleep.

構造と訳は？

分析: so + 形容詞 + that 節 = 結果構文「あまりに~なので~」
・前: It was so hot「あまりに暑かった」
・後: that I couldn't sleep「眠れなかった」(=結果)
訳: 「あまりに暑くて眠れなかった」

💡 so + 形容詞/副詞 + that 節!前=原因、後=結果!
Q3 because of ~ 群前置詞

The match was canceled because of the rain.

because of ~ の役割と訳は？

分析: because of ~ = 群前置詞「~のせいで」
→ 後ろに名詞 the rain「雨」
訳: 「試合は雨のせいで中止になった」

💡 because(接続詞、後ろにSV)と because of(群前置詞、後ろに名詞)を区別!
