▶ 主語の見極め

長くなった主語に振り回されない

Online Cram School THINKING
▶ THIS LESSON

この講で身につく「読み方」

第3講のテーマは 「長い主語の見抜き方」。
英語の主語は、第1講・第2講のように1語で済むこともあるけれど、とても長く膨らむこともあります。
コンマで区切られた名詞がいくつも並んだ時、それを「ひとかたまりの主語」として捉える視点を身につけましょう。

今日のキー:
① 主語は何語にも膨らむ(=名詞だけでなく、修飾語句もすべて含めてひとかたまり)
② A, B, C and D という並列(=三つ以上の名詞をつなぐ書き方)
③ 主語の終わりは動詞の直前(=動詞を見つけたら主語の範囲が確定する)
④ 2文目は「A is B」の単純な構造(=主語=補語の関係)
⑤ can change = 「変えうる/変えられる」(=助動詞 can は可能性)
これは Malala Yousafzai の有名な演説の一節。シンプルだけど力強い文です!

1
長い主語をひとかたまりとして捉える視点を身につけます。
2
動詞を見つけたら主語の範囲が確定すると理解します。
3
A, B, C and D の並列(=三つ以上の名詞をつなぐ書き方)を覚えます。
STEP 0 — First Read —

まず、自分で読んでみよう

解説を読む前に必ずやってほしいステップ。「自分はどう読んだか」を意識化することが、読み方を身につける最大の近道です。

One child, one teacher, one textbook and one pen can change the world. Education is the only solution.

STOP. ここで一度立ち止まって。
① まず辞書を引かずに訳してみてください。
② 訳せなくても OK。「どこで詰まったか」を意識してください。
③ 「ここの構造がよく分からない」「この単語の品詞が判別できない」と感じたら、それがあなたの伸びしろです。
STEP 1 — Common Mistakes —

ありがちな誤読を先につぶしておく

この英文で多くの生徒がハマる罠が 6つ あります。先に見ておくことで、自分が同じ罠にハマっていないかチェックできます。

! One child だけを主語と思い、後ろを補足扱いする
「一人の子どもは一人の教師、一冊の教科書、一本のペンと一緒に世界を変えうる」(=主語の範囲を誤認)

★ One child, one teacher, one textbook and one pen 全体がひとつの主語!
★ 判別: 主語の終わりは動詞の直前!
→ 動詞 can change までの間にあるすべての名詞句が主語!
★ コンマで区切られた4つの名詞が同列に並んでいて、最後の前に and。
→ A, B, C and D という並列のパターン!
★ 類例:
・apples, oranges, bananas and grapes「リンゴ、オレンジ、バナナ、ブドウ」
・Tom, Jerry, Mike and Lisa「トム、ジェリー、マイク、リサ」
★ いずれも、コンマで区切られて、最後の名詞の前にだけ and を置く!

! can change の can を「~できる」と能力で訳す
「~を変えることができる~」(=能力のニュアンス)

★ can には2つのニュアンスがある!
(1) 能力: 「~できる」(=実力としてできる)
(2) 可能性: 「~うる/~ることがある」(=理論的に起こりうる)
★ 本問の can change the world:
→ 「世界を変えることができる」(=能力)よりも、
→ 「世界を変えうる」「世界を変えられる」(=可能性、潜在力)の方が文脈にぴったり!
★ なぜなら、これは Malala の演説の一節で、「教育には世界を変える力がある」というメッセージだから。
★ can の用法:
・She can swim.「彼女は泳げる」(=能力)
・It can be cold in winter.「冬は寒くなることがある」(=可能性)
・Education can change lives.「教育は人生を変えうる」(=可能性・潜在力)

! change the world を「世界を交換する」と訳す
「世界を交換する~」

★ change は多義語!
(1) 「変える/変わる」(=変化)
(2) 「交換する」(=何かと取り替える)
(3) 「(衣服を)着替える」
★ 本問の change the world:
→ (1) 「世界を変える」(=変化させる)
★ 慣用フレーズ: change the world「世界を変える」(=社会を変革する、というポジティブな意味で頻出)
★ 類似フレーズ:
・change the future「未来を変える」
・change someone's life「人の人生を変える」
★ ポジティブな影響を与える、というニュアンス!

! 2文目の Education is the only solution. を見落とす
「(2文目の存在を見過ごす)」

★ 本問は2つの文からなる!
★ 1文目: One child, ... can change the world.「一人の子ども、~が世界を変えうる」
★ 2文目: Education is the only solution.「教育こそが唯一の解決策だ」
★ 2文目の構造: 主語(Education) + 動詞(is) + 補語(the only solution)
→ 「主語 = 補語」の関係!
→ 教育 = 唯一の解決策!
★ solution = 「解決策/答え」
★ the only solution = 「唯一の解決策」
★ Education = 抽象名詞「教育」(=無冠詞、第1講応用)
★ 意訳: 「教育こそが唯一の解決策だ」(=強調)

! コンマと and の組み合わせを「全部and」と読む
「(全てに and があると思い込む)」

★ 英語で三つ以上の名詞を並列するときは、最後の名詞の前にだけ and を置くのが普通!
★ 本問: One child, one teacher, one textbook and one pen
= 「一人の子ども、一人の教師、一冊の教科書、そして一本のペン」
★ パターン:
・2つの並列: A and B(=「AとB」)
・3つ以上: A, B(, ) and C(=「A、B、(そして)C」)
・4つ: A, B, C and D(=「A、B、C、(そして)D」)
★ 注意: アメリカ英語では A, B, and C(=最後の and の前にもコンマ、Oxford comma)も多い。本問はイギリス式!
★ つまり、複数のコンマと最後の and を見たら、「ああ、これは三つ以上の並列だな」と気づくのがポイント!

! One child, one teacher, ... を「一人の子ども一人につき一人の教師」と訳す
「一人の子ども一人につき一人の教師~」

★ One ~ one ~ は「~ごとに~」「~につき~」の意味になることもあるが、本問はそうではない!
★ 本問: One child, one teacher, one textbook and one pen は、4つの名詞句が並列!
→ 「一人の子ども、一人の教師、一冊の教科書、一本のペン」(=4つそれぞれが主語)
★ 判別: コンマで区切られている → 並列!
★ もし「一人の子どもごとに」なら、For each child, ~ や One teacher per child, ~ の形になる!
★ ここでは Malala が「(たとえ少なくても)この4つだけで世界を変えられる」と力強く宣言するために、4つの名詞を並列している!

STEP 2 — Read Along —

左から右へ、頭の中の実況中継

読める人は、英文を読みながら頭の中で常に何かを「考えて」います。その思考プロセスを 1語ずつ覗いてみましょう。これが英文解釈の正体です。

1 One child, one teacher, one textbook and one pen ▸ 4つの名詞を「ひとつの主語」として捉える

主語 One child, one teacher, one textbook and one pen「一人の子ども、一人の教師、一冊の教科書、一本のペン」が登場。

★ コンマで区切られた4つの名詞句!
→ One child「一人の子ども」
→ one teacher「一人の教師」
→ one textbook「一冊の教科書」
→ one pen「一本のペン」

★ 三つ以上の名詞を並列するパターン: A, B, C and D
→ 最後の名詞の前にだけ and を置く!

★ 4つ全体が「ひとつの主語」!
→ 動詞が来るまで、これらは全部主語の一部!

★ イメージ: 4つを抱え込んだ「主語のかたまり」が、ドンと文の前に置かれている感じ。

→ 後ろに動詞が来るはず!動詞が見つかったら主語の範囲が確定する!
S = One child, one teacher, one textbook and one pen(=4つの名詞が並列、ひとつの主語)
2 can change ▸ 動詞 ─ 助動詞 can は「能力」か「可能性」か

動詞 can change「変えうる」が登場。

★ can = 助動詞、後ろに動詞の原形を取る
★ change = 動詞「変える」(=他動詞)

★ can の2つのニュアンス:
(1) 能力: 「~できる」(=実力としてできる)
(2) 可能性: 「~うる/~ることがある」(=理論的に起こりうる)

★ 本問の can change the world:
→ 「世界を変えることができる」(=能力)よりも、
→ 「世界を変えうる」「世界を変えられる」(=可能性、潜在力)の方が文脈にぴったり!

★ なぜなら、これは Malala の演説の一節で、「教育には世界を変える力がある」というメッセージだから!

★ change = 多義語!
→ 「変える」(=変化、本問)
→ 「交換する」
→ 「(衣服を)着替える」
→ 文脈で判断!ここは「変える」!
V = can change「変えうる」(=can は可能性、change は「変える」)
3 the world. ▸ 目的語 ─ change の対象

目的語 the world「世界」が登場、1文目が完結!

★ change(=他動詞)の目的語!
★ the world = 「世界」
→ the がついて「(私たちの住む)世界」を特定

★ 慣用フレーズ: change the world「世界を変える」
→ 社会を変革する、というポジティブな意味で頻出!

★ 1文目の完成:
→ 主語(One child, one teacher, one textbook and one pen) + 動詞(can change) + 目的語(the world)
→ 「一人の子ども、一人の教師、一冊の教科書、一本のペンが、世界を変えうる」

★ Malala のメッセージ:
→ たとえ少ない人数や道具でも、教育の力があれば世界を変えられる
→ 教育の重要性を訴える格言的な一文!
O = the world「世界」(=change の目的語)。1文目「一人の子ども~が世界を変えうる」完成!
4 Education is ▸ 2文目スタート ─ Education は無冠詞の抽象名詞

2文目スタート Education is「教育は~である」!

★ S = Education「教育」
→ 無冠詞(=a/the が付いていない)!
→ 第1講で学んだ通り、無冠詞の抽象名詞は「教育というもの全般」を指す!

★ V = is(=be動詞、主語と補語をイコールでつなぐ)

→ 後ろに補語が来るはず!主語とイコールの関係になる名詞や形容詞!
S₂ = Education(=無冠詞の抽象名詞「教育」) / V₂ = is(=be動詞) → 補語を予測!
5 the only solution. ▸ 補語 ─ 「教育=唯一の解決策」のイコール関係

最後に the only solution.「唯一の解決策」が登場!

★ the only solution = 「唯一の解決策」(=補語)
★ solution = 「解決策/答え」
★ only = 「唯一の」(=形容詞)
★ the = 「(その)」(=特定)

★ 主語 = 補語の関係!
→ Education = the only solution
→ 「教育 = 唯一の解決策」!

★ be動詞 + 名詞 = 「~は~である」
→ 訳: 「教育は唯一の解決策である」
→ 意訳: 「教育こそが唯一の解決策だ」(=「こそ」で強調)

★ 2文の関係:
→ 1文目: 「教育の力(=最小の構成要素でも)で世界を変えられる」
→ 2文目: 「だから教育こそが解決策だ」
→ 1文目を受けて、2文目が結論を述べる構造!

★ Malala の演説のメッセージ性が、この簡潔な2文に凝縮されている!
C = the only solution「唯一の解決策」。Education = the only solution の関係!「教育こそが唯一の解決策」
▼ ここまでの解析を1枚で見る

5つのステップで、左から右へと考えてきたことを構造図にまとめると、こうなります。色分けで見ると、骨格(メイン)と補足の関係が一気にクリアになるはず。

One child, one teacher, one textbook and one penS₁ can助 changeV₁ the worldO₁ . EducationS₂ isV₂ the only solutionC₂ ..

骨格 = S₁(=4つの名詞並列) 助 V₁ O₁. S₂ V₂ C₂.(1文目=長い主語+他動詞+目的語。2文目=主語+be動詞+補語、主語=補語の関係)
▼ 構造が見えたら、いよいよ訳の仕上げ

構造解析で終わると「結局この文は何を言ってるの？」が宙ぶらりんになりがち。
ここから、直訳 → 中間訳 → 完成訳と、日本語として自然な訳に磨き上げる手順を見ていきます。これも「センス」ではなく、ちゃんと段階的な手順があります。

① 直訳
一人の子ども、一人の教師、一冊の教科書、そして一本のペンが世界を変えることができる。教育は唯一の解決策である。 構造どおりの直訳。「~ことができる」より「~うる」の方が、潜在力のニュアンスが伝わる。
▼ 長い主語をひとかたまりとして捉える コンマで区切られた4つの名詞 + and = ひとつの主語!動詞 can change までの全部が主語。
② 中間訳
一人の子ども、一人の教師、一冊の教科書、一本のペンが世界を変えうる。教育は唯一の解決策だ。 「~することができる」を「~うる」(=可能性)に変更。「である」を「だ」と簡潔に。
▼ A, B, C and D の並列パターン 三つ以上の名詞を並列するときは、最後の名詞の前にだけ and。これが英語の標準形!
③ 完成訳
一人の子ども、一人の教師、一冊の教科書、一本のペンが世界を変えうる。教育こそが唯一の解決策だ。 「教育は」を「教育こそが」と強調!Malala の演説の力強いメッセージ性が日本語でも伝わる。
💡 自然訳の「型」: 主語は何語にも膨らむ ─ 動詞が見つかるまで主語は終わらない

STEP 3 — Try It Yourself —

同じ思考で、別の英文を読んでみる

読み方は「使えてナンボ」。今日身につけた思考プロセスを、別の英文で試してみましょう。答えを見る前に必ず自分で考えるのがポイント。
知識として「覚える」のではなく、手を動かして「使える」状態に持っていきます。

Q1 長い主語を見抜く

My mother and her two sisters live in Kyoto.

主語の範囲はどこから どこまで？

分析: 動詞は live。動詞の前まで全部が主語!
→ 主語 = My mother and her two sisters「私の母と彼女の二人の姉妹」
訳: 「私の母と二人の伯母(叔母)は京都に住んでいる」

💡 動詞 live の主語は3人(母+姉妹2人)!are ではなく live でも単複の判断は同じ。
Q2 A, B, C and D の並列

I bought apples, oranges, bananas and grapes at the supermarket.

A, B, C and D の構造は？

分析: 三つ以上の名詞を並列するときは、最後の名詞の前にだけ and!
→ 4つの名詞 apples, oranges, bananas, grapes がすべて bought の目的語!
訳: 「私はスーパーでリンゴ、オレンジ、バナナ、ブドウを買った」

💡 コンマで区切られて、最後の前にだけ and。これが標準的な英語の並列!
Q3 can = 能力 vs 可能性

(1) She can swim. / (2) Education can change lives.

2つの can のニュアンスは？

(1): can swim = 「能力」(=泳ぐ実力がある)
→ 訳: 「彼女は泳げる」
(2): can change lives = 「可能性・潜在力」(=人生を変える力がある)
→ 訳: 「教育は人生を変えうる」

💡 主語が「人」で具体的な動作 → 能力。主語が「概念」で潜在力 → 可能性!文脈で判断!
STEP 4 — Your Reading Algorithm —

これからの英文に使える「思考フロー」

最後に、今日の学びを初見の英文に使える型として整理しておきます。これを毎回頭の中で回せば、確実に読める英文が増えていきます。

1
動詞を見つける(=英文を読むスタート)
まず動詞を探す!動詞が見つかれば、その前のかたまりが主語と確定!
2
動詞の前のすべてを主語のかたまりとして捉える
長くても1語でも、動詞の前は全部主語!コンマや修飾語があっても、動詞までは主語の範囲。
3
三つ以上の名詞並列 = A, B, C and D
最後の名詞の前にだけ and を置く。これが英語の標準形!
4
主語が複数の名詞なら、動詞は複数形を選ぶ
主語が複数 → are / have / live(=単純形)。単数 → is / has / lives(=三単現)。
5
can は「能力」と「可能性」の2つのニュアンス
「~できる」(=能力) vs 「~うる/~することがある」(=可能性)。文脈で使い分ける!
6
慣用フレーズ change the world「世界を変える」
社会変革のポジティブな意味で頻出!change someone's life「人の人生を変える」も同類。
7
be動詞 = イコールの記号(=主語と補語をつなぐ)
Education is the only solution. = 「教育=唯一の解決策」!be動詞は「~である」と訳す。
8
2つの文の関係を意識する
1文目で「教育の力」を語り、2文目で「だから教育が解決策」と結論。論理の流れを意識すると意味がより深く伝わる!
